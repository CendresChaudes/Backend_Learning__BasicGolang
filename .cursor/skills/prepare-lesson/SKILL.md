# Подготовить урок

Команда принимает одну папку и заполняет её по `.cursor/rules/lesson-files.mdc`.

## Вход

Путь к папке — текст после команды или папка, прикреплённая через `@`.

Пример: `/prepare-lesson 3. Переменные и типы/3.8. Новая тема`

Если пути нет, остановись и попроси его. Папку не угадывай.

Если папки нет на диске, создай её и продолжи.

## Шаги

1. Прочитай имя папки: это заголовок и тема урока. Посмотри соседние уроки той же главы, чтобы тема продолжала курс, а не повторяла уже пройденное.
2. Уже лежащие `theory.md`, `tasks.go` и `tasks_test.go` не перезаписывай. Создай только отсутствующие и напиши, какие файлы пропущены.
3. Создай недостающие файлы по спецификации ниже. Пиши по-русски, для разработчика без опыта на Golang. Термины Golang оставляй в оригинале и сразу поясняй.
4. Если в папке нет `go.mod`, создай его. Версию `go` и вид пути модуля возьми из `go.mod` соседнего урока. Без модуля команда `go test .` не запустится.
5. Когда `theory.md`, `tasks.go` и `tasks_test.go` лежат в папке, удали `.gitkeep`, если он есть.
6. В папке урока запусти `go test .`. Сборка должна пройти. Тесты должны упасть: заготовки возвращают нулевые значения, а в тестах лежат другие ожидаемые ответы. Если тесты прошли, в заготовке оказалось готовое решение — убери его. Если файл не компилируется, поправь заготовку, решение ученика не вписывай.

## theory.md

Теория по теме из имени папки.

- Заголовок — имя папки.
- Один шаг — одна мысль. Новый термин поясни сразу.
- К каждому тезису — короткий пример и разбор, что делает пример.
- В конце два коротких блока: что запомнить и что сделать ученику (`tasks.go`, `go run .`, `go test .`).

## tasks.go

Три задания в одном файле. `package main`.

- Комментарии: `Задание 1`, `Задание 2`, `Задание 3`.
- У каждого задания своя функция `task1`, `task2`, `task3`. Результат — число, строка или `bool`.
- Над функцией комментарий: что сделать. Готового решения в теле нет.
- Заготовка компилируется и возвращает нулевое значение типа: `0`, `""` или `false`.
- `main` только вызывает три функции и печатает результат.

## tasks_test.go

Тесты `TestTask1`, `TestTask2`, `TestTask3`.

- Первая строка файла: `// Запуск: go test .`
- Тест вызывает функцию ученика и сравнивает результат с ожидаемым значением.
- В тесте только проверка и ожидаемый ответ. Решения задания там нет.
- Пока заготовка пустая, тест падает. После верного решения проходит.
