# 10.1. Пакеты

Пакет — все файлы одной папки с одинаковой первой строкой `package`. Имя в этой строке общее. Файлы одного пакета видят имена друг друга без `import`.

## Несколько файлов

Программа `package main` может лежать в нескольких файлах одной папки.

```text
tasks.go
hello.go
```

Оба файла начинаются с `package main`. Функция `hello` из `hello.go` вызывается из `tasks.go` по имени, импорт не нужен. Имя с маленькой буквы видно внутри пакета и скрыто снаружи.

## Свой пакет

Свой пакет — отдельная папка внутри модуля. В папке лежит файл с именем пакета в первой строке. Программа в `package main` подключает его через `import`.

В этом уроке модуль называется `lesson10/packages`. Так записано в `go.mod`.

```text
go.mod
tasks.go
user/
  user.go
```

`user.go` начинается с `package user`. Импорт из `tasks.go`:

```go
import "lesson10/packages/user"
```

Путь импорта — имя модуля, затем папка пакета.

## Экспорт

Экспорт — имена, которые разрешено вызывать из другого пакета. Имя экспортируют большой буквой в начале.

```go
package user

func Login() string {
	return "Leo"
}
```

`user.Login()` вызывается снаружи. Функция `login` с маленькой буквы снаружи недоступна.

Поле struct устроено так же. `Balance` с большой буквы читают из другого пакета. Поле `name` с маленькой буквы снаружи не видно. Его отдают методом `Name()` или заполняют конструктором `New` в том же пакете.

## Что запомнить

- Файлы одной папки с одним `package` видят друг друга без импорта.
- Чужой пакет подключают путём `модуль/папка`.
- Большая буква экспортирует имя. Маленькая оставляет его внутри пакета.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
