# 10.1. Разделение кода

Пакет и `import` уже встречались в раннем уроке. Здесь программа растёт: функции одного пакета раскладывают по разным файлам.

Пакет — все файлы одной папки с одинаковой первой строкой `package`. Имя в этой строке общее. Для программы это `package main`.

```text
tasks.go
hello.go
```

Оба файла лежат в папке урока. Оба начинаются с `package main`.

## Общие имена

Файл `hello.go` описывает функцию. Второй файл её вызывает. `import` между ними не нужен: это один пакет.

```go
package main

func hello() string {
	return "hi"
}
```

`hello` — имя функции. Маленькая буква здесь уместна: вызов идёт из того же пакета.

```go
package main

func task1() string {
	return hello()
}
```

`hello()` запускает функцию из другого файла. Перед именем нет точки и нет имени пакета. `go run .` и `go test .` собирают все `.go` файлы папки вместе.

Функция `main` в пакете `main` одна. Её оставляют в `tasks.go`. В файле помощника пишут только его функции.

## Одна папка

У всех файлов папки одна и та же строка `package`. Так они входят в один пакет. Новый пакет со своим именем кладут в отдельную папку. Это следующий урок.

Имя с маленькой буквы видно каждому файлу этой папки. Имя с большой тоже видно внутри пакета. Большая буква понадобится, когда функцию вызывает другой пакет.

## Что запомнить

- Один пакет — одна папка и одно имя в строке `package`.
- Файлы пакета видят функции друг друга без `import`.
- Вызов внутри пакета: `hello()`.
- `main` пишут один раз.

## Что сделать

Заполни `tasks.go` и добавь рядом файлы, о которых просят задания. Запуск: `go run .`. Проверка: `go test .`.
