# 10.2. Добавление пакета

Свой пакет — отдельная папка внутри модуля. В папке лежит файл с именем пакета в первой строке. Программа в `package main` подключает его через `import`.

В этом уроке модуль называется `lesson10/add`. Так записано в `go.mod`.

```text
go.mod
tasks.go
wallet/
  wallet.go
```

`wallet` — папка пакета. `wallet.go` — его файл. Имя файла может быть любым. Имя пакета берётся из строки `package`.

## Файл пакета

```go
package wallet

func Owner() string {
	return "ann"
}
```

`package wallet` задаёт имя, которое пишут перед точкой при вызове. `Owner` начинается с большой буквы. Другой пакет, в том числе `main`, вызывает такое имя. Правила большой и маленькой буквы подробно разобраны в следующем уроке. Для вызова из `main` большая буква уже нужна.

## Импорт

Путь в `import` собирают из строки `module` и папки пакета. Папки идут от корня модуля, через слэш.

```go
import "lesson10/add/wallet"
```

`lesson10/add` — имя модуля. `wallet` — папка. Вместе это адрес пакета.

Вызов ставит имя пакета перед функцией:

```go
login := wallet.Owner()
```

`wallet.Owner()` выполняет `Owner` из пакета `wallet`. В `login` попадает `"ann"`.

Функцию кладут в пакет, когда ею пользуется `main` и когда у неё своя тема. В `tasks.go` остаётся запуск и вызов.

## Что запомнить

- Свой пакет — папка и строка `package` с его именем.
- Путь импорта: имя модуля, слэш, имя папки.
- Вызов: `wallet.Owner()`.
- Имя для вызова из `main` начинается с большой буквы.

## Что сделать

Заполни `tasks.go` и добавь пакет, о котором просят задания. Запуск: `go run .`. Проверка: `go test .`.
