# 10.2. Сторонние пакеты

Сторонний пакет написан другими людьми и лежит в своём модуле. Его скачивают в проект и подключают через `import`. Путь такого импорта — имя его модуля.

Для примера взят маленький пакет `rsc.io/quote`. Он отдаёт готовые английские фразы.

## Команда go get

Команду запускают в папке урока, там, где лежит `go.mod`.

```bash
go get rsc.io/quote
```

`go get` скачивает модуль и дописывает его в `go.mod` строкой `require`. После этого пакет можно импортировать.

```go
import "rsc.io/quote"

text := quote.Go()
```

`quote.Go()` возвращает фразу про общение через память. Имена `Glass` и `Opt` возвращают другие фразы того же пакета.

## go mod tidy

`go mod tidy` приводит `go.mod` в соответствие с импортами в коде. Команду запускают в папке, где лежит `go.mod`.

```bash
go mod tidy
```

Команда читает все `import` модуля и смотрит на `require`. Модуль, который импортируют, попадёт в список. Модуль, который больше никто не импортирует, из списка уйдёт. После `go get` и правок импортов `tidy` оставляют список требований чистым.

## Что запомнить

- `go get путь` скачивает сторонний модуль.
- Импорт совпадает с именем этого модуля.
- `go mod tidy` оставляет в `go.mod` только те модули, которые реально импортированы.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
