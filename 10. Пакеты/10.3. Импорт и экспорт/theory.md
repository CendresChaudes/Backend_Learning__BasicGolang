# 10.3. Импорт и экспорт

Экспорт — имена, которые разрешено вызывать из другого пакета. Импорт подключает этот пакет к файлу. Имя экспортируют большой буквой в начале.

В этом уроке модуль — `lesson10/export`. Пример ниже — пакет `item` в папке `item`. В заданиях пакет другой: его имя написано в `tasks.go`.

## Большая буква

```go
package item

func Title() string {
	return "box"
}
```

`Title` виден снаружи. Вызов из `main`: `item.Title()`.

Имя с маленькой буквы остаётся внутри пакета. Его вызывают файлы папки `item`.

Имя перед точкой — слово из строки `package`, здесь `item`. Путь в `import` — папки от модуля:

```go
import "lesson10/export/item"
```

## Поле struct

Тип и поле с большой буквы тоже экспортированы. Другой пакет создаёт значение и читает поле.

```go
type Goods struct {
	Price int
}
```

```go
g := item.Goods{Price: 40}
fmt.Println(g.Price)
```

`item.Goods` — тип из пакета `item`. `Price: 40` заполняет экспортированное поле. `g.Price` читает его. На экран попадёт `40`.

## Маленькое поле

Поле с маленькой буквы заполняют внутри пакета. Снаружи отдают конструктор и метод. Конструктор — функция, которая возвращает готовый struct. Метод — функция с получателем, её уже писали для struct.

```go
type Box struct {
	label string
}

func New(label string) Box {
	return Box{label: label}
}

func (b Box) Label() string {
	return b.label
}
```

`label` доступен в файлах пакета `item`. `New` и `Label` начинаются с большой буквы, их вызывает `main`.

```go
box := item.New("tape")
text := box.Label()
```

`item.New("tape")` собирает `Box` и кладёт `"tape"` в поле `label`. `box.Label()` возвращает это поле. В `text` лежит `"tape"`.

## Что запомнить

- Имя с большой буквы видно другому пакету: функция, тип, поле, метод.
- Имя с маленькой буквы остаётся в своём пакете.
- Путь импорта — папки модуля. Слово перед точкой — строка `package`.
- Маленькое поле снаружи читают через экспортированный метод.

## Что сделать

Заполни `tasks.go` и добавь пакет из заданий. Запуск: `go run .`. Проверка: `go test .`.
