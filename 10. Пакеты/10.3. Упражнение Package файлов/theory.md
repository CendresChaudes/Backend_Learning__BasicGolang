# 10.3. Упражнение Package файлов

В этом упражнении файл — значение в программе: имя и размер. Эти значения живут в своём пакете, разложенном по нескольким файлам.

Пакет уже умеет жить в отдельной папке. Файлы одной папки уже умеют видеть имена друг друга. Здесь оба правила работают вместе.

Модуль урока — `lesson10/bundle`. Пакет в заданиях называется `files`.

## Два файла одного пакета

```text
files/
  file.go
  size.go
```

Оба файла начинаются с `package files`. Struct из `file.go` виден функции из `size.go` без импорта. Пакет `fmt` подключают только в том файле, где он нужен.

Импорт из программы:

```go
import "lesson10/bundle/files"
```

Поля `Name` и `Size` экспортированы: их читает код снаружи пакета.

## Что запомнить

- Один пакет — одна папка и несколько файлов с общим `package`.
- Имена пакета видны во всех его файлах.
- Снаружи пакет подключают полным путём модуля.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
