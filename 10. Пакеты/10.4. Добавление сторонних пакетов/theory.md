# 10.4. Добавление сторонних пакетов

Сторонний пакет написан другими людьми и лежит в своём модуле. Его скачивают в проект и подключают через `import`. Путь такого импорта — имя его модуля.

Для примера взят маленький пакет `rsc.io/quote`. Он отдаёт готовые английские фразы.

## Команда go get

Команду запускают в папке урока, там, где лежит `go.mod`.

```bash
go get rsc.io/quote
```

`go get` скачивает модуль и дописывает его в `go.mod`. В файле появляется блок `require`: путь пакета и версия, которую скачала команда.

```text
require rsc.io/quote v1.5.2
```

Номер версии в твоём файле — тот, который записал `go get`. Рядом с `go.mod` появляется `go.sum`. Этот файл разбирается в уроке про `go mod tidy`.

У `quote` есть свой импорт, пакет `rsc.io/sampler`. Он тоже попадёт в `go.mod`. Пометка `indirect` стоит у пакета, который импортирует сам `quote`.

## Вызов

Импорт использует путь модуля пакета:

```go
import "rsc.io/quote"

func line() string {
	return quote.Go()
}
```

`quote` перед точкой — имя пакета. `Go` — экспортированная функция. Она возвращает английскую пословицу про память. Другие функции того же пакета устроены так же: вызов `quote.Имя()` возвращает строку.

Свой пакет из прошлого урока импортировали как `lesson10/add/wallet`. Чужой пакет импортируют по пути из его модуля: `rsc.io/quote`.

## Что запомнить

- `go get путь` скачивает сторонний модуль в папку с `go.mod`.
- В `go.mod` появляется `require` с путём и версией.
- Импорт стороннего пакета — путь его модуля: `rsc.io/quote`.
- Вызов: `quote.Go()`.

## Что сделать

В папке урока выполни `go get rsc.io/quote`. Затем заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
