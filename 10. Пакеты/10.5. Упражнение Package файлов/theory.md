# 10.5. Упражнение Package файлов

В этом упражнении файл — значение в программе: имя и размер. Эти значения живут в своём пакете, разложенном по нескольким файлам.

Пакет уже умеет жить в отдельной папке. Файлы одной папки уже умеют видеть имена друг друга. В упражнении оба правила работают вместе.

Модуль урока — `lesson10/bundle`. В примере пакет называется `docs`. В заданиях пакет называется `files`.

## Два файла одного пакета

```text
docs/
  doc.go
  size.go
```

Оба файла начинаются с `package docs`. Тип описывают в одном файле.

```go
package docs

type Doc struct {
	Name string
	Size int
}
```

`Doc`, `Name` и `Size` начинаются с большой буквы. `main` сможет собрать значение и прочитать поля.

Второй файл того же пакета пользуется типом `Doc` без `import`.

```go
package docs

func Pages(d Doc) int {
	return d.Size
}
```

`Pages` принимает `Doc`. Для файлов папки `docs` тип уже известен: они один пакет.

## Вызов из main

```go
import "lesson10/bundle/docs"

d := docs.Doc{Name: "a.txt", Size: 4}
n := docs.Pages(d)
```

`lesson10/bundle/docs` — путь к папке пакета. `docs.Doc` — тип. `docs.Pages(d)` — функция из второго файла. В `n` попадает `4`.

Третий файл пакета подключает `fmt` сам, если ему нужна сборка строки. `import` пишут в том файле, который вызывает чужой пакет. Соседний файл пакета `docs` этот `import` не видит.

## Что запомнить

- Пакет из нескольких файлов: одна папка и одно имя `package`.
- Тип из одного файла виден функциям других файлов этой папки.
- Из `main` вызывают имена с большой буквы: `docs.Doc`, `docs.Pages`.
- `import` стоит в том файле, который пользуется чужим пакетом.

## Что сделать

Это упражнение. Собери пакет `files` из трёх файлов и вызови его из `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
