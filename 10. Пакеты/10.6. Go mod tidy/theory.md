# 10.6. Go mod tidy

`go mod tidy` приводит `go.mod` в соответствие с импортами в коде. Команду запускают в папке, где лежит `go.mod`.

После `go get` в `go.mod` есть строки `require`. Они перечисляют скачанные модули. Код может измениться: импорт добавили или убрали. `tidy` обновляет список.

## Что делает команда

```bash
go mod tidy
```

Команда читает все `import` модуля и смотрит на `require`.

Импорт есть в коде, а строки `require` для него нет. `tidy` добавляет зависимость и скачивает модуль. Так бывает, если путь вписали в `import` руками.

Строка `require` есть, а ни один файл этот путь больше не импортирует. `tidy` убирает такую зависимость из `go.mod`.

## Файл go.sum

`go.sum` лежит рядом с `go.mod`. В нём контрольные суммы скачанных модулей. Сумма — длинная запись, по которой Go проверяет, что скачанный код совпадает с прошлым разом.

`tidy` обновляет `go.sum` вместе с `go.mod`. Оба файла оставляют в проекте. Список зависимостей меняют командами `go get` и `go mod tidy`.

Для пакета из прошлого урока строка в `go.mod` выглядит так:

```text
require rsc.io/quote v1.5.2
```

Если `import "rsc.io/quote"` из кода убрать и запустить `go mod tidy`, эта зависимость из списка уходит. Если импорт снова появится, та же команда вернёт её в `go.mod`.

## Что запомнить

- `go mod tidy` запускают в папке с `go.mod`.
- Команда добавляет недостающие зависимости и убирает лишние `require`.
- `go.sum` хранит контрольные суммы модулей.
- `go.mod` и `go.sum` правят командами, а не руками.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
