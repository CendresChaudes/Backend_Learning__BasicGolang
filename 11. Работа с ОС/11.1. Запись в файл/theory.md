# 11.1. Запись в файл

Программа держит текст в памяти. Когда она завершается, эта память освобождается. Файл — данные на диске. Запись в файл оставляет текст после выхода из программы.

## Пакет os

`os` — пакет стандартной библиотеки для разговора с операционной системой. Через него создают файлы, читают их и смотрят папки. Пакет подключают так:

```go
import "os"
```

`import "os"` делает функции пакета доступными по имени `os.Имя`.

## Байты

Файл хранит байты. Байт — число от 0 до 255, маленький кусок данных. Срез байтов имеет тип `[]byte`.

Строку превращают в байты так:

```go
data := []byte("go")
```

`[]byte("go")` берёт строку и отдаёт срез. В `data` два байта: код буквы `g` и код буквы `o`. `os` принимает именно такой срез, а не строку.

## Запись

`os.WriteFile` записывает срез в файл целиком.

```go
err := os.WriteFile("note.txt", []byte("go"), 0644)
```

По аргументам:

- `"note.txt"` — имя файла. Если такого файла нет, функция его создаст. Если есть, старое содержимое будет заменено.
- `[]byte("go")` — байты, которые лягут в файл.
- `0644` — права доступа. Права говорят, кто может читать файл и кто может его менять. Ноль впереди означает восьмеричную запись: так в Go принято писать права. `0644` значит: владелец читает и пишет, остальные только читают. Для обычной заметки этого достаточно.

Функция возвращает `error`. Это тот же тип, что ты уже использовал для неудачи. Успех — значение `nil`. Неудача — текст причины.

```go
if err != nil {
	return err.Error()
}
```

`err != nil` истинно, когда записать не удалось. `err.Error()` отдаёт текст ошибки. Пока `err` равен `nil`, в эту ветку не входят: файл уже записан.

## Что запомнить

- Файл хранит байты на диске. Строку перед записью превращают в `[]byte`.
- `os.WriteFile(имя, байты, права)` создаёт файл или заменяет его содержимое.
- Для обычного текста права записывают как `0644`.
- Результат записи — `error`. `nil` значит, что файл записан.
