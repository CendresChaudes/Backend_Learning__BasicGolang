# 11.1. Файлы

Программа держит текст в памяти. Когда она завершается, эта память освобождается. Файл — данные на диске. Запись в файл оставляет текст после выхода из программы.

## Пакет os

`os` — пакет стандартной библиотеки для разговора с операционной системой. Через него создают файлы и читают их.

```go
err := os.WriteFile("note.txt", []byte("привет"), 0644)
```

`os.WriteFile` создаёт файл или заменяет его целиком. Второй аргумент — байты. Строку переводят в байты: `[]byte(text)`. Третий аргумент — права. `0644` значит: владелец пишет и читает, остальные только читают. Ноль впереди — признак восьмеричной записи.

`os.ReadFile` читает файл целиком и возвращает байты.

```go
data, err := os.ReadFile("note.txt")
text := string(data)
```

Если файл прочитан, `err` равен `nil`. Если файла нет, `err` не равен `nil`, а `data` пустой.

## defer

`defer` откладывает вызов до выхода из функции. Даже если посередине будет `return`, отложенный вызов выполнится.

```go
func read() string {
	log := "открыл"
	defer func() {
		log = log + "|закрыл"
	}()
	return log
}
```

Здесь есть тонкость: `return log` запоминает текущую строку `"открыл"` до того, как отработает `defer`. Отложенная правка локальной `log` в ответ уже не попадёт. Если результат именованный, `defer` ещё успевает его изменить:

```go
func read() (log string) {
	log = "открыл"
	defer func() {
		log = log + "|закрыл"
	}()
	return log
}
```

`(log string)` — именованный результат. `defer` видит ту же переменную. Функция вернёт `"открыл|закрыл"`.

Так же планируют закрытие файла: открыли, сразу написали `defer file.Close()`, дальше работают с данными.

## Что запомнить

- `os.WriteFile` записывает байты на диск. `os.ReadFile` читает их обратно.
- Ошибку проверяют через `err != nil`.
- `defer` выполняется при выходе из функции. Именованный результат он ещё может изменить.
