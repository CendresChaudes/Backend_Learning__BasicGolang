# 11.11. Упражнение Поиск пароля

Поиск идёт по срезу `[]Entry`. Имя записи сравнивают с запросом. У первого совпадения забирают секрет.

```go
for i, item := range items {
	if item.Name == name {
		return item.Secret
	}
}
return ""
```

`item.Name == name` — имена равны. `return` сразу отдаёт `item.Secret` и выходит из функции. До конца среза цикл тогда не идёт. Если одно имя встречается дважды, наружу уходит секрет первой записи.

Если цикл закончился сам, совпадения не было. Пустая строка здесь значит: секрета нет.

## Индекс

Индекс совпадения — это `i` из `range`. Первый элемент имеет индекс `0`, поэтому ноль нельзя использовать как сигнал «не найдено». Для отсутствия берут `-1`: такого индекса в срезе не бывает.

```go
for i, item := range items {
	if item.Name == name {
		return i
	}
}
return -1
```

Нашли имя — вернули его индекс. Дошли до конца — вернули `-1`.

## Есть или нет

Проверка «запись есть» — отдельный результат типа `bool`. Нашли имя — `true`. Дошли до конца — `false`. Секрет при этой проверке не нужен: смотрят только на `Name`.

## Что запомнить

- Поиск — цикл по `[]Entry` и сравнение `Name`.
- Первое совпадение отдаёт `Secret` и заканчивает функцию.
- Нет совпадения — пустой секрет и `false`.
- Индекс отсутствия — `-1`, потому что `0` занят первым элементом.

## Что сделать

Это упражнение. Тип `Entry` уже описан в `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
