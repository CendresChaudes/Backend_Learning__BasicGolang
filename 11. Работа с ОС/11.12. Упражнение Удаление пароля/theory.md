# 11.12. Упражнение Удаление пароля

Удаление собирает новый срез. Записи с нужным именем в него не попадают. Остальные сохраняют прежний порядок.

```go
var kept []Entry
for _, item := range items {
	if item.Name == name {
		continue
	}
	kept = append(kept, item)
}
```

`var kept []Entry` — пустой срез. `continue` переходит к следующей записи, строка с `append` для этого имени не выполняется. Остальные имена добавляют в `kept`. Если одинаковых имён несколько, пропускают каждое.

## Имена через запятую

Имена оставшихся склеивают через запятую без пробела. У первой записи запятой слева нет.

```go
text := ""
for i, item := range kept {
	if i > 0 {
		text += ","
	}
	text += item.Name
}
```

`i > 0` истинно со второго элемента. Перед ним ставят запятую, потом имя. Из записей `mail` и `bank` получится `"mail,bank"`. Если не осталось ни одной записи, строка пустая.

Длину нового среза даёт `len(kept)`. Это число паролей после удаления.

## Запись обратно в файл

Тот же срез кладут в файл, из которого его прочитали. Сначала байты JSON, потом запись по старому пути.

```go
data, err := json.Marshal(kept)
if err != nil {
	return ""
}
err = os.WriteFile(path, data, 0644)
```

`json.Marshal(kept)` делает JSON-массив. Теги `json:"name"` и `json:"secret"` задают имена полей в тексте. `os.WriteFile` заменяет прежнее содержимое файла. В файле остаётся массив без удалённого имени.

## Что запомнить

- Удаление — новый срез без записей с этим именем.
- `continue` пропускает имя, которое удаляют. Порядок остальных сохраняется.
- Имена оставшихся склеивают через запятую без пробела.
- В файл кладут JSON нового среза, путь тот же.
