# 11.2. Stack frame

Вызов функции занимает свой кусок памяти. Этот кусок называют stack frame — кадр стека. В кадре лежат аргументы и локальные переменные именно этого вызова.

## Стек вызовов

Стек вызовов — стопка кадров. Вызов кладёт новый кадр сверху. `return` снимает верхний кадр.

```go
func main() {
	n := step(2)
}

func step(x int) int {
	y := x + 1
	return y
}
```

Пока выполняется `step`, сверху лежит его кадр. В нём `x` равен `2`, `y` равен `3`. Под ним лежит кадр `main`.

`return y` копирует `3` в вызывающий кадр. После этого кадр `step` снимают. `x` и `y` исчезают вместе с ним. В `main` остаётся копия: `n` равен `3`.

## Одинаковые имена

Имя переменной живёт внутри своего кадра. Две функции могут назвать переменную `n`. Это две разные переменные.

```go
func outer() int {
	n := 1
	return n + inner()
}

func inner() int {
	n := 10
	return n
}
```

`inner` возвращает `10`, и кадр `inner` снимается. `n` внутри `outer` по-прежнему `1`. Кадр `inner` эту переменную не меняет. Сумма равна `11`.

## Вложенные вызовы

Функция может вызвать другую, та — третью. На стеке одновременно несколько кадров. Верхний — тот, кто работает сейчас.

```go
func first() int {
	n := 1
	return n + second()
}

func second() int {
	n := 2
	return n + third()
}

func third() int {
	n := 4
	return n
}
```

Пока работает `third`, стопка сверху вниз такая: `third`, `second`, `first`. `third` возвращает `4` и снимается. `second` прибавляет свой `2` и тоже снимается. `first` прибавляет свой `1`. Наружу уходит `7`.

## Что запомнить

- Кадр стека хранит аргументы и локальные переменные одного вызова.
- Стек вызовов — стопка кадров. Новый вызов кладёт кадр сверху, `return` снимает его.
- `return` отдаёт копию результата. Локальные переменные кадра после этого недоступны.
- Одинаковое имя в разных кадрах — разные переменные.
