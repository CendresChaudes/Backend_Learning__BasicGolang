# 11.3. Defer

`defer` откладывает вызов до выхода из функции. В уроке про `panic` ты уже видел его рядом с `recover`. Здесь функция выходит обычным `return`. Кадр ещё не снят, и отложенные вызовы успевают отработать.

Так закрывают файл: открыли, сразу запланировали закрытие, дальше работают с данными. Даже если посередине будет `return`, закрытие не потеряется.

## Один отложенный вызов

```go
func read() (log string) {
	log = "открыл"
	defer func() {
		log += " закрыл"
	}()
	log += " прочитал"
	return
}
```

По строкам:

- `(log string)` — именованный результат. Это переменная кадра. Её можно дописать из `defer`.
- `log = "открыл"` записывает начало строки.
- `defer func() { ... }()` запоминает функцию без имени. Скобки `()` в конце регистрируют вызов, но тело пока не выполняется.
- `log += " прочитал"` дописывает работу.
- `return` начинает выход. Перед снятием кадра выполняется отложенное тело. К строке дописывается `" закрыл"`.

Снаружи придёт `"открыл прочитал закрыл"`.

## Стопка defer

Несколько `defer` лежат в кадре стопкой, как сами кадры из прошлого урока. Последний зарегистрированный выполняется первым.

```go
func order() (text string) {
	defer func() {
		text += "A"
	}()
	defer func() {
		text += "B"
	}()
	text = "старт"
	return
}
```

Сначала запомнили дописывание `"A"`, потом дописывание `"B"`. На выходе сначала срабатывает `"B"`, затем `"A"`. После слова `"старт"` в строке окажутся эти две буквы в таком порядке.

## Аргумент копируется сразу

Аргумент отложенного вызова считается в момент `defer`, а не в момент выхода.

```go
func captured() (result int) {
	n := 1
	defer func(x int) {
		result += x
	}(n)
	n = 10
	result = n
	return
}
```

`(n)` после функции без имени передаёт аргумент сразу. `x` получает копию `1`. Позже `n` становится `10`, на `x` это уже не влияет.

Перед выходом `result` равен `10`. Отложенный вызов прибавляет сохранённую копию `1`. Наружу уходит `11`.

## Что запомнить

- `defer` выполняет вызов при выходе из функции, до снятия кадра.
- Несколько `defer` идут с конца: последний зарегистрированный — первый на выходе.
- Аргумент `defer` копируется в момент регистрации.
- Именованный результат можно дописать из `defer`.
