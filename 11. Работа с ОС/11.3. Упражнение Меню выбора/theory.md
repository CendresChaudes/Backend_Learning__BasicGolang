# 11.3. Упражнение Меню выбора

Утилита паролей в консоли начинается с меню. Программа печатает команды, человек вводит число, `switch` выбирает действие. В этом упражнении число уже пришло в функцию.

Команды:

- `0` — выход
- `1` — показать
- `2` — добавить
- `3` — найти
- `4` — удалить

Любое другое число — неизвестная команда.

Список кодов обходят слева направо. Ноль значит «дальше не читать»: сам ноль в ответ не входит, и коды после него тоже.

## Что запомнить

- Одна команда — одно число. Имя команды выбирает `switch`.
- Неизвестное число — отдельная ветка.
- Ноль в списке останавливает разбор.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
