# 11.4. Упражнение Пароли

Один пароль — один struct: имя записи и секрет. Несколько паролей — срез таких struct.

```go
type Entry struct {
	Name   string
	Secret string
}
```

Поиск идёт по срезу. Имя записи сравнивают с запросом. У первого совпадения забирают секрет.

Удаление собирает новый срез. Записи с нужным именем в него не попадают. Остальные сохраняют прежний порядок.

```go
var kept []Entry
for _, item := range items {
	if item.Name == name {
		continue
	}
	kept = append(kept, item)
}
```

`continue` пропускает удаляемую запись. `append` кладёт остальные в новый срез.

## Что запомнить

- Поиск возвращает секрет первой записи с нужным именем.
- Нет записи — пустая строка или `-1`, смотря что просили вернуть.
- Удаление не дырявит старый срез: собирают новый без нужных имён.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
