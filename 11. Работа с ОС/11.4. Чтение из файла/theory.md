# 11.4. Чтение из файла

`os.ReadFile` читает файл целиком и возвращает его байты. Для короткой заметки этого достаточно: весь текст помещается в память.

## Чтение

```go
data, err := os.ReadFile("note.txt")
```

Функция возвращает две величины. `data` — срез `[]byte`. `err` — ошибка. Если файл прочитан, `err` равен `nil`.

Байты переводят в строку преобразованием типа:

```go
text := string(data)
```

`string(data)` собирает строку из тех же байтов. Файл на диске при этом не меняется. В `text` лежит копия содержимого.

Длину среза даёт `len(data)`. Это число байтов в файле, а не число букв. Для строки `"go"` длина равна `2`.

## Файла нет

Если пути нет на диске, `os.ReadFile` вернёт ошибку. В пакете `os` для этого случая есть готовое значение `os.ErrNotExist`.

Пакет `errors` умеет спрашивать, та ли это ошибка:

```go
import "errors"

if errors.Is(err, os.ErrNotExist) {
	return "нет файла"
}
```

`errors.Is` возвращает `true`, когда `err` — это `os.ErrNotExist`. Тогда функция отдаёт текст `"нет файла"`.

Пока `err` равен `nil`, в эту ветку не входят. Байты уже лежат в `data`.

## Что запомнить

- `os.ReadFile` возвращает `[]byte` и `error`.
- `string(data)` делает из байтов строку. `len(data)` — число байтов.
- `nil` в ошибке значит, что файл прочитан.
- `errors.Is(err, os.ErrNotExist)` истинен, когда файла нет.
