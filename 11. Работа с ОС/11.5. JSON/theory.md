# 11.5. JSON

JSON — текстовый формат для данных. Его удобно хранить в файле и читать из другой программы. В этом уроке значение Go превращается в такой текст и собирается обратно. Запись файла будет следующим шагом.

## Как выглядит текст

Объект JSON записан в фигурных скобках. Внутри пары: имя поля в кавычках, двоеточие, значение.

```text
{"Title":"Go","Pages":3}
```

`"Title"` — имя поля. `"Go"` — строка. `3` — число, его пишут без кавычек.

## Пакет encoding/json

`encoding/json` входит в стандартную библиотеку. `json.Marshal` переводит значение Go в байты JSON. `json.Unmarshal` делает обратное.

В JSON попадают поля struct с большой буквы. Имя поля в тексте совпадает с именем в Go.

```go
type Note struct {
	Title string
	Pages int
}

data, err := json.Marshal(Note{Title: "Go", Pages: 3})
```

`json.Marshal` возвращает `[]byte` и `error`. При успехе `err` равен `nil`. В `data` лежат байты текста `{"Title":"Go","Pages":3}`. Строку из них получают так же, как при чтении файла: `string(data)`.

Порядок полей в тексте — порядок полей в struct. Сначала `Title`, потом `Pages`.

## Разбор

`json.Unmarshal` пишет результат в уже созданную переменную. Ей передают адрес: функция должна знать, куда положить поля.

```go
var note Note
err = json.Unmarshal([]byte(`{"Title":"Go","Pages":3}`), &note)
```

`[]byte(...)` — байты того текста, который разбираем. Обратные кавычки держат строку как есть, двойные кавычки внутри экранировать не нужно.

`&note` — адрес переменной `note`. После успешного вызова `note.Title` равен `"Go"`, `note.Pages` равен `3`.

Если текст обрезан и это уже не JSON, `err` не равен `nil`. Поля `note` тогда не используют.

## Что запомнить

- JSON-объект — текст в фигурных скобках: `"имя": значение`.
- `json.Marshal` делает из struct байты JSON. В текст попадают поля с большой буквы.
- `json.Unmarshal` разбирает байты в переменную. Ей передают адрес через `&`.
- Битый текст даёт `error`, не равный `nil`.
