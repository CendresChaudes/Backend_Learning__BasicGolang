# 11.7. Сохранение JSON

JSON-текст из `json.Marshal` — это байты. Их можно отдать `os.WriteFile` и оставить на диске.

## Два шага

Сначала значение собирают в байты. Потом эти байты записывают в файл.

```go
type Account struct {
	Login string `json:"login"`
	Port  int    `json:"port"`
}

data, err := json.Marshal(Account{Login: "ann", Port: 80})
if err != nil {
	return err.Error()
}
err = os.WriteFile("account.json", data, 0644)
```

`json.Marshal` собирает байты `{"login":"ann","port":80}`. Если сборка не вышла, `err` не равен `nil`, и до файла дело не доходит.

`os.WriteFile` записывает эти байты в `account.json`. Права те же, что у обычного текста: `0644`. После записи `err` проверяют ещё раз: диск может не принять файл.

`len(data)` — число байтов, которые ушли в файл. Для текста выше это длина JSON-строки.

## Пустое значение

Пустой логин в файл класть не стоит. Такую проверку делают до `Marshal`:

```go
if login == "" {
	return "пустой логин"
}
```

`login == ""` значит, строка пустая. Функция возвращает текст причины и не вызывает запись.

## Что запомнить

- Сначала `json.Marshal`, потом `os.WriteFile` с теми же байтами.
- Ошибку проверяют после каждого из двух вызовов.
- Пустое поле отсекают до записи.
- Права текстового файла — `0644`.
