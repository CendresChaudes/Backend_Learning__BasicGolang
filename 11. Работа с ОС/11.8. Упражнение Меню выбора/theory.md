# 11.8. Упражнение Меню выбора

Утилита паролей в консоли начинается с меню. Программа печатает команды, человек вводит число, `switch` выбирает действие. В этом упражнении число уже пришло в функцию. Нужно вернуть имя действия.

Команды:

- `0` — выход
- `1` — показать
- `2` — добавить
- `3` — найти
- `4` — удалить

Любое другое число — неизвестная команда. Известные коды — от `0` до `4` включительно.

```go
func action(code int) string {
	switch code {
	case 1:
		return "показать"
	case 2:
		return "добавить"
	default:
		return "неизвестно"
	}
}
```

`switch` сравнивает `code` с `case` по очереди. Совпавшая ветка делает `return`, остальные не выполняются. `default` забирает числа, которым нет отдельной ветки. Ветки для `0`, `3` и `4` устроены так же: у каждой свой текст.

## Сеанс

Несколько чисел подряд — это уже сеанс. Его обрывает код `0`.

```go
for _, code := range codes {
	if code == 0 {
		break
	}
}
```

`break` выходит из цикла. Команды после нуля не смотрят. Сам ноль в список действий не добавляют: это сигнал остановки, а не имя команды. Если нуля в срезе нет, проходят все коды.

Имена до нуля склеивают через пробел. Перед первым словом пробел не ставят.

```go
names := []string{"показать", "найти"}
text := ""
for i, name := range names {
	if i > 0 {
		text += " "
	}
	text += name
}
```

`i > 0` истинно со второго имени. Перед ним ставят пробел. Из этих двух имён получится `"показать найти"`.

## Что запомнить

- Число команды переводится в имя действия через `switch`.
- Незнакомое число даёт текст `"неизвестно"`.
- Ноль останавливает сеанс и сам в список имён не входит.
- Имена команд до нуля идут через пробел.
