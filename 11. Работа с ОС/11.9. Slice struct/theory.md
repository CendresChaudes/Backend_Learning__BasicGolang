# 11.9. Slice struct

Один пароль — один struct: имя записи и секрет. Несколько паролей — срез таких struct. Тип среза пишут `[]Entry`: квадратные скобки без длины, затем имя struct.

```go
type Entry struct {
	Name   string
	Secret string
}

list := []Entry{
	{Name: "mail", Secret: "a"},
	{Name: "vpn", Secret: "b"},
}
```

`list` содержит два значения `Entry`. Длину даёт `len(list)`. Она равна `2`.

## Последний элемент

Последний элемент стоит на индексе `len(list)-1`. Индексы начинаются с нуля, поэтому последний на единицу меньше длины.

```go
last := list[len(list)-1]
```

`last.Name` равен `"vpn"`. У пустого среза длины `0` такого индекса нет, последний элемент читают только когда `len(list)` больше нуля.

## append

Новую запись добавляют через `append`. Функция возвращает срез, его записывают обратно в переменную.

```go
list = append(list, Entry{Name: "bank", Secret: "c"})
```

После этого длина равна `3`, последний элемент — `"bank"`.

## Подсчёт

Число записей с одним именем считают циклом:

```go
count := 0
for _, item := range list {
	if item.Name == "mail" {
		count++
	}
}
```

`range` по срезу struct отдаёт индекс и копию элемента. Индекс здесь не нужен, на его месте `_`. `item.Name` — поле копии. Каждое совпадение увеличивает `count` на один.

## Что запомнить

- Срез struct имеет тип `[]Entry`.
- Последний элемент: `list[len(list)-1]`, если срез не пустой.
- `append` возвращает срез, результат нужно присвоить.
- `range` обходит записи, поле читают через точку.
