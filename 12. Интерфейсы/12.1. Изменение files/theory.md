# 12.1. Изменение files

В прошлых уроках имя файла стояло аргументом у каждой функции. Запись и проверка смотрели на это имя снаружи. Сейчас устройство меняется: имя живёт внутри типа, а действие становится методом.

Метод — функция, привязанная к типу. Её вызывают у значения через точку. Тип и метод пишут на уровне пакета, рядом с `main`, а не внутри другой функции.

## Тип хранит имя

`FileBox` — коробка с одним полем. Поле `Name` — имя файла на диске.

```go
type FileBox struct {
	Name string
}

func (b FileBox) Title() string {
	return b.Name
}
```

`type FileBox struct` описывает тип. `Name string` — поле, строка.

`(b FileBox)` — получатель метода. `b` внутри метода — копия той коробки, у которой метод вызвали. `Title` возвращает поле `Name`.

```go
box := FileBox{Name: "notes.txt"}
text := box.Title()
```

`FileBox{Name: "notes.txt"}` собирает значение. `box.Title()` вызывает метод. В `text` попадает `"notes.txt"`. Имя больше не передают отдельным аргументом: оно уже лежит в `box`.

## Метод собирает подпись

Подпись файла можно собрать из поля. Снаружи передают только коробку.

```go
func (b FileBox) Mark() string {
	return "file " + b.Name
}
```

`b.Name` читает имя. Сложение строк склеивает `"file "` и это имя. Для `"notes.txt"` метод вернёт `"file notes.txt"`.

Вызов тот же: `box.Mark()`.

## Пустое имя

Пустое имя значит, что коробка ещё не готова к записи. Проверку тоже кладут в метод.

```go
func (b FileBox) Ready() bool {
	return b.Name != ""
}
```

`b.Name != ""` истинно, когда в поле есть текст. Для `"notes.txt"` метод вернёт `true`. Для `""` вернёт `false`.

Дальше программа говорит с `FileBox`, а не с голой строкой пути. Когда появится второй способ хранения, у него будут свои методы, а вызовы останутся похожими.

## Что запомнить

- Имя файла лежит в поле struct. Действие с этим именем — метод.
- Тип и метод пишут на уровне пакета.
- Вызов выглядит так: `box.Title()`. Получатель — копия значения.
- Пустое `Name` — коробка не готова. Это проверяет метод.

## Что сделать

Заполни `tasks.go`. Тип `FileBox` опиши на уровне пакета. Запуск: `go run .`. Проверка: `go test .`.
