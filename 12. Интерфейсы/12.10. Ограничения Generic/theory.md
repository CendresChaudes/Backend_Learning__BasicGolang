# 12.10. Ограничения Generic

Ограничение — правило для параметра типа. Оно стоит в квадратных скобках вместо широкого `any` и говорит, какие операции с `T` разрешены.

`any` почти ничего не разрешает. Два значения `T` нельзя сравнить через `==` и нельзя сложить через `+`, пока ограничение этого не позволит.

## comparable

`comparable` — готовое ограничение. Типы под ним сравнивают через `==` и `!=`. Строка и `int` подходят. Срез не подходит: срезы через `==` не сравнивают.

```go
func Same[T comparable](a, b T) bool {
	return a == b
}
```

`Same("go", "go")` вернёт `true`. `Same(1, 2)` вернёт `false`. Оба вызова законны, потому что `string` и `int` входят в `comparable`.

## Список типов

Свой интерфейс может перечислить конкретные типы через `|`. Такая запись называется объединение. `T` будет одним из них.

```go
type Number interface {
	int | int64
}

func Add[T Number](a, b T) T {
	return a + b
}
```

`int | int64` значит: `T` — либо `int`, либо `int64`. У обоих есть `+`, поэтому `a + b` компилируется. `Add(2, 5)` подставляет `int` и возвращает `7`.

Строку в `Add` передать нельзя. `string` в списке `Number` нет.

## Сравнение больше и меньше

`>` тоже должно быть разрешено ограничением. У `int` и у `string` такое сравнение есть. Их объединяют в отдельный интерфейс.

```go
type Ordered interface {
	int | string
}

func Larger[T Ordered](a, b T) T {
	if a > b {
		return a
	}
	return b
}
```

`Larger` возвращает то значение, которое больше. `Larger(3, 9)` вернёт `9`. Для строк сравнение идёт по буквам: `Larger("disk", "cloud")` вернёт `"disk"`, потому что `"disk"` больше `"cloud"`.

## Что запомнить

- Ограничение пишут в квадратных скобках. Оно решает, что можно делать с `T`.
- `comparable` разрешает `==` и `!=`.
- `int | int64` внутри `interface` — свой список типов. Для них доступен `+`.
- `>` пишут, когда каждый тип в списке это сравнение поддерживает.
