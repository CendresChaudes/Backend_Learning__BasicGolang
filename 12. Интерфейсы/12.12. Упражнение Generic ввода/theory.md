# 12.12. Упражнение Generic ввода

Меню из главы про файлы принимало код команды числом: `0` — выход, `1` — показать, `2` — добавить, `3` — найти, `4` — удалить. Имена тех же команд — строки: `"выход"`, `"показать"`, `"добавить"`, `"найти"`, `"удалить"`.

Проверка ответа не должна быть написана дважды. Generic-функция с ограничением `comparable` принимает и срез чисел, и срез строк. `comparable` разрешает `==`.

## Индекс ответа

```go
func Index[T comparable](items []T, answer T) int {
	for i, item := range items {
		if item == answer {
			return i
		}
	}
	return -1
}
```

Цикл сравнивает каждый элемент с `answer`. Первое совпадение возвращает индекс `i` и выходит из функции. Если цикл закончился сам, ответа в списке нет. Для отсутствия берут `-1`: такого индекса в срезе не бывает. Ноль уже занят первым элементом.

`Index([]int{0, 1, 2, 3, 4}, 2)` вернёт `2`. `Index([]int{0, 1, 2}, 9)` вернёт `-1`.

## Ответ из списка

```go
func Allowed[T comparable](items []T, answer T) bool {
	for _, item := range items {
		if item == answer {
			return true
		}
	}
	return false
}
```

Индекс здесь не нужен, на его месте `_`. Нашли элемент — сразу `true`. Дошли до конца — `false`.

Для имён команд список такой:

```go
names := []string{"выход", "показать", "добавить", "найти", "удалить"}
```

`Allowed(names, "добавить")` вернёт `true`. `Allowed(names, "нет")` вернёт `false`.

## Короткая подпись

Подпись для меню — строка. Есть ответ в списке — `"ok"`. Нет — `"нет"`.

```go
func Code[T comparable](items []T, answer T) string {
	if Allowed(items, answer) {
		return "ok"
	}
	return "нет"
}
```

`Code` пользуется уже написанной `Allowed`. Для `"найти"` результат `"ok"`. Для слова вне списка результат `"нет"`. Одна пара функций обслуживает и коды `int`, и имена `string`.

## Что запомнить

- Список допустимых ответов проверяют одной generic-функцией.
- Ограничение `comparable` нужно, чтобы сравнивать элемент и ответ через `==`.
- Нет совпадения у индекса — это `-1`. У проверки «есть в списке» — это `false`.
- Подпись меню: `"ok"`, если ответ найден, и `"нет"`, если нет.

## Что сделать

Это упражнение. Функции `Index`, `Allowed` и `Code` опиши на уровне пакета и вызови их из заданий. Запуск: `go run .`. Проверка: `go test .`.
