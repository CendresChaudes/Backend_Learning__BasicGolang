# 12.2. Any и типы

`any` — пустой интерфейс. В его списке нет ни одного метода. Любой тип подходит: методов у значения всегда не меньше, чем ноль. В переменную типа `any` кладут строку, число и другие значения.

Старое имя того же типа — `interface{}`. В новом коде пишут `any`.

```go
var box any
box = "vault"
box = 7
```

Внутри `box` лежит конкретное значение, но через тип `any` его методы и операции недоступны. Чтобы снова получить строку или число, тип спрашивают явно.

## Type switch

Type switch смотрит на тип значения внутри `any`. Ветки — это типы.

```go
func kind(v any) string {
	switch v.(type) {
	case string:
		return "string"
	case int:
		return "int"
	default:
		return "other"
	}
}
```

`v.(type)` пишут только внутри такого `switch`.

## Один тип

Проверка одного типа называется type assertion. Пишут точку и тип в скобках.

```go
text, ok := v.(string)
```

Если внутри строка, `ok` равен `true`, а `text` — эта строка. Если тип другой, `ok` равен `false`, а `text` — нулевое значение. Форма без `ok` при несовпадении типа останавливает программу. В обычной проверке берут форму с `ok`.

## Что запомнить

- `any` принимает значение любого типа.
- Type switch разбирает несколько возможных типов.
- `v.(string)` с `ok` достаёт один тип и не роняет программу, если тип другой.
