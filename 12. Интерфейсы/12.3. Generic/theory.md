# 12.3. Generic

Generic — функция или тип с параметром типа. Один текст работает для строки, числа и других типов. Конкретный тип подставляется в месте вызова.

Параметр типа пишут в квадратных скобках перед обычными аргументами. Имя чаще всего `T`.

```go
func Echo[T any](v T) T {
	return v
}
```

`Echo("vault")` возвращает строку. `Echo(7)` возвращает число. `any` здесь значит: подойдёт любой тип. Складывать два `T` или сравнивать их через `==` при ограничении `any` нельзя: компилятор не знает, умеет ли конкретный тип эту операцию.

## Ограничение

Ограничение — правило для параметра типа. Оно стоит в квадратных скобках вместо широкого `any`.

`comparable` — готовое ограничение. Типы под ним сравнивают через `==` и `!=`. Строка и `int` подходят. Срез не подходит: срезы через `==` не сравнивают.

```go
func Same[T comparable](a, b T) bool {
	return a == b
}
```

## Generic struct

Struct тоже может иметь параметр типа. Поле хранит значение этого типа.

```go
type Box[T any] struct {
	Value T
}
```

`Box[int]{Value: 7}` — коробка с числом. `Box[string]{Value: "a"}` — коробка со строкой. Конкретный тип пишут при создании значения.

## Что запомнить

- `[T any]` — параметр типа. Конкретный тип выбирают в вызове.
- Ограничение говорит, какие операции с `T` разрешены.
- `comparable` разрешает `==`. Generic struct хранит значение типа `T`.
