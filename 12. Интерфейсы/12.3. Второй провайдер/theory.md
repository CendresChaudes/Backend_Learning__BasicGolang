# 12.3. Второй провайдер

Провайдер — тип, который даёт услугу. Здесь услуга — назвать место, где лежит файл. Первый провайдер пишет на диск. Второй отвечает за облако. У каждого своё имя типа и свой метод.

## Диск

```go
type Disk struct {
	Name string
}

func (d Disk) Label() string {
	return "disk:" + d.Name
}
```

`Disk` хранит имя файла. `Label` склеивает приставку `"disk:"` и это имя. Для `"vault"` получится `"disk:vault"`. Приставка показывает, какой провайдер ответил.

## Облако

```go
type Cloud struct {
	Name string
}

func (c Cloud) Label() string {
	return "cloud:" + c.Name
}
```

`Cloud` — второй тип с тем же полем `Name`. Метод тоже называется `Label`, но приставка другая. Для `"vault"` получится `"cloud:vault"`.

Вызов у каждого свой:

```go
disk := Disk{Name: "vault"}
cloud := Cloud{Name: "vault"}
fmt.Println(disk.Label())
fmt.Println(cloud.Label())
```

`disk.Label()` вернёт `"disk:vault"`. `cloud.Label()` вернёт `"cloud:vault"`. Имена методов совпали, типы остались разными.

Функция, которая принимает `Disk`, не примет `Cloud`. Для компилятора это два разных аргумента. В следующем уроке общий список методов станет интерфейсом, и одна функция сможет принять оба провайдера.

## Что запомнить

- Провайдер — тип, который оказывает одну услугу. Здесь это подпись места файла.
- `Disk` и `Cloud` — два таких типа. У обоих есть метод `Label`.
- Приставка в ответе показывает, какой провайдер сработал.
- Общая функция для обоих типов появится вместе с интерфейсом.

## Что сделать

Заполни `tasks.go`. Оба типа опиши на уровне пакета. Запуск: `go run .`. Проверка: `go test .`.
