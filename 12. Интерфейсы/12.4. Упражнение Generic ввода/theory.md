# 12.4. Упражнение Generic ввода

Меню принимало код команды числом и то же меню может принять имя команды строкой. Проверка «есть ли ответ в списке» не должна быть написана дважды.

Generic-функция с ограничением `comparable` принимает и срез чисел, и срез строк. `comparable` разрешает `==`.

## Индекс ответа

```go
func Index[T comparable](items []T, answer T) int {
	for i, item := range items {
		if item == answer {
			return i
		}
	}
	return -1
}
```

`Index([]int{0, 1, 2}, 2)` вернёт `2`. `Index` по строкам команд найдёт `"добавить"`. Если ответа в списке нет, результат `-1`.

Та же проверка в виде `bool` отвечает, разрешён ли ответ. Третья функция может вернуть `"ok"` или `"нет"`, вызвав уже написанную проверку.

## Что запомнить

- Один generic с `comparable` ищет значение и в `[]int`, и в `[]string`.
- Сравнение внутри — обычный `==`.
- Нет совпадения — индекс `-1`.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
