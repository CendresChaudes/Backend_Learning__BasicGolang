# 12.6. Any тип

`any` — пустой интерфейс. В его списке нет ни одного метода. Любой тип подходит: методов у значения всегда не меньше, чем ноль. В переменную типа `any` кладут строку, число, struct или другое значение.

Старое имя того же типа — `interface{}`. В новом коде пишут `any`. Смысл один.

## Что можно положить

```go
var box any
box = "vault"
box = 7
```

`var box any` создаёт переменную. Сначала в ней `nil`: значения нет. `box = "vault"` кладёт строку. `box = 7` кладёт число на то же место. Тип переменной остаётся `any`, внутри по очереди лежат разные значения.

## Функция принимает any

```go
import "fmt"

func show(v any) string {
	return fmt.Sprint(v)
}
```

`fmt.Sprint` собирает текст из значения. Для строки `"vault"` текст тот же: `"vault"`. Для числа `7` текст будет `"7"`. Функция `show` не смотрит, какой тип пришёл. Печать умеет работать с `any`.

```go
fmt.Println(show("vault"))
fmt.Println(show(7))
```

Первая строка выведет `vault`. Вторая выведет `7`.

## nil и поля

```go
func present(v any) bool {
	return v != nil
}
```

`v != nil` истинно, когда в `any` что-то положили. `present("vault")` вернёт `true`. `present(nil)` вернёт `false`.

Поле через точку у `any` не прочитать. У пустого интерфейса нет полей и нет своих методов. Достать исходный тип обратно можно проверкой типа. Это следующие уроки.

## Что запомнить

- `any` — интерфейс без методов. В него помещается значение любого типа.
- `interface{}` — старое написание того же типа.
- `fmt.Sprint` превращает значение внутри `any` в текст.
- `nil` значит, что значения нет. Поля у `any` нет.
