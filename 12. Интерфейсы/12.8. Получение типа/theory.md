# 12.8. Получение типа

Получение типа — проверка, что внутри `any` лежит одно конкретное значение, и чтение этого значения. В Go это называют type assertion. Пишут точку и тип в скобках: `box.(string)`.

Type switch из прошлого урока перебирает несколько типов. Здесь спрашивают один.

## Форма с ok

```go
func asText(v any) string {
	text, ok := v.(string)
	if ok {
		return text
	}
	return ""
}
```

`v.(string)` проверяет, строка ли внутри. Результата два. `text` — сама строка, если проверка прошла. `ok` имеет тип `bool`: `true`, когда внутри была строка.

`asText("vault")` вернёт `"vault"`. `ok` при этом `true`.

Если внутри число, проверка не проходит. `ok` равен `false`, а `text` — пустая строка, нулевое значение для `string`. Функция возвращает `""`.

То же для числа:

```go
func asInt(v any) int {
	n, ok := v.(int)
	if ok {
		return n
	}
	return 0
}
```

`asInt(8)` вернёт `8`. `asInt("vault")` вернёт `0`: внутри была строка, не `int`.

## Одна величина

Скобкам можно оставить один результат:

```go
text := v.(string)
```

Если внутри и правда строка, `text` её получит. Если тип другой, программа останавливается: это panic, аварийный выход. Для значения, которое пришло снаружи, бери два результата и смотри на `ok`.

Проверка без самого текста выглядит так:

```go
func textOK(v any) bool {
	_, ok := v.(string)
	return ok
}
```

`_` занимает место строки: текст здесь не нужен. Наружу уходит только `ok`. `textOK("go")` вернёт `true`. `textOK(1)` вернёт `false`.

## Что запомнить

- `value, ok := box.(Type)` достаёт значение одного типа из `any`.
- `ok` равен `true`, когда тип совпал. Иначе значение — нулевое для этого типа.
- Форма без `ok` останавливает программу, если тип другой.
- `_` ставят, когда само значение не нужно, а нужен только `ok`.
