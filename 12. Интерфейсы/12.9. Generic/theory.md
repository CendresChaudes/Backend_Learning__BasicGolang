# 12.9. Generic

Generic — функция с параметром типа. Один текст функции работает для строки, числа и других типов. Конкретный тип подставляется в месте вызова.

Параметр типа пишут в квадратных скобках перед обычными аргументами. Имя чаще всего `T`.

## Одно значение

```go
func Echo[T any](v T) T {
	return v
}
```

`[T any]` — параметр типа. `any` здесь ограничивает `T`: подходит любой тип. `v T` — аргумент этого типа. Результат тоже `T`.

```go
word := Echo("vault")
n := Echo(3)
```

`Echo("vault")` подставляет вместо `T` тип `string`. В `word` строка `"vault"`. `Echo(3)` подставляет `int`. В `n` число `3`. Тело функции в обоих вызовах одно: `return v`.

Компилятор проверяет каждый вызов отдельно. Смешать типы в одном вызове нельзя: `Echo` ждёт один `T`.

## Срез

```go
func Count[T any](items []T) int {
	return len(items)
}
```

`[]T` — срез элементов типа `T`. `len` считает элементы и не смотрит на их тип, поэтому ограничение `any` здесь подходит.

```go
fmt.Println(Count([]string{"a", "b"}))
fmt.Println(Count([]int{1, 2, 3}))
```

Первый вызов вернёт `2`. Второй вернёт `3`.

Пустой срез тоже корректен. Проверка «есть элементы» выглядит так:

```go
func HasItem[T any](items []T) bool {
	return len(items) > 0
}
```

`HasItem([]int{7})` вернёт `true`. `HasItem([]int{})` вернёт `false`.

При ограничении `any` у значения `T` нельзя вызвать свой метод и нельзя сложить два `T` через `+`. Для `len` и простого возврата этого ограничения хватает. Более узкие ограничения — в следующем уроке.

## Что запомнить

- Параметр типа пишут в квадратных скобках: `func Echo[T any](v T) T`.
- `any` в скобках значит: `T` может быть любым типом.
- Вызов подставляет тип сам: `Echo("vault")` — это `T` как `string`.
- `[]T` — срез таких элементов. `len` от типа элемента не зависит.
