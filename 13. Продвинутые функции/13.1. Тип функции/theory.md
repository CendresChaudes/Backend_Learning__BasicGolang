# 13.1. Тип функции

У функции есть тип, как у числа и у строки. Тип функции — это список аргументов и тип результата. Имя функции в тип не входит.

## Сигнатура

Сигнатура — краткая запись этого типа.

```go
func double(n int) int {
	return n * 2
}
```

`double` принимает один `int` и возвращает `int`. Её тип пишут так: `func(int) int`.

Две функции с одинаковыми аргументами и одинаковым результатом имеют один тип. Функция `func(int) string` — уже другой тип: результат строка, а не число.

## Имя для типа

Длинную сигнатуру можно назвать один раз через `type`.

```go
type IntOp func(int) int
```

`type` создаёт новое имя типа. `IntOp` означает «функция с одним аргументом `int` и результатом `int`».

Переменная такого типа хранит функцию.

```go
var op IntOp = double
result := op(4)
```

`double` написан без скобок. Так в переменную попадает сама функция. `op(4)` вызывает то, что сейчас лежит в `op`. Здесь это `double`, поэтому в `result` будет `8`.

В ту же переменную можно положить другую функцию той же сигнатуры.

```go
func triple(n int) int {
	return n * 3
}

op = triple
```

`op(4)` теперь вернёт `12`. Тип переменной прежний: `func(int) int`.

## Тип прямо у переменной

Отдельное имя через `type` не обязательно. Сигнатуру пишут прямо у переменной.

```go
var format func(string) string
```

`format` принимает строку и возвращает строку.

Пока в переменную ничего не записали, в ней нулевое значение. Для типа функции это `nil`: функции нет. Вызов такой переменной останавливает программу. Сначала записывают функцию, потом вызывают.

```go
func vaultLabel(name string) string {
	return "vault:" + name
}

format = vaultLabel
text := format("mail")
```

В `text` будет `"vault:mail"`.

## Что запомнить

- Тип функции — аргументы и результат: `func(int) int`.
- `type IntOp func(int) int` даёт этому типу короткое имя.
- В переменную кладут функцию без скобок: `op = double`.
- Вызов пишут у переменной: `op(4)`. Пустую переменную вызывать нельзя, в ней `nil`.
