# 13.1. Функции как значения

У функции есть тип, как у числа и у строки. Тип функции — список аргументов и тип результата. Имя функции в тип не входит. Такую запись называют сигнатурой.

```go
func double(n int) int {
	return n * 2
}
```

Тип `double` — `func(int) int`. Функцию кладут в переменную того же типа:

```go
var op func(int) int
op = double
result := op(4)
```

`result` равен `8`. Вызов идёт через переменную, не через исходное имя.

## Аргумент

Функцию можно передать в другую функцию. Та, которая принимает, вызывает её в нужный момент.

```go
func apply(n int, op func(int) int) int {
	return op(n)
}
```

`apply(3, double)` вернёт `6`. Одна и та же `apply` работает с разной работой внутри: удвоить, прибавить единицу, взять модуль.

## Функция без имени

Анонимная функция — функция без имени. Её пишут там, где она нужна: в переменную или сразу аргументом.

```go
apply(3, func(n int) int {
	return n + 1
})
```

После `func` имя не пишут. Сразу идут аргументы. Именованная функция живёт на уровне пакета. Анонимная видна только в том месте, где её записали.

## Что запомнить

- Тип функции — это аргументы и результат, без имени.
- Функцию передают аргументом и кладут в переменную.
- Анонимную функцию пишут на месте, без имени.
