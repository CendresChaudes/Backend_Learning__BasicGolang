# 13.2. Передача функции

Функцию можно передать в другую функцию аргументом. Та, которая принимает, вызывает её в нужный момент. Одна и та же обёртка работает с разной работой внутри.

## Аргумент-функция

Тип параметра может быть типом функции.

```go
func apply(n int, op func(int) int) int {
	return op(n)
}
```

`n` — обычное число. `op` — функция: принимает `int` и возвращает `int`. Внутри `apply` её вызывают как любую другую: `op(n)`.

```go
func double(n int) int {
	return n * 2
}

result := apply(5, double)
```

Вторым аргументом написано `double` без скобок. В `apply` уходит сама функция. Скобки `double(5)` запустили бы её сразу, и вторым аргументом стало бы число `10`. Параметр `op` ждёт функцию, поэтому скобок при передаче нет.

Дальше `apply` выполняет `op(5)`. Это вызов `double(5)`. В `result` будет `10`.

## Две проверки

Параметров-функций может быть несколько. Одинаковый тип записывают один раз.

```go
func both(login string, a, b func(string) bool) bool {
	return a(login) && b(login)
}
```

`a, b func(string) bool` — две функции. Каждая принимает строку и возвращает `bool`. `&&` значит «и»: общий результат `true`, когда оба вызова вернули `true`.

```go
func isAdmin(login string) bool {
	return login == "admin"
}

func longEnough(login string) bool {
	return len(login) > 3
}
```

`both("admin", isAdmin, longEnough)` вызывает обе проверки с одной строкой `"admin"`. Логин совпал, длина `5` больше трёх. Результат `true`.

Так проверка логина собирается из маленьких функций. Обёртка `both` не знает, что именно они сравнивают. Она только вызывает то, что ей передали.

## Что запомнить

- Параметр может иметь тип функции: `op func(int) int`.
- Передают имя без скобок: `apply(5, double)`.
- Внутри обёртки функцию вызывают обычным вызовом: `op(n)`.
- Несколько параметров одного типа пишут так: `a, b func(string) bool`.
