# 13.3. Variadic

Обычная функция ждёт заранее известное число аргументов. Два параметра — два значения в вызове.

Динамическое число значит другое: значений одного типа может быть сколько угодно, в том числе ноль. Такой параметр называют variadic — параметр переменной длины.

## Три точки

Перед типом последнего параметра пишут `...`. Внутри функции эти аргументы лежат в срезе.

```go
func total(nums ...int) int {
	sum := 0
	for _, n := range nums {
		sum = sum + n
	}
	return sum
}
```

`total(1, 2, 3)` равно `6`. `total()` без аргументов равно `0`: срез пустой.

Готовый срез передают в такой параметр, раскрыв его тремя точками:

```go
nums := []int{1, 2, 3}
sum := total(nums...)
```

`nums...` превращает срез в отдельные аргументы. Три точки в параметре собирают аргументы в срез. Три точки в вызове делают обратное.

Variadic-параметр может быть только последним.

## Что запомнить

- `...T` в конце параметров собирает сколько угодно значений типа `T` в срез.
- Вызов без этих аргументов даёт пустой срез.
- Готовый срез раскрывают в вызове через `name...`.
