# 13.3. Анонимные функции

Анонимная функция — функция без имени. Её пишут там, где она нужна: кладут в переменную или сразу передают аргументом.

Именованная функция живёт на уровне пакета и видна по имени. Анонимная видна только в том месте, где её записали.

## Функция в переменной

После `func` имя не пишут. Сразу идут аргументы.

```go
double := func(n int) int {
	return n * 2
}
```

Тип у `double` получается `func(int) int`. Вызов обычный.

```go
result := double(4)
```

В `result` будет `8`. Отдельного имени `double` снаружи этой переменной нет.

## Сразу аргументом

Если функция нужна один раз, переменную можно не заводить. Анонимную функцию пишут прямо в вызове.

```go
func apply(n int, op func(int) int) int {
	return op(n)
}

result := apply(4, func(n int) int {
	return n * 2
})
```

`apply` ждёт вторым аргументом `func(int) int`. Ему передают функцию без имени. Внутри `apply` сработает `op(4)`. В `result` будет `8`.

Так поступают с короткой проверкой или подписью, которую больше нигде не вызывают.

## Вызов на месте

Скобки сразу после тела вызывают функцию в этой же записи.

```go
text := func(name string) string {
	return "login:" + name
}("root")
```

Сначала описана функция: аргумент `name`, результат — строка `"login:"` и это имя. Затем `("root")` передаёт аргумент и запускает её. В `text` будет `"login:root"`.

Без последних скобок это была бы сама функция, а не строка. Скобки после `}` превращают запись в вызов.

## Что запомнить

- Анонимная функция — `func` без имени перед аргументами.
- Её можно записать в переменную и вызвать по этой переменной.
- Её можно передать аргументом сразу в вызове.
- Скобки сразу после `}` вызывают функцию на месте.
