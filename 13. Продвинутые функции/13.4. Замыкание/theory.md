# 13.4. Замыкание

Замыкание (closure) — функция, которая пользуется переменной внешней функции. Эта переменная остаётся с ней и после того, как внешняя функция уже закончилась.

## Функция возвращает функцию

Результат функции может быть другой функцией. Тип результата тогда выглядит как сигнатура: `func(string) string`.

```go
func withPrefix(prefix string) func(string) string {
	return func(name string) string {
		return prefix + name
	}
}
```

`withPrefix("id:")` возвращает функцию. Эта функция помнит `prefix`. Вызов `withPrefix("id:")("7")` даёт `"id:7"`.

Счётчик устроен так же. Внешняя функция создаёт переменную `n`. Внутренняя при каждом вызове увеличивает её и возвращает новое значение.

```go
func counter() func() int {
	n := 0
	return func() int {
		n = n + 1
		return n
	}
}
```

Два вызова одной и той же возвращённой функции дадут `1`, затем `2`. Новая функция из нового вызова `counter()` начинает снова с нуля: у неё своя переменная `n`.

## Что запомнить

- Внутренняя функция видит переменные внешней и хранит их после возврата.
- Тип результата `func(...) ...` — это тоже функция.
- Каждый вызов внешней функции создаёт свои переменные для своего замыкания.
