# 13.5. Динамическое число аргументов

Обычная функция ждёт заранее известное число аргументов. Два параметра — два значения в вызове.

Динамическое число значит другое: значений одного типа может быть сколько угодно. Ноль тоже подходит. Такой параметр называют variadic — параметр переменной длины.

## Три точки

Перед типом последнего параметра пишут `...`.

```go
func total(nums ...int) int {
	sum := 0
	for _, n := range nums {
		sum += n
	}
	return sum
}
```

`nums ...int` собирает переданные числа. Внутри функции `nums` — обычный срез `[]int`. Его обходят циклом `range`. `len(nums)` показывает, сколько чисел пришло.

```go
total(10, 20, 12)
total()
```

Первый вызов передаёт три числа. Сумма равна `42`. Второй вызов не передаёт ничего. Срез пустой, сумма равна `0`.

`...` стоит только у последнего параметра. Перед ним могут быть обычные параметры, их число фиксировано.

```go
func line(prefix string, parts ...string) string {
	text := prefix
	for _, part := range parts {
		text += part
	}
	return text
}
```

`prefix` обязателен, он один. `parts` забирает все строки после него.

`line("user:", "an", "na")` начинает с `"user:"` и дописывает `"an"`, затем `"na"`. Результат — `"user:anna"`.

## Срез в вызов

Готовый срез передают с `...` после имени переменной. Элементы среза становятся отдельными аргументами.

```go
items := []int{10, 20, 12}
total(items...)
```

`items...` раскрывает срез. Вызов совпадает с `total(10, 20, 12)`.

`total` ждёт отдельные числа `int`. Срез без трёх точек в этот параметр не подходит. Три точки ставят в том месте, где срез нужно разложить по аргументам.

## Что запомнить

- `nums ...int` принимает сколько угодно чисел `int`, включая ноль.
- Внутри функции это срез `[]int`.
- `...` пишут только у последнего параметра.
- Готовый срез передают так: `items...`.
