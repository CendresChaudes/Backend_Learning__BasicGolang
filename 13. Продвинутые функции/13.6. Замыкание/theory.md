# 13.6. Замыкание

Замыкание (closure) — функция, которая пользуется переменной внешней функции. Эта переменная остаётся с ней и после того, как внешняя функция уже закончилась.

## Функция возвращает функцию

Результат функции может быть другой функцией. Тип результата тогда выглядит как сигнатура: `func(string) string`.

```go
func withPrefix(prefix string) func(string) string {
	return func(name string) string {
		return prefix + name
	}
}
```

`withPrefix` принимает строку `prefix`. Она возвращает анонимную функцию. У той свой аргумент `name`. Строку `prefix` она берёт снаружи: своего параметра с таким именем у неё нет.

Функция вместе с запомненной внешней переменной и есть замыкание.

```go
vault := withPrefix("vault:")
text := vault("mail")
```

Вызов `withPrefix("vault:")` уже завершился. Переменная `prefix` со значением `"vault:"` живёт внутри `vault`. Следующая строка вызывает эту внутреннюю функцию с `"mail"`. В `text` будет `"vault:mail"`.

Новый вызов `withPrefix` создаёт другую функцию и другую переменную `prefix`.

```go
user := withPrefix("user:")
```

`user("anna")` вернёт `"user:anna"`. `vault` по-прежнему клеит `"vault:"`. У каждой возвращённой функции свой `prefix`.

## Счётчик помнит число

Внутренняя функция может менять внешнюю переменную. Следующий вызов увидит новое значение.

```go
func counter() func() int {
	n := 0
	return func() int {
		n = n + 1
		return n
	}
}
```

`n` объявлена в `counter` и начинается с нуля. Возвращённая функция прибавляет единицу и отдаёт новое `n`. Аргументов у неё нет: скобки пустые, `func() int`.

```go
next := counter()
next()
second := next()
```

Первый `next()` возвращает `1`. Второй возвращает `2`. Между вызовами `n` не создаётся заново. Замыкание продолжает с того значения, которое осталось.

Отдельный вызов `counter()` начинает новый счёт с нуля. Это уже другая переменная `n`.

## Что запомнить

- Функция может вернуть функцию. Тип результата пишут как `func(string) string`.
- Внутренняя функция читает переменные внешней. Вместе они образуют замыкание.
- После выхода из внешней функции эти переменные остаются у внутренней.
- Повторный вызов того же замыкания видит уже изменённое значение.
