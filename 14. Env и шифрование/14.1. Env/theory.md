# 14.1. Env

env — переменная окружения (environment variable). Это пара «имя и значение» снаружи программы. Её задают в системе или прямо в команде запуска. В коде секреты не записывают открытым текстом: их читают из окружения.

Ключ хранилища в этих уроках называется `VAULT_KEY`.

## os.Getenv

Пакет `os` читает переменные окружения. `os.Getenv` принимает имя и возвращает строку.

```go
port := os.Getenv("APP_PORT")
```

Если переменной нет, результат — пустая строка. Отличить «переменной нет» от «значение пустое» эта функция не умеет. Для учебного кода пустая строка значит: значения нет.

## Файл env

Переменные неудобно набирать в каждой команде. Их кладут в файл: одна строка — одно имя и значение. В папке урока он уже лежит и называется `app.env`.

```text
# учебный файл
VAULT_KEY=1234567890123456
APP_PORT=8080
APP_MODE=dev
```

Строка с `#` в начале — комментарий. `os.ReadFile` читает файл. Байты переводят в строку и режут по переносу.

```go
func envValue(text, key string) string {
	lines := strings.Split(text, "
")
	for _, line := range lines {
		line = strings.TrimSpace(line)
		if line == "" || strings.HasPrefix(line, "#") {
			continue
		}
		name, value, ok := strings.Cut(line, "=")
		if ok && name == key {
			return value
		}
	}
	return ""
}
```

`strings.Cut` делит строку по первому `=`. `ok` равен `true`, если знак был. Нет такого имени — функция возвращает пустую строку.

В настоящем проекте файл с ключом в git не кладут.

## Что запомнить

- `os.Getenv` читает переменную окружения по имени.
- Env-файл: строка `ИМЯ=значение`. Комментарий начинается с `#`.
- `strings.Cut` делит строку по первому `=`.
