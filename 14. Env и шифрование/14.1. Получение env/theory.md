# 14.1. Получение env

env — переменная окружения (environment variable). Это пара «имя и значение» снаружи программы. Её задают в системе или прямо в команде запуска. В коде секреты тогда не лежат: программа читает их в момент старта.

Ключ хранилища как раз такое значение. Его имя в уроках — `VAULT_KEY`.

## os.Getenv

Пакет `os` читает переменные окружения. `os.Getenv` принимает имя и возвращает строку.

```go
port := os.Getenv("APP_PORT")
```

Если перед запуском было `APP_PORT=8080`, в `port` попадёт `"8080"`. Если переменной нет, вернётся пустая строка.

Задать переменную только для одного запуска можно так:

```bash
APP_PORT=8080 go run .
```

После этой команды переменная в систему навсегда не записывается. Она есть только у этого запуска `go run`.

## Значение по умолчанию

Пустая строка значит: переменной не было или её задали пустой. Для режима приложения тогда берут запасное значение.

```go
mode := os.Getenv("APP_MODE")
if mode == "" {
	mode = "dev"
}
```

`mode == ""` — строка пустая. В `mode` записывают `"dev"`. Если в окружении было `APP_MODE=prod`, условие ложно и остаётся `"prod"`.

## os.LookupEnv

`os.LookupEnv` возвращает две величины: строку и `bool`.

```go
secret, ok := os.LookupEnv("VAULT_KEY")
```

`ok` равен `true`, когда переменная задана. Тогда секрет лежит в `secret`. `ok` равен `false`, когда имени `VAULT_KEY` в окружении нет.

Так отличают «переменную не задали» от «значение прочитали». Для ключа хранилища это важно: пустой ключ дальше в шифрование не пускают.

## Что запомнить

- env — значение снаружи программы. Его читают по имени.
- `os.Getenv("APP_PORT")` возвращает строку. Нет переменной — пустая строка.
- Пустую строку можно заменить запасным значением, например `"dev"`.
- `os.LookupEnv` вторым результатом `ok` сообщает, задана ли переменная.

## Что сделать

Заполни `tasks.go`. Запуск с переменной: `APP_PORT=8080 go run .`. Проверка: `go test .`.
