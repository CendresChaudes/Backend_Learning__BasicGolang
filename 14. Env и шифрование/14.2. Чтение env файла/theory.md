# 14.2. Чтение env файла

Переменные окружения неудобно набирать в каждой команде. Их кладут в файл: одна строка — одно имя и значение. Такой файл называют env-файлом.

В папке урока он уже лежит и называется `app.env`.

```text
# учебный файл
VAULT_KEY=1234567890123456
APP_PORT=8080
APP_MODE=dev
```

Строка с `#` в начале — комментарий. Её не читают как переменную. `VAULT_KEY=1234567890123456` значит: имя `VAULT_KEY`, значение `1234567890123456`. Это учебный ключ из 16 символов. В настоящем проекте такой файл в git не кладут: там будет настоящий ключ.

## Текст файла

`os.ReadFile` читает файл целиком. Байты переводят в строку.

```go
data, err := os.ReadFile("app.env")
if err != nil {
	return ""
}
text := string(data)
```

`text` содержит все строки файла, включая переносы.

## Одна переменная

Функция ищет имя и возвращает значение после `=`.

```go
func envValue(text, key string) string {
	lines := strings.Split(text, "\n")
	for _, line := range lines {
		line = strings.TrimSpace(line)
		if line == "" || strings.HasPrefix(line, "#") {
			continue
		}
		name, value, ok := strings.Cut(line, "=")
		if ok && name == key {
			return value
		}
	}
	return ""
}
```

`strings.Split(text, "\n")` режет текст по переносу строки. Получается срез строк.

`strings.TrimSpace` убирает пробелы по краям. Пустую строку пропускают. `strings.HasPrefix(line, "#")` — строка начинается с `#`. Это комментарий, его тоже пропускают. `continue` переходит к следующей строке цикла.

`strings.Cut(line, "=")` режет строку по первому `=`. Наружу выходят три значения: левая часть, правая часть и `ok`. `ok` равен `true`, если знак `=` в строке был.

Для строки `APP_PORT=8080` имя — `APP_PORT`, значение — `8080`. Когда `name` совпал с `key`, значение возвращают сразу. Если цикл закончился, такого имени нет. Результат — пустая строка.

```go
envValue(text, "APP_PORT")
```

Этот вызов вернёт `"8080"`.

## Что запомнить

- Env-файл: строка `ИМЯ=значение`. Комментарий начинается с `#`.
- Файл читают через `os.ReadFile` и переводят байты в строку.
- `strings.Cut` делит строку по первому `=`.
- Нет такого имени — функция возвращает пустую строку.

## Что сделать

Заполни `tasks.go`. Файл `app.env` лежит в этой папке. Запуск: `go run .`. Проверка: `go test .`.
