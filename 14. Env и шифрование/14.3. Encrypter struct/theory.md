# 14.3. Encrypter struct

Секрет хранилища шифруют одним и тем же ключом: и когда прячут, и когда открывают. Ключ удобно держать в struct, а не передавать отдельной строкой в каждый вызов.

AES — алгоритм шифрования из пакета `crypto/aes`. Ему подходит ключ длиной 16, 24 или 32 байта. Учебный ключ из цифр: один символ — один байт. Строка из 16 символов — это 16 байт.

## Struct и конструктор

```go
type Encrypter struct {
	Key string
}

func NewEncrypter(key string) Encrypter {
	return Encrypter{Key: key}
}
```

`Key` — строка ключа. `NewEncrypter` собирает значение и возвращает его. Ключ к этому моменту уже прочитан из env или из файла.

```go
enc := NewEncrypter("1234567890123456")
```

В `enc.Key` лежит `"1234567890123456"`. Длина этой строки — 16.

## Длина ключа

```go
func (e Encrypter) KeySize() int {
	return len(e.Key)
}
```

`KeySize` — метод. Получатель `e` — тот `Encrypter`, у которого метод вызвали. `len(e.Key)` считает байты ключа.

`NewEncrypter("1234567890123456").KeySize()` вернёт `16`.

## Имя режима

Длине ключа соответствует имя режима AES. 16 байт — это 128 бит, поэтому имя `"aes-128"`. 24 байта — `"aes-192"`. 32 байта — `"aes-256"`. Другая длина для AES не подходит, имя тогда пустое.

```go
func (e Encrypter) Mode() string {
	switch len(e.Key) {
	case 16:
		return "aes-128"
	case 24:
		return "aes-192"
	case 32:
		return "aes-256"
	default:
		return ""
	}
}
```

`switch` сравнивает `len(e.Key)` с числами 16, 24 и 32. Первая подошедшая ветка возвращает имя. `default` забирает все остальные длины.

```go
NewEncrypter("1234567890123456").Mode()
```

Этот вызов вернёт `"aes-128"`. Для ключа из 32 символов метод вернёт `"aes-256"`. Для короткой строки `"short"` вернёт пустую строку: шифровать таким ключом нельзя.

Само шифрование — в следующем уроке. Здесь struct только хранит ключ и умеет сказать, годится ли его длина.

## Что запомнить

- `Encrypter` хранит ключ в поле `Key`.
- `NewEncrypter(key)` собирает это значение.
- AES принимает ключ в 16, 24 или 32 байта.
- `Mode` возвращает `"aes-128"`, `"aes-192"` или `"aes-256"`. Иная длина — пустая строка.
