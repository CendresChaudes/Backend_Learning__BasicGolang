# 14.3. Упражнение Применение шифрования

Запись хранилища состоит из имени и секрета. В файл и в память после шифрования попадает не открытый пароль, а hex-строка.

```go
type Entry struct {
	Name   string
	Secret string
}
```

Ключ не пишут в коде. Его читают из переменной окружения `VAULT_KEY` через `os.Getenv`. Если ключа нет, шифровать нечем: функция возвращает пустую строку.

`Encrypter`, `NewEncrypter`, `Encrypt` и `Decrypt` те же, что в прошлом уроке. Nonce учебный и постоянный: `[]byte("0123456789ab")`.

Проверка хранилища выглядит так: зашифровать секрет, сразу расшифровать результат тем же ключом и убедиться, что открытый текст совпал.

## Что запомнить

- Ключ берут из `VAULT_KEY`, не из литерала в задании.
- В записи после шифрования лежит hex, не исходный пароль.
- Расшифровка тем же ключом возвращает секрет обратно.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
