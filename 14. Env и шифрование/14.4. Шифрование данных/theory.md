# 14.4. Шифрование данных

Шифрование прячет секрет так, чтобы без ключа его было не прочитать. Результат называют шифротекстом. В хранилище в файл попадает шифротекст, а не пароль открытым текстом.

В этом уроке шифр — AES в режиме GCM. AES берёт ключ из `Encrypter`. GCM — режим из пакета `crypto/cipher`: он шифрует байты и добавляет метку. Если шифротекст потом испортят, расшифровка это заметит.

## Nonce

Nonce — дополнительные 12 байт рядом с шифротекстом. Одним и тем же ключом нельзя шифровать два разных секрета с одним и тем же nonce.

В настоящем хранилище nonce каждый раз новый. Его берут из `crypto/rand`: пакет наполняет срез случайными байтами. Nonce сохраняют вместе с шифротекстом, иначе секрет потом не открыть.

В уроке nonce фиксированный: `[]byte("0123456789ab")`. Это 12 байт. Так строка результата не меняется от запуска к запуску, и тест может сверить её целиком. В свой проект этот постоянный nonce не переносят.

## Метод Encrypt

`Encrypter` тот же, что в прошлом уроке: поле `Key` и `NewEncrypter`. Метод возвращает строку и ошибку.

```go
func (e Encrypter) Encrypt(plain string) (string, error) {
	block, err := aes.NewCipher([]byte(e.Key))
	if err != nil {
		return "", err
	}
	gcm, err := cipher.NewGCM(block)
	if err != nil {
		return "", err
	}
	nonce := []byte("0123456789ab")
	sealed := gcm.Seal(nil, nonce, []byte(plain), nil)
	full := append(nonce, sealed...)
	return hex.EncodeToString(full), nil
}
```

`aes.NewCipher` готовит AES по ключу. Ключ переводят в байты: `[]byte(e.Key)`. Длина должна быть 16, 24 или 32 байта, иначе `err` не равен `nil`.

`cipher.NewGCM` включает режим GCM у этого AES.

`gcm.Seal` шифрует. Четыре аргумента такие:

- `nil` — куда сложить результат. `nil` значит: верни новый срез.
- `nonce` — 12 учебных байт.
- `[]byte(plain)` — секрет, который прячем.
- последний `nil` — дополнительные данные для метки. В этом уроке их нет.

`sealed` — зашифрованные байты и метка. Спереди к ним приписывают nonce: `append(nonce, sealed...)`. При расшифровке эти первые 12 байт снова станут nonce.

## Строка hex

В файл удобнее писать текст, а не сырые байты. Пакет `encoding/hex` переводит байты в шестнадцатеричную строку.

```go
enc := NewEncrypter("1234567890123456")
hidden, err := enc.Encrypt("vault")
```

Если `err` равен `nil`, в `hidden` будет такая строка:

```text
3031323334353637383961627d720c0df0d0d984191548689c68bd324d0c89e005
```

Начало `303132333435363738396162` — это nonce `"0123456789ab"`, записанный через hex. Дальше идёт сам шифротекст секрета `"vault"`. Открытого слова `vault` в строке нет.

Другой секрет с тем же ключом даёт другую строку. Ключ другой длины до `Seal` не дойдёт: `NewCipher` вернёт ошибку.

## Что запомнить

- `Encrypt` прячет строку и возвращает hex-текст и ошибку.
- Спереди шифротекста лежит nonce, 12 байт.
- Учебный nonce постоянный, чтобы результат можно было сверить.
- В настоящем хранилище nonce каждый раз новый, из `crypto/rand`, и его сохраняют вместе с шифротекстом.
