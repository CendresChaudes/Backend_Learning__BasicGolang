# 14.5. Расшифровка данных

Расшифровка — обратный шаг. На входе hex-строка из прошлого урока и тот же ключ. На выходе секрет, который шифровали.

Ключ внутри строки не лежит. Его снова передают через `Encrypter`. Первые 12 байт строки — nonce. Остальные байты — зашифрованный секрет и метка GCM.

## Метод Decrypt

```go
func (e Encrypter) Decrypt(encoded string) (string, error) {
	data, err := hex.DecodeString(encoded)
	if err != nil {
		return "", err
	}
	if len(data) < 12 {
		return "", errors.New("короткие данные")
	}
	block, err := aes.NewCipher([]byte(e.Key))
	if err != nil {
		return "", err
	}
	gcm, err := cipher.NewGCM(block)
	if err != nil {
		return "", err
	}
	nonce := data[:12]
	sealed := data[12:]
	plain, err := gcm.Open(nil, nonce, sealed, nil)
	if err != nil {
		return "", err
	}
	return string(plain), nil
}
```

`hex.DecodeString` переводит hex-текст обратно в байты. Если в строке попался посторонний символ, `err` не равен `nil`.

`len(data) < 12` значит: nonce целиком в данные не помещается. Дальше резать срез нельзя. `errors.New` создаёт ошибку с текстом `"короткие данные"`.

`data[:12]` — nonce, который при шифровании записали спереди. `data[12:]` — то, что вернул `Seal`.

`gcm.Open` проверяет метку и снимает шифр. Первый аргумент `nil` — верни новый срез с секретом. Последний `nil` — тех же дополнительных данных, что и при `Seal`, здесь нет.

Если ключ другой или байты шифротекста изменили, метка не сойдётся. `Open` вернёт ошибку, секрета в ответе не будет.

Удачный вызов отдаёт байты секрета. `string(plain)` делает из них строку.

## Тот же ключ

```go
enc := NewEncrypter("1234567890123456")
secret, err := enc.Decrypt("3031323334353637383961627d720c0df0d0d984191548689c68bd324d0c89e005")
```

Это шифротекст слова `"vault"` из прошлого урока. Ключ тот же, учебный. Если `err` равен `nil`, в `secret` будет `"vault"`.

Чужой ключ или обрезанная строка дают ошибку. Открытый текст тогда не возвращают.

## Что запомнить

- `Decrypt` принимает hex-строку и возвращает секрет и ошибку.
- Ключ должен быть тем же, каким строку зашифровали.
- Первые 12 байт — nonce, хвост отдаёт `gcm.Open`.
- Чужая метка, чужой ключ или слишком короткая строка — это ошибка, не секрет.
