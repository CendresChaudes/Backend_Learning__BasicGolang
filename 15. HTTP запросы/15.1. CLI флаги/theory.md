# 15.1. CLI флаги

Дальше будет клиент погоды: программа, которая сама спрашивает сервис и печатает одну строку. Город пользователь пишет при запуске, а не внутри кода. Такой аргумент с именем называется флаг. CLI — программа в терминале, от command line interface.

Запуск выглядит так:

```bash
go run . -city Moscow -units F
```

`-city` — имя флага. `Moscow` — его значение. `-units` — второй флаг.

## Набор флагов

Пакет `flag` разбирает аргументы. В тесте не трогают глобальные флаги программы: создают свой набор.

```go
fs := flag.NewFlagSet("weather", flag.ContinueOnError)
city := fs.String("city", "", "город")
err := fs.Parse([]string{"-city", "Moscow"})
```

`NewFlagSet` создаёт набор с именем `"weather"`. `ContinueOnError` значит: ошибка разбора вернётся из `Parse`, а не остановит программу.

`String` описывает флаг-строку. Второй аргумент — значение по умолчанию. Функция возвращает указатель: само значение читают через `*city`.

`Parse` разбирает срез строк так, как будто их передали при запуске. После успешного разбора `*city` равен `"Moscow"`. Если аргументов не было, остаётся значение по умолчанию.

## Что запомнить

- Флаг — именованный аргумент запуска.
- Свой `FlagSet` не мешает глобальным флагам.
- `String` возвращает указатель. Значение читают через `*`.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
