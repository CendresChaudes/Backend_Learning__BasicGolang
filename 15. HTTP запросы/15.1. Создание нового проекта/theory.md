# 15.1. Создание нового проекта

Дальше будет отдельная программа: клиент погоды. Клиент — программа, которая сама отправляет запросы. Сервис погоды — другая программа, она отвечает текстом.

У этого клиента своя папка и своё имя: `weather`.

## Модуль

Модуль — папка проекта с файлом `go.mod`. В файле записаны имя и версия Go. Так уже устроены прошлые уроки.

Новую программу начинают командой:

```bash
go mod init weather
```

`weather` — имя модуля. В `go.mod` появляются две строки:

```text
module weather

go 1.27.1
```

В папке урока `go.mod` уже лежит, чтобы работали `go run .` и `go test .`. Имя модуля в учебном файле другое: так названы папки курса. Имя программы, которое печатает клиент, остаётся `weather`.

## Адрес сервиса

Базовый адрес держат в константе. Константа (`const`) — имя, значение которого не меняют.

```go
const serviceURL = "https://api.weather.local/v1"
```

`serviceURL` — адрес без города. Город добавится позже, отдельным параметром. Пока это одна строка, к которой клиент будет дописывать запрос.

## Строка старта

Сети ещё нет. При запуске программа может показать имя и адрес.

```go
func startLine() string {
	return "weather " + serviceURL
}
```

`+` между строками склеивает их. Пробел после `weather` тоже часть текста. Результат: `weather https://api.weather.local/v1`.

`main` эту строку печатает через `fmt.Println`.

## Что запомнить

- Клиент `weather` — новая программа со своим модулем.
- Базовый адрес сервиса лежит в константе `serviceURL`.
- Строка старта — имя программы, пробел и этот адрес.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
