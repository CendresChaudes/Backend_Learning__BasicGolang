# 15.2. План проекта

Клиент `weather` делает одно дело. Пользователь называет город. Программа спрашивает сервис и печатает одну строку.

Порядок работы такой:

1. Прочитать город.
2. Собрать адрес запроса.
3. Отправить запрос.
4. Прочитать ответ.
5. Напечатать отчёт.

Флаги, адрес и сам запрос будут в следующих уроках. Сейчас нужны вид отчёта и проверка города.

## Отчёт

Отчёт — строка из города и текста погоды. Между ними двоеточие и пробел.

Данные удобно держать в struct. Struct — тип из нескольких полей.

```go
type Report struct {
	City string
	Text string
}

func (r Report) Line() string {
	return r.City + ": " + r.Text
}
```

По строкам:

- `City` — город, `Text` — текст погоды. Оба поля — строки.
- `(r Report)` — метод `Line` принадлежит `Report`. `r` — тот отчёт, у которого вызвали метод.
- `r.City + ": " + r.Text` склеивает три куска.

Для города `Moscow` и текста `ясно` метод вернёт `Moscow: ясно`.

## Градусы

Сервис может отдать температуру числом. В строку её кладут вместе с единицей.

```go
temp := fmt.Sprintf("%d C", 12)
```

`fmt.Sprintf` собирает строку и возвращает её. `%d` заменяется на целое число. В `temp` будет `12 C`.

## Город задан

Пустой город означает, что спрашивать сервис рано. Проверка — сравнение строки с пустой.

```go
func cityReady(city string) bool {
	return city != ""
}
```

`!=` значит «не равно». Выражение `city != ""` имеет тип `bool`: `true` или `false`. Для `Moscow` функция вернёт `true`. Для пустой строки вернёт `false`.

## Что запомнить

- План: город, адрес, запрос, ответ, отчёт.
- Отчёт собирает метод `Line`: `город: текст`.
- Температуру в текст кладут через `fmt.Sprintf("%d C", число)`.
- Пустой город — повод остановиться до запроса. `city != ""` это проверяет.

## Что сделать

Заполни `tasks.go`. Тип `Report` и функции опиши на уровне пакета. Запуск: `go run .`. Проверка: `go test .`.
