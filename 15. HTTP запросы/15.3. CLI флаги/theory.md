# 15.3. CLI флаги

Город пользователь пишет при запуске, а не внутри кода. Такой аргумент с именем называется флаг. CLI — программа в терминале, от command line interface.

Запуск выглядит так:

```bash
go run . -city Moscow -units F
```

`-city` — имя флага. `Moscow` — его значение. `-units` — второй флаг.

## Набор флагов

Пакет `flag` из стандартной библиотеки разбирает такие аргументы. `FlagSet` — отдельный набор флагов с именем программы.

```go
fs := flag.NewFlagSet("weather", flag.ContinueOnError)
```

`NewFlagSet` создаёт набор. Первый аргумент `"weather"` — имя для сообщений. `flag.ContinueOnError` значит: при ошибке разбора функция вернёт `error`, программа сама не завершится.

## Флаг-строка

Город и единицы — строки. Их описывают через `String`.

```go
city := fs.String("city", "", "город")
units := fs.String("units", "C", "единицы")
```

По аргументам `String`:

- первое — имя флага без минуса;
- второе — значение по умолчанию, если флаг не передали;
- третье — короткая подсказка.

`String` возвращает указатель `*string`. Указатель — адрес места, куда `Parse` потом запишет текст. Сразу после `String` по этому адресу лежит значение по умолчанию.

## Разбор

`Parse` читает срез строк. Это то, что пользователь написал после имени программы. Самого имени `weather` в срезе нет.

```go
err := fs.Parse([]string{"-city", "Moscow", "-units", "F"})
if err != nil {
	return ""
}
name := *city
scale := *units
```

По строкам:

- `[]string{...}` — аргументы запуска.
- `err` не равен `nil`, если флаг записан с ошибкой. Тогда значение не используют.
- `*city` читает строку по указателю. Здесь это `Moscow`.
- `*units` равен `F`, потому что флаг передали.

Если разобрать пустой срез `[]string{}`, `-units` никто не передал. `*units` останется значением по умолчанию: `C`.

## Что запомнить

- Флаг — именованный аргумент запуска: `-city Moscow`.
- `flag.NewFlagSet` создаёт набор. `ContinueOnError` отдаёт ошибку разбора в `err`.
- `String` возвращает `*string`. После `Parse` строку читают через `*`.
- Второй аргумент `String` — значение, когда флага в команде нет.

## Что сделать

Заполни `tasks.go`. В каждом задании свой `FlagSet`. Запуск: `go run .`. Проверка: `go test .`.
