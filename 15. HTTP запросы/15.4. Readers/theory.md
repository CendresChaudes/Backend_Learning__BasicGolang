# 15.4. Readers

Ответ сервиса приходит потоком байтов. В Go такой поток читают через `io.Reader`. Reader — интерфейс с одним методом: из него можно читать байты.

```go
type Reader interface {
	Read(p []byte) (n int, err error)
}
```

`Read` кладёт кусок данных в срез `p`. `n` — сколько байтов легло. Свой `Read` в этом уроке вызывать не нужно. Пакет `io` читает поток до конца сам.

## Строка как поток

`strings.NewReader` делает `Reader` из обычной строки. Так проверяют чтение без сети.

```go
r := strings.NewReader("ясно")
data, err := io.ReadAll(r)
if err != nil {
	return ""
}
text := string(data)
```

По строкам:

- `strings.NewReader` принимает строку и возвращает значение, которое умеет `Read`.
- `io.ReadAll` вызывает `Read`, пока данные не кончатся. Результат — `[]byte` и `error`.
- Если `err` не равен `nil`, строку из `data` не собирают.
- `string(data)` превращает байты в текст. Здесь `text` равен `ясно`.

Тело HTTP-ответа тоже будет `Reader`. Его читают тем же `io.ReadAll`.

## Сколько байтов

`len` у среза байтов — длина в байтах, не в буквах.

```go
n := len(data)
```

Для текста `12 C` в `data` четыре байта: `1`, `2`, пробел, `C`. `n` равен `4`.

## Что запомнить

- `io.Reader` — поток, из которого читают байты.
- `strings.NewReader` делает такой поток из строки.
- `io.ReadAll` забирает весь поток в `[]byte`. Строку получают через `string(data)`.
- `len` у этих байтов считает байты.
