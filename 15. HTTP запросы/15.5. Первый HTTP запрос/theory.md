# 15.5. Первый HTTP запрос

HTTP-запрос — сообщение клиента серверу. Метод `GET` значит «прочитать». Ответ — код статуса и тело. Тело как раз `Reader` из прошлого урока.

Пакет `net/http` входит в стандартную библиотеку. `http.Get` отправляет `GET` по адресу.

## Запрос

```go
resp, err := http.Get(url)
if err != nil {
	return ""
}
defer resp.Body.Close()
```

По строкам:

- `http.Get` возвращает ответ и ошибку. Ответ имеет тип `*http.Response`.
- `err` не равен `nil`, если до сервера не дошли. Тело тогда не читают.
- `resp.Body` — тело ответа, тип `io.Reader`.
- `defer resp.Body.Close()` закрывает тело при выходе из функции. Соединение так не остаётся занятым.

Текст из тела забирают так же, как из строки:

```go
data, err := io.ReadAll(resp.Body)
text := string(data)
```

Если сервер прислал `ясно`, в `text` будет `ясно`.

## Код статуса

Число статуса лежит в поле `StatusCode`.

```go
code := resp.StatusCode
```

`200` значит, что ответ удался. `404` значит, что такого пути нет.

## Сервер рядом

В заданиях интернет не нужен. `httptest.NewServer` из пакета `net/http/httptest` поднимает сервер на этой машине и сам выбирает порт.

```go
srv := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
	w.Write([]byte("ясно"))
}))
defer srv.Close()
```

По строкам:

- `http.HandlerFunc` — функция, которая отвечает на один запрос.
- `w` — куда пишут ответ. `r` — пришедший запрос.
- `w.Write` кладёт байты в тело. Без отдельного кода статус будет `200`.
- `srv.URL` — адрес этого сервера. Его передают в `http.Get`.
- `defer srv.Close()` останавливает сервер при выходе из функции.

Свой код ставят до записи тела:

```go
w.WriteHeader(404)
```

`WriteHeader` записывает статус. Здесь это `404`.

## Что запомнить

- `http.Get` отправляет `GET` и возвращает ответ с ошибкой.
- Тело закрывают через `defer resp.Body.Close()`. Текст даёт `io.ReadAll`.
- `resp.StatusCode` — число. `200` — ответ есть, `404` — пути нет.
- `httptest.NewServer` — локальный сервер. Адрес лежит в `srv.URL`.

## Что сделать

Заполни `tasks.go`. В каждом задании свой сервер через `httptest`, затем `http.Get`. Запуск: `go run .`. Проверка: `go test .`.
