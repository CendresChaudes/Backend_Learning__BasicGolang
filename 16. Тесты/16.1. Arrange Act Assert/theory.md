# 16.1. Arrange Act Assert

Тест проверяет одно поведение функции. Его делят на три шага: Arrange, Act, Assert. Шаги идут по порядку, сверху вниз.

## Arrange

Arrange — подготовка. Здесь появляются входные данные и ответ, который считают верным. Функцию ещё не вызывают.

```go
city := "Moscow"
text := "ясно"
want := "Moscow: ясно"
```

`city` и `text` — вход. `want` — ожидаемая строка. Имя `want` значит «нужно получить».

## Act

Act — действие. Здесь функцию вызывают один раз и сохраняют результат.

```go
got := reportLine(city, text)
```

`got` — то, что функция вернула на самом деле. Имя `got` значит «получилось». В этом шаге одна строка вызова. Второй вызов той же функции в этом тесте уже другой Act, для него пишут другой тест.

## Assert

Assert — проверка. `got` сравнивают с `want`.

```go
if got != want {
	t.Errorf("получилось %q, нужно %q", got, want)
}
```

По строкам:

- `!=` значит «не равно». В `if` входят, когда строки разные.
- `t.Errorf` записывает текст провала. Что такое `t`, будет в следующем уроке. Сейчас важно само сравнение.
- `%q` подставляет строку в кавычках. Пробел в начале или в конце тогда виден.

Если `got` и `want` равны, `if` пропускается. Тест на этом заканчивается успешно.

## Что запомнить

- Arrange готовит вход и `want`. Функцию здесь не вызывают.
- Act вызывает функцию один раз и кладёт результат в `got`.
- Assert сравнивает `got` и `want`. Различие записывают через `t.Errorf`.
- Один тест — один Act.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`. В `tasks_test.go` шаги уже стоят в этом порядке: данные, вызов, сравнение.
