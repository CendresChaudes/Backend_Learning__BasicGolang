# 16.1. Первый тест

Тест проверяет одно поведение функции. Его делят на три шага: Arrange, Act, Assert. Шаги идут по порядку, сверху вниз.

Arrange — подготовка. Здесь появляются входные данные и ответ, который считают верным. Функцию ещё не вызывают.

Act — действие. Один вызов функции. Результат кладут в переменную `got`.

Assert — проверка. `got` сравнивают с ожидаемым `want`. Если они различаются, тест сообщает об этом и считается проваленным.

```go
func TestLabel(t *testing.T) {
	city := "Moscow"
	text := "ясно"
	want := "Moscow: ясно"

	got := label(city, text)

	if got != want {
		t.Errorf("получилось %q, нужно %q", got, want)
	}
}
```

Тест — обычная функция. Имя начинается с `Test`. Аргумент имеет тип `*testing.T`. Файл с тестами заканчивается на `_test.go`. Команда `go test .` запускает такие функции и сама сообщает, сошёлся результат или нет.

`t.Errorf` пишет строку в отчёт и помечает тест как проваленный, но не останавливает остальные проверки в этой функции. `%q` подставляет строку в кавычках, поэтому в отчёте видно и `got`, и `want`.

Пакет `testing` подключают через `import`. В `tasks_test.go` этого урока проверка уже написана. Тебе нужно заполнить функции, которые тест вызывает.

## Что запомнить

- Сначала данные, потом один вызов, потом сравнение.
- Имя теста начинается с `Test`, файл заканчивается на `_test.go`.
- `t.Errorf` показывает, что получилось и что нужно.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
