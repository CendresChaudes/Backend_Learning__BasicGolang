# 16.2. Ошибки в тестах

Позитивный тест даёт функции обычный вход и ждёт удачный ответ. Негативный тест даёт плохой вход и ждёт отказ.

Оба теста нужны одной функции. Проверка только на городе `Moscow` не увидит пустую строку. Проверка только на пустой строке не увидит успешный отчёт.

Функция может вернуть два значения: результат и `error`. В учебном задании наружу отдаём текст: если ошибки нет, строка пустая или в ней лежит полезный ответ. `errors.New` создаёт ошибку. Метод `Error` возвращает её текст.

```go
func load(city string) (string, error) {
	if city == "" {
		return "", errors.New("пустой город")
	}
	return city + ": ясно", nil
}
```

Тест сначала смотрит на ошибку. Для пустого города `err` не равен `nil`, а текст равен `"пустой город"`. Для обычного города `err` равен `nil`, и тогда сравнивают отчёт.

В `tasks.go` этого урока функции возвращают одну строку: текст ошибки или полезный ответ. Тесты проверяют оба входа.

## Что запомнить

- Негативный тест ждёт отказ на плохом входе.
- Успешный вход и плохой вход проверяют отдельно.
- Текст ошибки берут из `errors.New(...).Error()`.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
