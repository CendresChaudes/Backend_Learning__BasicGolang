# 16.2. Первый тест

Тест — обычная функция. Go запускает её отдельно от `main` и сам сообщает, сошёлся результат или нет.

Файл с тестами заканчивается на `_test.go`. Окончание `_test.go` говорит команде `go test`, что внутри лежат тесты. Рядом в этой папке уже есть `tasks_test.go`.

## Пакет testing

`testing` — пакет стандартной библиотеки. Его подключают через `import`.

```go
package main

import "testing"
```

`package main` здесь совпадает с пакетом в `tasks.go`. Тест может вызвать `task1` напрямую. Имя с маленькой буквы видно внутри одного пакета.

## Функция теста

Имя теста начинается со слова `Test`. Следующая буква — большая.

```go
func TestUnits(t *testing.T) {
	got := unitsOrDefault("")
	want := "C"
	if got != want {
		t.Errorf("получилось %q, нужно %q", got, want)
	}
}
```

По строкам:

- `TestUnits` — имя. `go test` запускает функции, у которых имя начинается с `Test`.
- `t *testing.T` — параметр. `T` — тип отчёта о тесте. Звёздочка значит указатель: функция получает адрес общего отчёта и может записать туда провал.
- Внутри те же три шага, что в прошлом уроке: `want`, вызов, сравнение.
- `t.Errorf` дописывает текст в отчёт. Тест после этой строки продолжается.

## Запуск

Из папки урока:

```bash
go test .
```

Точка — текущая папка. Команда собирает `tasks.go` и `tasks_test.go`. В конце будет `ok` или `FAIL`.

Пока функции возвращают пустые заготовки, в терминале будет `FAIL`. Так и задумано: проверка уже работает, код под ней ещё пустой.

## Что запомнить

- Тесты лежат в файле `*_test.go`. Пакет `testing` подключают через `import`.
- Имя функции начинается с `Test`, дальше большая буква.
- Параметр `t *testing.T` принимает отчёт. `t.Errorf` записывает провал.
- Запуск из папки урока: `go test .`.

## Что сделать

Открой `tasks_test.go` и прочитай каждый тест по строкам. Затем заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
