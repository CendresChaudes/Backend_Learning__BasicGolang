# 16.3. Группы тестов

Одна и та же проверка на трёх входах — это три почти одинаковых куска. Их собирают в группу: список случаев и цикл.

Один случай описывает структура. У неё нет отдельного имени: поля перечислены прямо в типе списка.

```go
tests := []struct {
	name string
	kind string
	want string
}{
	{name: "ясно", kind: "clear", want: "ясно"},
	{name: "дождь", kind: "rain", want: "дождь"},
	{name: "чужой код", kind: "fog", want: ""},
}
for _, tt := range tests {
	t.Run(tt.name, func(t *testing.T) {
		got := task1(tt.kind)
		if got != tt.want {
			t.Errorf("получилось %q, нужно %q", got, tt.want)
		}
	})
}
```

`t.Run` запускает вложенный тест со своим именем. Если упадёт один случай, в отчёте будет видно его `name`, а остальные случаи всё равно выполнятся.

В `tasks_test.go` этого урока группа уже собрана. Функции в `tasks.go` по-прежнему возвращают одно значение на один вход.

## Что запомнить

- Повторяющиеся проверки держат списком случаев, а не копией `if`.
- У случая есть имя, вход и ожидаемый ответ.
- `t.Run` показывает в отчёте, какой случай упал.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
