# 16.5. Упражнение Тест погоды

У погодного клиента три отдельные проверки. У каждой свой тест: один вход, один вызов, одно сравнение.

Файл `tasks_test.go` уже содержит эти три теста. Ниже — что именно они ждут.

## Строка отчёта

Отчёт для человека — город, двоеточие и температура с единицей.

```go
line := fmt.Sprintf("%s: %d C", "Moscow", 12)
```

`%s` заменяется на строку, `%d` — на целое число. В `line` будет `Moscow: 12 C`.

Тест передаёт `Moscow` и `12`, затем сравнивает результат с этой строкой. Второй вызов в том же тесте берёт отрицательную температуру: `Kazan` и `-5` дают `Kazan: -5 C`.

## Query

Query — часть адреса после `?`. Пары собирает `url.Values` из пакета `net/url`.

```go
q := url.Values{}
q.Set("city", "Moscow")
q.Set("units", "C")
query := q.Encode()
```

`Set` записывает одну пару. `Encode` склеивает их в строку. Имена идут по алфавиту, поэтому сначала `city`, потом `units`. В `query` будет `city=Moscow&units=C`.

Пробел в городе `Encode` записывает как `+`. Город `New York` и единицы `F` дадут `city=New+York&units=F`.

## Полный адрес

Базовый адрес и query соединяют через `?`.

```go
rawURL := "https://api.weather.local/v1?" + query
```

Для города `Moscow` и единиц `C` в `rawURL` будет `https://api.weather.local/v1?city=Moscow&units=C`.

Единицы в этом задании всегда `C`. Меняется только город.

## Что запомнить

- Один тест проверяет одно: отчёт, query или полный адрес.
- Отчёт: `fmt.Sprintf("%s: %d C", город, температура)`.
- Query: `url.Values`, `Set`, `Encode`. Ключи по алфавиту, пробел становится `+`.
- Полный адрес: `https://api.weather.local/v1?` и следом `Encode`.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
