# 16.6. Упражнение Ошибки

Функция может вернуть два значения: результат и `error`. Тест проверяет оба. Сначала смотрят на ошибку, потом на результат.

`error` — тип для сообщения о неудаче. `nil` в этом типе значит: ошибки нет. `errors.New` создаёт ошибку из текста. Метод `Error` возвращает этот текст обратно.

## Ждали ошибку

Пустой город — повод вернуть ошибку и пустую строку на месте отчёта.

```go
func load(city string) (string, error) {
	if city == "" {
		return "", errors.New("пустой город")
	}
	return city + ": ясно", nil
}
```

`return "", errors.New("пустой город")` отдаёт пустой результат и ошибку. `return city + ": ясно", nil` отдаёт отчёт и `nil`.

Тест на плохой вход выглядит так:

```go
got, err := load("")
if err == nil {
	t.Fatal("ждали ошибку")
}
if err.Error() != "пустой город" {
	t.Errorf("получилось %q, нужно %q", err.Error(), "пустой город")
}
```

По строкам:

- `load("")` — вызов с пустым городом.
- `err == nil` значит, ошибки нет. Здесь её как раз ждали, поэтому тест останавливают.
- `t.Fatal` записывает провал и прекращает этот тест. Дальше `err.Error()` уже не вызывают. Вызов `Error`, когда `err` равен `nil`, останавливает программу.
- `err.Error()` — текст ошибки. Его сравнивают с `пустой город`.

## Ждали успех

Второй тест вызывает `load("Moscow")`. Ошибки быть не должно.

```go
got, err := load("Moscow")
if err != nil {
	t.Fatal(err.Error())
}
```

`err != nil` — ошибка есть. `t.Fatal` печатает её текст и останавливает тест. До сравнения `got` с `Moscow: ясно` ход доходит, только если `err` равен `nil`.

`t.Errorf` в такой проверке слабее: он записывает провал, но тест идёт дальше и может вызвать метод у `nil`.

## В заданиях

Функции заданий возвращают одну строку — тот текст, который тест сравнивает.

- Ветка ошибки: `errors.New` с текстом из комментария, наружу верни результат `Error`.
- Ветка успеха: верни полезную строку. Если в комментарии сказано, что ошибки нет и вернуть нужно пустую строку, так и сделай.

## Что запомнить

- Сначала проверяют `error`, потом результат.
- `err == nil` на негативном тесте — провал. Его останавливают через `t.Fatal`.
- Текст ошибки даёт метод `Error`. Его сравнивают как обычную строку.
- На успехе `err` равен `nil`. Чужую ошибку тоже останавливают через `t.Fatal`.

## Что сделать

Заполни `tasks.go`. Ошибку создавай через `errors.New`. Запуск: `go run .`. Проверка: `go test .`.
