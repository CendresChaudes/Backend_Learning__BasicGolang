# 16.7. Группы тестов

Одна и та же проверка на трёх городах — это три почти одинаковых куска. Их собирают в группу: список случаев и цикл.

Один случай описывает структура. Структура — тип из нескольких полей. Здесь у неё нет отдельного имени: поля перечислены прямо в типе списка.

## Список случаев

```go
tests := []struct {
	name string
	kind string
	want string
}{
	{name: "clear", kind: "clear", want: "ясно"},
	{name: "rain", kind: "rain", want: "дождь"},
}
```

По строкам:

- `[]struct { ... }` — список. В фигурных скобках поля одного случая: имя, вход, ожидаемый ответ.
- Ниже в фигурных скобках — сами случаи. `name` потом видно в отчёте. `kind` уйдёт в функцию. `want` — с чем сравнивать.

Такой список называют таблицей. Строка таблицы — один случай.

## Подтест

`t.Run` запускает подтест. Подтест — отдельный прогон внутри большого теста. У него своё имя и свой отчёт.

```go
for _, tt := range tests {
	t.Run(tt.name, func(t *testing.T) {
		got := weatherWord(tt.kind)
		if got != tt.want {
			t.Errorf("получилось %q, нужно %q", got, tt.want)
		}
	})
}
```

По строкам:

- `for _, tt := range tests` перебирает случаи. `tt` — текущая строка таблицы.
- Первый аргумент `t.Run` — имя подтеста, здесь `tt.name`.
- Второй аргумент — функция без имени. Её пишут прямо в вызове. Параметр `t *testing.T` — отчёт этого подтеста, не всего теста целиком.
- Внутри те же `got` и `want`. Провал одного подтеста не выключает цикл: следующий случай всё равно запустится.

В терминале имя склеивается через `/`:

```text
--- FAIL: TestTask1/rain
```

`TestTask1` — внешний тест. `rain` — подтест. По этому имени сразу видно, какой случай упал.

Пробел в имени подтеста в отчёте заменяется на `_`. Имя `not found` выглядит как `TestTask2/not_found`.

`go test -v .` показывает `PASS` или `FAIL` у каждой такой строки.

## Что запомнить

- Повторы одной проверки складывают в список случаев: имя, вход, `want`.
- `t.Run` запускает подтест. Первый аргумент — имя, второй — функция с параметром `t *testing.T`.
- Провал одного случая не прячет остальные.
- В отчёте имя выглядит как `TestTask1/rain`.

## Что сделать

Открой `tasks_test.go` и найди `t.Run`. Затем заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`. Подробный отчёт: `go test -v .`.
