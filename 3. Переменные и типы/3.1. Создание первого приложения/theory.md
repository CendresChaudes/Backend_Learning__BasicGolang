# 3.1. Создание первого приложения

Программа на Go — это текст в файле с расширением `.go`. Компьютер сам этот текст не выполняет. Сначала команда `go run` превращает его в программу и сразу запускает.

## С чего начинается файл

Каждый файл объявляет пакет. Пакет (`package`) — это папка с кодом, у которой есть общее имя.

```go
package main
```

`main` — особое имя. Так Go понимает: это не библиотека, а программа, которую можно запустить.

## Точка входа

Запуск начинается с функции `main`. Функция — это именованный кусок кода. Пока её не вызвали, она не выполняется. Функцию `main` вызывает сам Go, когда программа стартует.

```go
func main() {
}
```

`func` означает «дальше описана функция». Фигурные скобки `{ }` держат внутри себя команды этой функции.

## Печать на экран

Чтобы увидеть результат, программу просят напечатать текст. Для этого берут пакет `fmt` из стандартной библиотеки. Стандартная библиотека — набор готовых пакетов, который ставится вместе с Go.

```go
import "fmt"
```

`import` подключает чужой пакет к этому файлу. После этого можно вызывать его функции через точку: `имяПакета.ИмяФункции`.

```go
fmt.Println("Hello, World!")
```

- `fmt` — пакет для форматированного вывода.
- `Println` — функция «напечатай строку и перейди на следующую». Имя с большой буквы: снаружи пакета видны только такие имена.
- `"Hello, World!"` — строка, текст в двойных кавычках.
- Точка с запятой в конце строки не нужна. Go сам понимает, где команда закончилась.

`fmt.Print` печатает текст и остаётся на той же строке. `fmt.Println` после текста добавляет перевод строки.

## Целый пример

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello, World!")
}
```

По строкам:

1. Файл принадлежит пакету `main`, значит это программа.
2. Подключаем `fmt`, чтобы было чем печатать.
3. Описываем `main`. С неё начнётся запуск.
4. Печатаем одну строку.

Запуск из папки, где лежит файл:

```bash
go run .
```

Точка означает «текущая папка». Go соберёт все файлы пакета `main` в этой папке и запустит их.

## Что запомнить

- Файл программы начинается с `package main`.
- Код запуска лежит в `func main`.
- `import "fmt"` нужен, чтобы вызвать `fmt.Println`.
- Текст для печати пишут в двойных кавычках.

## Что сделать

Открой `tasks.go`. Каждая заготовка пока возвращает пустую строку. Замени `return ""` своим значением. `main.go` печатает результаты после `Hello, World!`.

Проверка из этой папки: `go run .` запускает программу, `go test .` проверяет ответы. Пока заготовки пустые, тесты падают. Это нормально.
