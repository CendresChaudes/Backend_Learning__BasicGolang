# 3.2. Packages

Пакет (`package`) — это набор файлов Go с одним именем. Имя пакета пишут в первой строке каждого файла. По этому имени другой код вызывает функции пакета.

## Два вида пакетов

`package main` — программа. У неё есть `func main`, её запускают.

Любое другое имя — библиотека. Её не запускают отдельно. Её подключают и вызывают функции.

```go
package main
```

Файл библиотеки выглядел бы так: `package strings`. Сам по себе он не стартует.

## Импорт

`import` подключает пакет к текущему файлу. Подключение действует только в этом файле. Соседний файл той же папки, если ему нужен тот же пакет, пишет свой `import`.

```go
import "fmt"
```

Несколько пакетов собирают в скобки. Так читается проще, чем несколько отдельных `import`.

```go
import (
	"fmt"
	"strings"
)
```

`fmt` и `strings` лежат в стандартной библиотеке. Их не нужно скачивать.

Если пакет импортирован и ни разу не использован, программа не скомпилируется. Go так защищает файл от мусора.

## Как вызвать чужую функцию

Снаружи пакета видно только имена с большой буквы. Это называется экспорт. Экспорт — разрешение пользоваться именем из другого пакета.

```go
fmt.Println("go")
```

`Println` написан с большой буквы, поэтому его можно вызвать из нашего пакета. Вызов читается как «пакет `fmt`, функция `Println`».

Пакет `strings` умеет работать с текстом. `strings.ToUpper` делает все буквы заглавными. `strings.Repeat` повторяет строку нужное число раз.

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	fmt.Println(strings.ToUpper("go"))
	fmt.Println(strings.Repeat("-", 3))
}
```

На экран попадёт:

```text
GO
---
```

`strings.ToUpper("go")` сначала считает результат, потом `fmt.Println` его печатает. Функцию можно передать прямо в другую функцию.

## Что запомнить

- Каждый файл начинается с `package`.
- `main` — программа, остальные имена — библиотеки.
- `import` нужен в каждом файле, который пользуется чужим пакетом.
- Снаружи доступны только имена с большой буквы: `fmt.Println`.

## Что сделать

В `tasks.go` три заготовки. Во втором и третьем задании аргументы уже переданы в функцию: это входные данные, свои подставлять не нужно. Для них подключи пакет `strings` рядом с `fmt`.

Проверка из этой папки: `go run .` и `go test .`. Пустая заготовка возвращает пустую строку, поэтому тесты сначала падают.
