# 3.3. Go modules

Модуль (`module`) — это папка проекта, у которой есть имя и список зависимостей. Зависимость — чужой пакет, без которого проект не соберётся. Описание модуля лежит в файле `go.mod`.

## Зачем он нужен

Пока программа использует только стандартную библиотеку, Go и так знает, где лежит `fmt`. Модуль становится нужен, как только появляется свой проект:

- у проекта есть постоянное имя;
- Go запоминает версию языка;
- позже сюда же запишутся внешние пакеты и их версии.

Один модуль — один `go.mod` в корне этого проекта. Вложенные папки уроков не обязаны быть отдельными модулями. Отдельный модуль заводят для отдельной программы.

## Как появляется go.mod

Команда создаёт файл в текущей папке:

```bash
go mod init example.com/wallet
```

`example.com/wallet` — путь модуля. Это имя, по которому другие пакеты будут его импортировать. Для учёбы подойдёт короткое имя, например `wallet`. В настоящей библиотеке путь обычно похож на адрес репозитория.

## Что внутри файла

```text
module example.com/wallet

go 1.27.1
```

- Строка `module` — имя модуля. Его нельзя угадать из названия папки: оно записано явно.
- Строка `go` — версия языка, на которую рассчитан проект. Её берут из `go version`.

Позже в этот файл попадут строки `require`: имя внешнего пакета и точная версия. Сейчас их нет, и это нормально.

## Как это связано с запуском

Если в папке есть `go.mod`, из неё запускают весь пакет:

```bash
go run .
```

Один файл можно запустить и без модуля:

```bash
go run tasks.go
```

Так удобно для короткого упражнения. Настоящее приложение держат внутри модуля, чтобы имя проекта и зависимости не терялись.

## Что запомнить

- `go.mod` описывает модуль: имя и версию Go.
- Файл создают командой `go mod init имя`.
- Имя в строке `module` — это путь, по которому модуль импортируют.
- Внешние пакеты потом фиксируются в том же файле.

## Что сделать

Открой `tasks.go`. Каждая функция возвращает строку, а `main` её печатает. В этом курсе в `go.mod` пишем версию `1.27.1`, чтобы тест мог сверить ответ.

Проверка из этой папки: `go run .` и `go test .`. Пока стоит `return ""`, тесты падают.
