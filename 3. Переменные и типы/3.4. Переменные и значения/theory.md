# 3.4. Переменные и значения

Переменная — это имя, за которым хранится значение. Значение — конкретные данные: число `3`, текст `"Go"`. Имя нужно, чтобы прочитать значение позже и чтобы заменить его.

## Объявление

Объявление создаёт переменную. Внутри функции это удобно писать коротко: `:=`.

```go
language := "Go"
fmt.Println(language)
```

- `language` — имя. Его придумываешь ты. Пробелов в имени нет.
- `:=` — «создай переменную и сразу положи в неё значение».
- `"Go"` — значение, строка.
- Дальше программа обращается к значению по имени `language`, уже без кавычек. Кавычки были бы новым текстом, а не переменной.

Имя начинается с буквы. В Go принято `camelCase`: `userName`, не `user_name`.

## Замена значения

Когда переменная уже есть, новое значение кладут через `=`. Один знак `=`, без двоеточия. Двоеточие нужно только в момент создания.

```go
score := 10
fmt.Println(score)

score = 25
fmt.Println(score)
```

Сначала на экране будет `10`, потом `25`. Старое значение не хранится рядом: в переменной лежит только последнее.

`:=` второй раз для того же имени в той же функции использовать нельзя. Переменная уже создана.

## Две переменные

Каждое значение, которое хочешь сохранить, получает своё имя.

```go
city := "Казань"
year := 2009
fmt.Println(city, year)
```

`Println` с двумя аргументами печатает их через пробел: `Казань 2009`.

Число пишут без кавычек. Текст — в кавычках. `"2009"` был бы текстом из четырёх символов, а не числом.

## Что запомнить

- `имя := значение` создаёт переменную внутри функции.
- `имя = значение` меняет уже созданную переменную.
- В переменной хранится текущее значение, старое пропадает.
- Имя без кавычек — переменная. Текст в кавычках — новое значение.
