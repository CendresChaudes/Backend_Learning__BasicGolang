# 3.5. Типы

Тип (`type`) — это вид значения. Он решает, какие операции разрешены и сколько места значение занимает. У переменной тип есть всегда, даже если ты его не написал: Go берёт его из значения справа.

## Четыре типа, с которых начинают

```go
count := 3
price := 1.5
title := "Go"
ready := true

fmt.Println(count, price, title, ready)
```

- `3` имеет тип `int` — целое число.
- `1.5` имеет тип `float64` — число с дробной частью. `64` значит «64 бита точности».
- `"Go"` имеет тип `string` — строка, последовательность символов.
- `true` имеет тип `bool` — логическое значение. Вариантов два: `true` и `false`.

## Нулевое значение

Если объявить переменную и ничего не положить, Go кладёт нулевое значение (`zero value`). Это безопасная пустота для данного типа, не случайный мусор.

```go
var count int
var price float64
var title string
var ready bool

fmt.Println(count, price, title, ready)
```

Получится `0`, `0`, пустая строка и `false`. Пустую строку на экране не видно, но переменная существует.

Здесь использован `var`, потому что `:=` требует значение справа. Подробные формы записи будут в следующем уроке. Пока достаточно читать `var count int` как «переменная `count` типа `int`».

## Типы не смешиваются сами

`int` и `float64` нельзя сложить напрямую. Go не превращает типы молча: так меньше скрытых ошибок.

Преобразование типа — явная просьба получить значение другого типа. Пишется как вызов: `float64(count)`.

```go
count := 3
price := 1.5
total := float64(count) * price
fmt.Println(total)
```

`float64(count)` берёт целое `3` и делает дробное `3.0`. Потом его можно умножить на `1.5`. Исходный `count` остаётся `int`.

Текст и число тоже нельзя сложить через `+`, пока число не превращено в строку. Для печати это не нужно: `fmt.Println` принимает их рядом, через запятую.

## Что запомнить

- `int`, `float64`, `string`, `bool` — базовые типы.
- Тип переменной не меняется, когда меняется значение.
- Пустая переменная получает нулевое значение своего типа.
- Чужой тип получают преобразованием: `float64(count)`.
