# 3.6. Варианты записи переменных

Одно и то же значение можно положить в переменную несколькими способами. Смысл один: появляется имя и тип. Отличается только то, что Go додумывает сам, а что написано явно.

## Три формы одной переменной

Внутри функции:

```go
var count int = 42
var total = 42
items := 42
```

- `var count int = 42` — полная форма. Видны имя, тип и значение.
- `var total = 42` — тип не написан. Go смотрит на `42` и выбирает `int`.
- `items := 42` — короткая форма. Она разрешена только внутри функции. Тип тоже выводится из значения.

Все три переменные — `int` со значением `42`.

Короткая форма создаёт переменную. Если имя уже есть, пиши `=`, без двоеточия.

## Несколько переменных сразу

Два новых имени можно создать одной строкой. Слева и справа должно быть поровну.

```go
language, year := "Go", 2009
fmt.Println(language, year)
```

Слева направо: `language` получает `"Go"`, `year` получает `2009`.

## Группа var

Когда переменных много, их собирают в блок. Так список настроек читается как один кусок.

```go
var (
	host  = "localhost"
	port  = 8080
	debug = false
)
```

Это то же самое, что три отдельных `var`, только записанных вместе. Тип каждой снова выводится из значения: строка, число, `bool`.

Блок `var` можно поставить и снаружи функции. `:=` снаружи функции нельзя: там нет «внутри функции», а короткая форма живёт только там.

## Когда какая форма

Внутри `main` чаще пишут `:=`: короче. Полную форму `var name int = ...` берут, когда тип хотят показать явно или когда значения ещё нет и нужно нулевое. Блок `var (` нужен для пачки связанных переменных.

## Что запомнить

- `var name int = value` указывает тип явно.
- `var name = value` и `name := value` выводят тип из значения.
- `:=` пишут только внутри функции и только когда создают переменную.
- Несколько имён сразу: `a, b := 1, 2`.

## Что сделать

В `tasks.go` одна и та же идея записана тремя заданиями: три формы, одна строка на два имени, блок `var`. Запуск: `go run tasks.go`.
