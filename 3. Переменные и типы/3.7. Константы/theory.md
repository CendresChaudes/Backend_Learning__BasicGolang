# 3.7. Константы

Константа (`const`) — имя для значения, которое нельзя заменить. Переменная меняется через `=`. Константа после создания остаётся той же до конца программы.

Константа подходит для того, что известно заранее и не должно случайно поменяться: имя приложения, лимит попыток, код статуса.

## Объявление

```go
const appName = "wallet"
fmt.Println(appName)
```

`const` вместо `:=`. Значение справа должно быть известно при сборке: число, строка, `true` или `false`. Результат чтения файла или текущее время в константу положить нельзя. Это ещё не посчитано, когда программу компилируют.

Попытка написать `appName = "other"` не скомпилируется. Так Go ловит случайную перезапись.

Тип можно указать явно, по тем же правилам, что у `var`:

```go
const maxAttempts int = 3
```

Если тип не написан, константа называется нетипизированной: точный тип она получает в месте использования. Для начала достаточно формы без типа.

## Группа констант

Связанные константы держат в одном блоке.

```go
const (
	statusOK   = 200
	statusFail = 500
)
```

## iota

`iota` — счётчик внутри блока `const`. На каждой следующей строке блока он увеличивается на единицу, начиная с нуля. Его берут, когда нужны подряд идущие номера и не хочется писать их руками.

```go
const (
	sunday = iota
	monday
	tuesday
)

fmt.Println(sunday, monday, tuesday)
```

На экране будет `0 1 2`. Повторять `= iota` на каждой строке не нужно: в блоке `const` пустая правая часть означает «как у строки выше».

## Что запомнить

- `const` создаёт имя, которое нельзя переназначить.
- Значение константы известно уже при сборке программы.
- Несколько констант группируют в `const ( )`.
- `iota` нумерует строки такого блока с нуля.

## Что сделать

Заполни `tasks.go`. Константу не нужно менять после создания: во втором задании рядом с ней живёт обычная переменная. Запуск: `go run tasks.go`.
