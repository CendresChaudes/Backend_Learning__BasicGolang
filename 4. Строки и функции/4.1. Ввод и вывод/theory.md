# 4.1. Ввод и вывод

Программа разговаривает с внешним миром в две стороны. Вывод — текст, который она пишет наружу. Ввод — текст, который она читает.

В прошлом уроке печать уже была: `fmt.Println`. Здесь видно, чем запись отличается от чтения.

## Куда уходит текст

Стандартный вывод (`stdout`) — место, куда программа пишет. В терминале это экран.

`fmt.Print` пишет аргументы через пробел и остаётся на той же строке.

```go
fmt.Print("id", 7)
```

На экране будет `id 7`. Следующая печать продолжится сразу после семёрки.

`fmt.Println` пишет так же и в конце добавляет перевод строки. Следующая печать начнётся с новой строки.

```go
fmt.Println("Готово")
```

## Вернуть текст, а не напечатать его

Задание должно отдать строку вызывающему коду. Для этого есть пара к `Print` и `Println`.

`fmt.Sprint` собирает тот же текст, что `Print`, и возвращает его. Перевод строки в конец не ставит.

```go
text := fmt.Sprint("id", 7)
```

В `text` лежит `"id 7"`. На экран само по себе это не выводится.

`fmt.Sprintln` собирает текст как `Println`: в конце есть перевод строки.

```go
line := fmt.Sprintln("Готово")
```

В `line` после слова стоит символ новой строки.

## Откуда приходят данные

Стандартный ввод (`stdin`) — место, откуда программа читает. В терминале это клавиатура.

`fmt.Scan` читает куски текста, разделённые пробелом или новой строкой, и записывает их в переменные.

```go
var age int
fmt.Scan(&age)
```

`var age int` создаёт число. Пока ничего не прочитали, там `0`.

`&age` значит «запиши сюда». Знак `&` берёт адрес переменной. Как устроены адреса, будет в главе про указатели. Сейчас достаточно поставить `&` перед именем, иначе `Scan` не знает, куда положить число.

В тесте клавиатуры нет. `fmt.Sscan` читает так же, но из готовой строки.

```go
var n int
fmt.Sscan("15", &n)
```

Строка `"15"` стоит вместо текста, набранного руками. После вызова в `n` лежит число `15`.

## Что запомнить

- `fmt.Print` не переводит строку, `fmt.Println` переводит.
- `fmt.Sprint` и `fmt.Sprintln` возвращают тот же текст как `string`.
- `fmt.Scan` читает ввод в переменную, перед именем пишут `&`.
- `fmt.Sscan` читает из строки. В заданиях нужен он.
