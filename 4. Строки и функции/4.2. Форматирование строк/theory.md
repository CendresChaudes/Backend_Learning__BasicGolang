# 4.2. Форматирование строк

Форматирование — сборка текста по образцу. Образец называется строкой формата. В ней заранее стоят места, куда потом подставятся значения.

Так пишут порт, цену и флаг, не склеивая куски через `+`.

## Строка формата

`fmt.Printf` печатает по образцу. Место для значения отмечают знаком `%` и буквой. Буква говорит, какого вида это значение. Такую букву называют глаголом формата.

```go
fmt.Printf("порт %d", 8080)
```

`%d` — место для целого числа. `8080` встаёт на это место. На экране будет `порт 8080`.

`Printf` сам перевод строки не добавляет. Если нужна новая строка, в образец пишут `\n`.

```go
fmt.Printf("порт %d\n", 8080)
```

## Глаголы

Глагол должен совпадать с видом значения.

```go
fmt.Printf("%s %d %.1f %t\n", "Go", 2009, 1.5, true)
```

- `%s` — строка.
- `%d` — целое число.
- `%.1f` — дробь с одним знаком после точки. Точка в глаголе — разделитель, не запятая.
- `%t` — логическое значение, `true` или `false`.

Значения после запятой идут в том же порядке, что и глаголы. Первое значение попадает в первый `%`, второе — во второй.

## Та же сборка, но строкой

В задании результат нужно вернуть. `fmt.Sprintf` использует те же глаголы и отдаёт готовую строку. На экран она не печатается.

```go
text := fmt.Sprintf("%s-%d", "Go", 2009)
```

В `text` лежит `"Go-2009"`. Как сохранить такую строку и собрать из неё сообщение, будет в уроке про создание форматированных строк.

## Что запомнить

- Строка формата — образец текста с местами `%`.
- `%s` строка, `%d` целое, `%.1f` дробь с одним знаком, `%t` логическое значение.
- `fmt.Printf` печатает и сам не переводит строку.
- `fmt.Sprintf` возвращает собранную строку.

## Что сделать

Заполни `tasks.go`. В каждом задании собери строку через `fmt.Sprintf`. Запуск: `go run .`. Проверка: `go test .`.
