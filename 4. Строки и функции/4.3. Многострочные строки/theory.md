# 4.3. Многострочные строки

Строка в двойных кавычках — одна логическая строка кода. Перевод строки внутри таких кавычек пишут особым знаком, а не настоящей новой строкой в файле.

Когда текст и так занимает несколько строк, его держат в обратных кавычках.

## Обычная строка

Двойные кавычки задают обычную строку. Обратный слэш включает escape-последовательность: короткий код вместо символа.

```go
text := "имя\tGo"
```

`\t` — символ табуляции. Между `имя` и `Go` будет отступ, не буквы `\` и `t`.

`\n` — перевод строки.

```go
text := "первая\nвторая"
```

В значении две строки текста. В исходнике это по-прежнему одна строка кода.

## Raw-строка

Raw-строка (сырая строка) записана в обратных кавычках `` ` ``. Обратный слэш в ней остаётся обычным символом. Перевод строки пишут настоящей новой строкой.

```go
text := `первая
вторая`
```

Значение то же, что у `"первая\nвторая"`: слово, перевод строки, слово. В файле это видно сразу, без `\n`.

Сырая строка удобна для пути, шаблона письма или куска текста, где много слэшей.

```go
path := `C:\temp\notes`
```

Здесь `\t` не станет табуляцией. В строке лежат символы `\`, `t`, `e` и дальше по буквам.

Обратную кавычку внутрь raw-строки положить нельзя: она закрывает строку.

## Что запомнить

- В `"..."` последовательности `\n` и `\t` превращаются в символы.
- В `` `...` `` слэш остаётся слэшем.
- Перевод строки внутри raw-строки — это настоящая новая строка в коде.
- Raw-строка не содержит символ `` ` ``.

## Что сделать

Заполни `tasks.go`. В первом и третьем задании нужна raw-строка. Во втором — обычная строка с `\t`. Запуск: `go run .`. Проверка: `go test .`.
