# 4.4. Создание форматированных строк

`fmt.Printf` сразу печатает текст. Часто строка нужна раньше печати: её кладут в переменную, отдают из функции или собирают в ответ сервера.

Для этого строку создают через `fmt.Sprintf`. Глаголы те же, что в прошлом уроке про форматирование: `%s`, `%d`, `%.2f`, `%q`.

## Строка как значение

`fmt.Sprintf` возвращает `string`. Её можно сохранить.

```go
message := fmt.Sprintf("пользователь %s", "Анна")
fmt.Println(message)
```

Сначала появляется значение `"пользователь Анна"`. Печать — отдельный шаг. Если `Println` убрать, строка всё равно существует.

`%s` заменяется на текст аргумента. Слово `пользователь` и пробел написаны в образце как есть.

## Деньги и кавычки

`%.2f` оставляет два знака после точки. Так записывают сумму.

```go
total := fmt.Sprintf("сумма %.2f", 19.9)
```

В `total` лежит `"сумма 19.90"`. Ноль на конце дописывает сам глагол.

`%q` подставляет строку в двойных кавычках. Так в журнале видно, где значение начинается и заканчивается.

```go
quoted := fmt.Sprintf("%q", "Go")
```

В `quoted` лежит `"Go"` вместе с кавычками.

## Что запомнить

- `fmt.Sprintf` создаёт строку и возвращает её.
- Готовую строку можно положить в переменную и напечатать позже.
- `%.2f` — дробь с двумя знаками после точки.
- `%q` — строка в кавычках.

## Что сделать

Заполни `tasks.go`. Каждая функция возвращает строку, собранную через `fmt.Sprintf`. Запуск: `go run .`. Проверка: `go test .`.
