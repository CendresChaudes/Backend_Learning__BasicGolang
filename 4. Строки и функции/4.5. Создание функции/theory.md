# 4.5. Создание функции

Функция — именованный кусок кода. Её описывают один раз и вызывают по имени, когда нужен этот кусок.

`main` тоже функция. Её вызывает сам Go при запуске. Остальные функции вызываешь ты.

## Объявление

```go
func greet(name string) string {
	return "Привет, " + name
}
```

По частям:

- `func` начинает объявление функции.
- `greet` — имя. По нему функцию вызывают.
- `name string` — параметр. Параметр — имя внутри функции для значения, которое передали при вызове.
- `string` после скобок — тип результата. Функция обязана вернуть строку.
- `{ }` держат тело: команды, которые выполнятся при вызове.
- `return` отдаёт результат тому, кто вызвал функцию.

Два параметра одного типа можно записать короче: `func sum(a, b int) int`. Это то же самое, что `a int, b int`.

## Вызов

Вызов — имя и скобки. В скобках лежат аргументы: конкретные значения для параметров.

```go
text := greet("Анна")
```

В параметр `name` попадает `"Анна"`. То, что функция вернула, записывается в `text`. Там будет `"Привет, Анна"`.

Пока функцию не вызвали, тело не выполняется. Объявление только говорит, как функция устроена.

## Что запомнить

- `func` объявляет функцию: имя, параметры, тип результата, тело.
- Параметр — вход функции. Аргумент — значение, которое передают при вызове.
- Вызов пишут как `имя(аргументы)`.
- `return` отдаёт результат вызывающему коду.

Заполни тела `task1`, `task2` и `task3` в `tasks.go`. Имена и параметры уже объявлены. Запуск: `go run .`. Проверка: `go test .`.
