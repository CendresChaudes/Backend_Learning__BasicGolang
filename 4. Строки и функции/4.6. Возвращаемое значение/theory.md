# 4.6. Возвращаемое значение

Возвращаемое значение — результат, который функция отдаёт наружу. Вызвавший код получает его и может положить в переменную.

В прошлом уроке `return` уже встречался. Здесь важно, где написан тип результата и что происходит в момент возврата.

## Тип результата

Тип пишут после списка параметров и до тела.

```go
func code() int {
	return 200
}
```

`int` значит: из функции выйдет целое число. `return 200` заканчивает функцию и отдаёт `200`.

Строки после `return` в этой функции уже не выполнятся. Управление возвращается к тому месту, где функцию вызвали.

```go
status := code()
fmt.Println(status)
```

`status` получает `200`. `Println` печатает уже это число, не вызывая `code` ещё раз.

## Выражение в return

Справа от `return` может стоять не только готовое число, но и выражение. Сначала оно считается, потом результат уходит наружу.

```go
func rest(left int, right int) int {
	return left - right
}
```

Вызов `rest(10, 3)` вернёт `7`. Тип выражения должен совпадать с типом после скобок. Строку из функции с типом `int` вернуть нельзя: программа не скомпилируется.

## Что запомнить

- Тип результата пишут между списком параметров и телом.
- `return` отдаёт значение и заканчивает функцию.
- Справа от `return` может быть выражение: его посчитают и вернут.
- Тип возвращённого значения совпадает с объявленным типом.

## Что сделать

Заполни `tasks.go`. В каждом задании один `return`. Запуск: `go run .`. Проверка: `go test .`.
