# 4.7. Упражнение Несколько значений возврата

Функция может вернуть не одно значение, а несколько. Их перечисляют в скобках после параметров. Порядок в `return` и порядок в этих скобках совпадают.

Так из одного вызова получают и число, и подпись к нему.

## Два результата

```go
func size() (int, int) {
	return 800, 600
}
```

`(int, int)` — два целых. `return 800, 600` отдаёт оба. Первое число — ширина, второе — высота. Кто есть кто, видно только по порядку.

Вызов принимает оба значения:

```go
width, height := size()
fmt.Println(width, height)
```

`width` станет `800`, `height` станет `600`. Слева имён столько же, сколько значений справа.

Если одно значение не нужно, на его место ставят `_`. Это пустое имя: значение есть, но сохранять его некуда.

```go
width, _ := size()
```

Здесь остаётся только ширина.

## Что запомнить

- Несколько типов результата пишут в скобках: `(int, int)`.
- `return` перечисляет значения в том же порядке.
- При вызове слева объявляют переменную на каждое значение.
- Лишнее значение принимают в `_`.

## Что сделать

Это упражнение. В `tasks.go` у каждого задания своя функция с двумя результатами. Вызови её из `task1`, `task2` или `task3` и верни то, о чём просит комментарий. Запуск: `go run .`. Проверка: `go test .`.
