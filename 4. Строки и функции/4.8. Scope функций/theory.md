# 4.8. Scope функций

Scope (область видимости) — участок программы, где имя можно прочитать. Одно и то же слово в другом участке может быть другой переменной или вообще не существовать.

У функции свой участок: её параметры и переменные, созданные внутри.

## Внутри функции

Параметр виден только в своей функции.

```go
func portLine(port int) int {
	return port
}
```

`port` существует, пока выполняется `portLine`. Снаружи этого имени нет. Другая функция может завести свой `port`, и это будет другое имя.

Переменная, созданная внутри через `:=`, тоже остаётся внутри.

## На уровне пакета

Переменная снаружи всех функций видна каждой функции этого пакета.

```go
var service = "api"

func current() string {
	return service
}
```

`service` объявлена на уровне пакета. `current` читает её и возвращает `"api"`.

## То же имя внутри

Если внутри функции написать `:=` с уже знакомым именем, появится новая переменная. Она закрывает внешнюю до конца функции.

```go
var service = "api"

func local() string {
	service := "worker"
	return service
}
```

`local` вернёт `"worker"`. Внешняя `service` останется `"api"`, потому что `:=` создал другую переменную.

Запись `service = "worker"` без двоеточия внешнюю переменную меняет. Нового имени нет, есть присваивание старому.

## Что запомнить

- Параметр и переменная внутри функции видны только в ней.
- Переменная на уровне пакета видна всем функциям пакета.
- `:=` с тем же именем создаёт внутреннюю переменную и закрывает внешнюю.
- `=` без двоеточия меняет уже существующую переменную.

## Что сделать

Заполни `tasks.go`. Переменная `service` уже объявлена снаружи функций. Запуск: `go run .`. Проверка: `go test .`.
