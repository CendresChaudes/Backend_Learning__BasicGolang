# 5.1. Типы данных

Дальше программа будет выбирать, какую ветку выполнить. Для выбора нужно значение типа `bool`. Вариантов два: `true` и `false`.

Такое значение получают сравнением. Сравнение — вопрос к двум значениям. Ответ всегда `bool`, даже если сравнивали числа или строки.

## Равенство

`==` спрашивает «это одно и то же?». `!=` спрашивает «это разное?».

```go
code := 200
same := code == 200
other := code != 404
```

`code == 200` считает сравнение. Оба числа равны, поэтому в `same` лежит `true`.

`code != 404` тоже `true`: `200` и `404` — разные числа. Знак `!=` как раз этого и ждёт.

Строки сравнивают теми же знаками. `"go"` и `"Go"` — разные строки: регистр буквы входит в значение.

## Порядок чисел

Для чисел есть знаки порядка. Результат снова `bool`.

```go
port := 8080
high := port > 1024
```

`>` значит «больше». `8080 > 1024` — это `true`, поэтому в `high` лежит `true`.

Остальные знаки:

- `<` — меньше.
- `>=` — больше или равно.
- `<=` — меньше или равно.

`1024 >= 1024` даёт `true`: равенство здесь тоже подходит.

## Один тип с двух сторон

С двух сторон сравнения стоит один тип. Число и строку через `==` сопоставить нельзя. Go не превращает типы сам.

```go
title := "8080"
port := 8080
```

`title == port` не скомпилируется. Слева `string`, справа `int`. Чтобы сравнить их как числа, строку сначала нужно прочитать в `int`. Это сделает позже функция вроде `fmt.Sscan`, не знак `==`.

## Что запомнить

- Сравнение возвращает `bool`: `true` или `false`.
- `==` — равно, `!=` — не равно.
- `<`, `>`, `<=`, `>=` сравнивают порядок чисел.
- С двух сторон сравнения стоит один и тот же тип.

## Что сделать

Заполни `tasks.go`. Каждая функция возвращает `bool`. Запуск: `go run .`. Проверка: `go test .`.
