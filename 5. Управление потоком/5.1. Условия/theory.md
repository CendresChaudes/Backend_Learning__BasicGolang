# 5.1. Условия

Программа выбирает ветку по значению типа `bool`. Вариантов два: `true` и `false`. Такое значение получают сравнением. Сравнение — вопрос к двум значениям. Ответ всегда `bool`, даже если сравнивали числа или строки.

## Сравнение

`==` спрашивает «это одно и то же?». `!=` спрашивает «это разное?». `>`, `<`, `>=`, `<=` сравнивают порядок.

```go
code := 200
ok := code == 200
```

`code == 200` имеет тип `bool`. Здесь оно равно `true`. Скобки вокруг сравнения не нужны.

## if

`if` выполняет блок, только когда условие равно `true`.

```go
func label(code int) string {
	if code == 200 {
		return "ok"
	}
	return "ошибка"
}
```

- `if` начинает проверку.
- `code == 200` — условие. Скобки вокруг него не пишут.
- `{ }` держат блок. Фигурные скобки обязательны, даже если внутри одна строка.
- `return "ok"` сразу выходит из функции. Строка `return "ошибка"` тогда не выполняется.
- Если условие `false`, блок пропускается.

`else` — блок на случай, когда условие ложно. Его пишут сразу после `}` первого блока. Если после `if` и так стоит общий `return`, отдельный `else` не обязателен.

## И, или, не

Логический оператор собирает несколько `bool` в одно. Операнд — значение, над которым оператор работает.

`&&` читается «и». Результат `true`, только когда оба операнда `true`. Если левый операнд уже `false`, правый не вычисляется.

`||` читается «или». Результат `true`, когда хотя бы один операнд `true`. Если левый уже `true`, правый не вычисляется.

`!` читается «не». Он переворачивает один `bool`: `!true` равно `false`.

```go
admin := true
active := false
allowed := admin && active
```

`allowed` равен `false`: человек администратор, но учётка не активна. Оба факта должны быть истинны.

## else if

`else if` добавляет ещё одну проверку. Она выполняется, только если предыдущее условие было `false`. Так выбирают одну подпись из трёх и больше.

```go
func mark(score int) string {
	if score >= 90 {
		return "отлично"
	} else if score >= 70 {
		return "хорошо"
	}
	return "ещё раз"
}
```

Цепочка идёт сверху вниз и останавливается на первом `true`. Оценка `95` вернёт `"отлично"` и не дойдёт до второй проверки.

## Что запомнить

- Сравнение даёт `bool`.
- `if` пускает в блок только при `true`. Скобки вокруг условия не нужны, фигурные скобки обязательны.
- `&&` требует оба `true`. `||` достаточно одного. `!` переворачивает значение.
- `else if` проверяют по порядку, срабатывает первая истинная ветка.
