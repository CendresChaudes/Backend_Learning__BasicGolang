# 5.10. Panic

`panic` останавливает обычный ход функции. Если это никто не перехватит, остановится вся программа.

Для обычной ошибки ввода `panic` не используют. Для неё есть `error`. `panic` оставляют поломке, после которой текущую работу продолжать нельзя.

## Остановка

```go
panic("авария")
```

В скобках — значение, которое унесёт с собой остановка. Часто это строка. Строки после `panic` в этой функции не выполняются.

## defer

`defer` откладывает вызов до выхода из функции. Он срабатывает и при обычном `return`, и при `panic`.

```go
defer fmt.Println("выход")
fmt.Println("работа")
```

Сначала напечатается `работа`, потом `выход`. Строка с `defer` записана выше, но выполнится в конце.

Отложить можно несколько строк. Для этого в `defer` передают функцию без имени и сразу ставят скобки вызова:

```go
defer func() {
	fmt.Println("выход")
}()
```

`func() { }` — функция без имени. `()` после неё значит «запомни этот вызов». Тело выполнится при выходе из внешней функции.

## recover

`recover` забирает значение из `panic` и гасит аварию. Программа продолжает работу. Вызывать `recover` нужно внутри `defer`. В другом месте он ничего не поймает и вернёт `nil`.

Чтобы отдать пойманный текст наружу, результату функции дают имя. Это именованный результат: обычная переменная, которую функция вернёт.

```go
func shout() (text string) {
	defer func() {
		caught := recover()
		if caught != nil {
			text = fmt.Sprint(caught)
		}
	}()
	panic("авария")
	return "тихо"
}
```

По строкам:

- `(text string)` — результат с именем `text`. Пока туда ничего не записали, там пустая строка.
- `defer` запоминает функцию без имени. Она выполнится, когда `shout` будет выходить.
- `panic("авария")` останавливает тело. До `return "тихо"` выполнение не доходит.
- При выходе срабатывает отложенная функция. `recover` возвращает `"авария"`.
- `caught != nil` значит, авария была. `fmt.Sprint` превращает пойманное значение в строку.
- Эта строка записывается в `text`. Её и получит тот, кто вызвал `shout`.

Если `panic` не было, `recover` вернёт `nil`. Условие `caught != nil` будет ложным, и `text` не перезапишут.

## Что запомнить

- `panic` останавливает функцию. Обычную ошибку сообщают через `error`.
- `defer` выполняется при выходе из функции.
- `recover` внутри `defer` ловит `panic`. Без аварии он возвращает `nil`.
- Именованный результат, например `(text string)`, можно заполнить из `defer`.

## Что сделать

Заполни `tasks.go`. Аварию перехватывай, чтобы функция могла вернуть ответ. Запуск: `go run .`. Проверка: `go test .`.
