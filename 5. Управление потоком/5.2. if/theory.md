# 5.2. if

`if` выполняет блок кода, только когда условие равно `true`. Условие — выражение типа `bool`. Его собирает сравнение из прошлого урока.

## Одна ветка

```go
func label(code int) string {
	if code == 200 {
		return "ok"
	}
	return "ошибка"
}
```

По строкам:

- `if` начинает проверку.
- `code == 200` — условие. Скобки вокруг него не пишут.
- `{ }` держат блок. Он выполнится, только если условие `true`.
- `return "ok"` сразу выходит из функции. Строка `return "ошибка"` тогда не выполняется.
- Если условие `false`, блок пропускается. Выполняется то, что написано после него.

Фигурные скобки обязательны, даже когда внутри одна строка.

## else

`else` — блок на случай, когда условие ложно.

```go
func label(code int) string {
	if code == 200 {
		return "ok"
	} else {
		return "ошибка"
	}
}
```

`else` пишут сразу после закрывающей скобки первого блока. Два блока сразу не выполняются: либо условие истинно и работает первый, либо ложно и работает `else`.

Если после `if` и так стоит общий `return`, отдельный `else` не обязателен. Первый пример делает то же самое, что второй.

## Что запомнить

- `if` пускает внутрь блока только при `true`.
- Условие имеет тип `bool`. Скобки вокруг него не нужны.
- Фигурные скобки обязательны.
- `else` выполняется, когда условие ложно.
