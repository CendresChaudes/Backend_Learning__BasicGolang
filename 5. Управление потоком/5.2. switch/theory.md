# 5.2. switch

`switch` выбирает ветку по одному значению. Им заменяют длинную цепочку `else if`, когда каждый раз сравнивают одну и ту же переменную через `==`.

## Ветки case

```go
func action(method string) string {
	switch method {
	case "GET":
		return "чтение"
	case "POST":
		return "запись"
	default:
		return "неизвестно"
	}
}
```

- `switch method` — значение, с которым сравнивают ветки.
- `case "GET":` срабатывает, когда `method` равен `"GET"`.
- `return` выходит из функции, поэтому `break` после ветки не пишут. В Go ветка `switch` сама не проваливается в следующую.
- `default` выполняется, если не подошёл ни один `case`.

Несколько значений можно записать в одной ветке через запятую: `case 6, 7:`.

## Что запомнить

- `switch` сравнивает одно значение с ветками `case`.
- Ветка не проваливается в следующую. `break` не нужен.
- `default` — ветка «ничего не подошло».

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
