# 5.3. Булева логика

Логический оператор собирает значения `bool` в одно `bool`. Так в условие `if` попадают два факта сразу.

Операнд — значение, над которым оператор работает. У `&&` и `||` операнда два. У `!` операнд один.

## И

`&&` читается «и». Результат `true`, только когда оба операнда `true`.

```go
admin := true
active := false
allowed := admin && active
```

`allowed` станет `false`. Первое значение истинно, второе ложно. Для `&&` нужны оба.

Если левый операнд уже `false`, правый Go не считает. Итог и так `false`.

## Или

`||` читается «или». Результат `true`, когда хотя бы один операнд `true`.

```go
code := 201
success := code == 200 || code == 201
```

Сначала считается `code == 200`. Это `false`. Потом `code == 201`. Это `true`. `false || true` даёт `true`, поэтому в `success` лежит `true`.

Если левый операнд уже `true`, правый не считается. Итог и так `true`.

## Не

`!` переворачивает один `bool`. Знак пишут перед значением.

```go
blocked := true
open := !blocked
```

`!true` — это `false`. `!false` — это `true`. В `open` лежит `false`: пользователь заблокирован, значит доступ не открыт.

## Скобки

Когда в одном выражении несколько операторов, поставь скобки. По ним видно, какие части связаны.

```go
allowed := admin && (active || local)
```

Сначала считается то, что в скобках. Потом результат связывается с `admin` через `&&`.

## Что запомнить

- `&&` даёт `true`, только если оба операнда `true`.
- `||` даёт `true`, если хотя бы один операнд `true`.
- `!` переворачивает `bool`.
- Скобки показывают, что с чем связано.
