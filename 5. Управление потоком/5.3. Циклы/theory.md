# 5.3. Циклы

Цикл повторяет блок, пока условие истинно. В Go для этого один оператор: `for`. Один проход тела называют итерацией. Счётчик — переменная, которая помнит, какая сейчас итерация.

## Три части

```go
sum := 0
for i := 1; i <= 3; i++ {
	sum = sum + i
}
```

- `i := 1` выполняется один раз перед циклом.
- `i <= 3` проверяется перед каждым проходом. Если оно `false`, цикл заканчивается.
- Тело прибавляет `i` к `sum`.
- `i++` увеличивает счётчик на 1 после прохода.

После трёх проходов `sum` равен `6`.

## break и continue

Иногда остановиться или пропустить проход нужно уже внутри тела.

`break` сразу выходит из цикла. Код после цикла выполняется дальше.

`continue` пропускает остаток текущего прохода и переходит к следующей итерации. У `for` с тремя частями перед этим всё равно выполнится шаг `i++`.

```go
sum := 0
for i := 1; i <= 5; i++ {
	if i == 3 {
		continue
	}
	if i == 5 {
		break
	}
	sum = sum + i
}
```

Число `3` пропускается. На `5` цикл заканчивается. В сумму входят `1`, `2` и `4`, поэтому `sum` равен `7`.

## Что запомнить

- В Go цикл — это `for`.
- Условие проверяется перед проходом.
- `break` выходит из цикла. `continue` пропускает остаток прохода.
