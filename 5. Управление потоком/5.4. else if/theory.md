# 5.4. else if

`else if` добавляет ещё одну проверку. Она выполняется, только если предыдущее условие было `false`.

Так выбирают одну подпись из трёх и больше, не вкладывая `if` внутрь `if`.

## Цепочка сверху вниз

```go
func mark(score int) string {
	if score >= 90 {
		return "отлично"
	} else if score >= 60 {
		return "зачёт"
	} else {
		return "незачёт"
	}
}
```

Проверки идут сверху вниз. Срабатывает первая, у которой условие `true`. Остальные уже не смотрят.

Для `95` истинна первая ветка. Функция вернёт `"отлично"`. До `>= 60` дело не дойдёт, хотя `95` тоже больше `60`.

Для `70` первая ветка ложна. Вторая истинна. Результат — `"зачёт"`.

Для `40` обе проверки ложны. Выполнится `else`, результат — `"незачёт"`.

`else` в конце не обязателен. Если его нет и ни одно условие не подошло, выполнение идёт дальше после всей цепочки.

Порядок решает. Более узкое условие пишут выше. Если поставить `score >= 60` первым, ветка `"отлично"` никогда не выполнится: `95` тоже проходит через `>= 60`.

## Что запомнить

- `else if` проверяется, только если прошлый `if` был ложен.
- Срабатывает первая истинная ветка.
- Более узкое условие пишут выше широкого.
- Конечный `else` ловит всё, что не подошло раньше.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
