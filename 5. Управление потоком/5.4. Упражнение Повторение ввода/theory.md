# 5.4. Упражнение Повторение ввода

Клавиатура в тесте недоступна. Числа лежат в одной строке, через пробел. Цикл читает их по одному, пока строка не кончится.

## Источник из строки

Пакет `strings` умеет сделать источник чтения из готовой строки.

```go
import "strings"

src := strings.NewReader("10 20 30")
```

`strings.NewReader` создаёт источник. Он помнит, какое место строки ещё не прочитано.

`fmt.Fscan` читает из источника очередное значение. Для числа тип переменной — `int`.

```go
var n int
_, err := fmt.Fscan(src, &n)
```

`&n` — адрес переменной, куда положить прочитанное число. Когда чисел больше нет, `err` не равен `nil`. Это сигнал закончить цикл.

```go
sum := 0
for {
	var n int
	_, err := fmt.Fscan(src, &n)
	if err != nil {
		break
	}
	sum = sum + n
}
```

Цикл `for` без условия крутится, пока из тела не вызовут `break`. Для строки `"10 20 30"` сумма равна `60`.

## Что запомнить

- `strings.NewReader` читает готовую строку как источник.
- `fmt.Fscan` кладёт очередное значение по адресу переменной.
- Ошибка чтения значит: числа кончились, цикл пора остановить через `break`.
