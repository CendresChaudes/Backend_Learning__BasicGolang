# 5.5. Error

`error` — тип для сообщения о неудаче. Функция возвращает его рядом с результатом. Вызывающий код сам решает, что делать. Программа при этом не останавливается.

## Текст ошибки

Пакет `errors` создаёт ошибку из строки.

```go
import "errors"

func port(value string) error {
	if value == "" {
		return errors.New("пустой порт")
	}
	return nil
}
```

`nil` в типе `error` значит: ошибки нет. Метод `Error` возвращает текст обратно: `errors.New("пустой порт").Error()` даёт строку `"пустой порт"`.

Обычная проверка выглядит так:

```go
err := port("")
if err != nil {
	fmt.Println(err.Error())
}
```

## panic

`panic` останавливает обычный ход функции. Если это никто не перехватит, остановится вся программа.

```go
panic("авария")
```

Строки после `panic` в этой функции не выполняются. Для обычной ошибки ввода `panic` не используют. Для неё есть `error`. `panic` оставляют поломке, после которой текущую работу продолжать нельзя: например, программа запущена без обязательной настройки, без которой дальше нет смысла работать.

## Что запомнить

- Обычная неудача — это `error`, не остановка программы.
- `nil` значит, что ошибки нет.
- `panic` обрывает функцию. Для проверки ввода его не берут.
