# 5.5. switch

`switch` выбирает ветку по одному значению. Им заменяют длинную цепочку `else if`, когда каждый раз сравнивают одну и ту же переменную через `==`.

## Ветки case

```go
func action(method string) string {
	switch method {
	case "GET":
		return "чтение"
	case "POST":
		return "создание"
	default:
		return "неизвестно"
	}
}
```

По строкам:

- `switch method` берёт значение, с которым будут сравнивать. Скобки вокруг него не пишут.
- `case "GET":` — ветка. Она выполнится, если `method` равен `"GET"`.
- После двоеточия пишут команды этой ветки.
- Как только ветка совпала, остальные `case` не проверяются. Отдельный `break` не пишут: Go сам выходит из `switch`.
- `default` выполняется, если не подошёл ни один `case`. Эту ветку можно не писать.

Для `"POST"` функция вернёт `"создание"`. Для `"PUT"` вернёт `"неизвестно"`.

## Несколько значений в одном case

Один `case` принимает список. Подойдёт любое значение из него.

```go
switch code {
case 200, 201:
	return "успех"
default:
	return "другое"
}
```

И `200`, и `201` попадут в первую ветку. Запятая между ними значит «или это, или это».

## Что запомнить

- `switch` сравнивает одно значение с вариантами `case`.
- После совпадения остальные ветки не выполняются. `break` не пишут.
- Несколько значений в одном `case` перечисляют через запятую.
- `default` — ветка, если ничего не совпало.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
