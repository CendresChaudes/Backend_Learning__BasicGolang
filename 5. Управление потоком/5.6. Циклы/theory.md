# 5.6. Циклы

Цикл повторяет блок, пока условие истинно. В Go для этого один оператор: `for`.

Один проход тела называют итерацией. Счётчик — переменная, которая помнит, какая сейчас итерация.

## Три части

```go
sum := 0
for i := 1; i <= 3; i++ {
	sum = sum + i
}
```

В заголовке `for` три части. Их делят точкой с запятой.

- `i := 1` выполняется один раз, до повторов. Здесь создаётся счётчик.
- `i <= 3` проверяется перед каждой итерацией. Если получится `false`, цикл останавливается. Тело при этом не выполняется.
- `i++` выполняется после каждой итерации. `i++` — короткая запись `i = i + 1`.

По шагам `sum` станет `1`, потом `3`, потом `6`. Когда `i` дойдёт до `4`, условие `i <= 3` ложно. Цикл закончится.

Имя `i` видно только внутри `for`. Снаружи этого счётчика нет.

## Только условие

Если старт и шаг не нужны, оставляют одну часть — условие.

```go
n := 3
for n > 0 {
	n = n - 1
}
```

Перед каждым заходом Go проверяет `n > 0`. Тело уменьшает `n`. После третьей итерации `n` равен `0`, условие ложно, цикл останавливается.

Так пишут, когда заранее неизвестно число повторов, но известно, когда остановиться.

## Что запомнить

- В Go цикл пишут через `for`.
- Три части заголовка: старт, условие, шаг. Между ними стоит `;`.
- `i++` увеличивает число на 1.
- Форма с одним условием повторяется, пока это условие `true`.

## Что сделать

Заполни `tasks.go`. Считай результат циклом `for`. Запуск: `go run .`. Проверка: `go test .`.
