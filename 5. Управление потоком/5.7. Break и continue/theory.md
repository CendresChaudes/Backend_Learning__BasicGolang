# 5.7. Break и continue

Условие в заголовке `for` проверяется перед проходом. Иногда остановиться или пропустить проход нужно уже внутри тела. Для этого есть `break` и `continue`.

## break

`break` сразу выходит из цикла. Код после цикла выполняется дальше.

```go
sum := 0
for i := 1; i <= 10; i++ {
	if i == 4 {
		break
	}
	sum = sum + i
}
```

Счётчик дойдёт до `4`. Условие `i == 4` истинно, `break` остановит цикл. Числа `5` и дальше не прибавятся. В `sum` будет `6`: это `1 + 2 + 3`.

## continue

`continue` пропускает остаток тела и переходит к следующей итерации. Шаг заголовка при этом выполняется.

```go
sum := 0
for i := 1; i <= 5; i++ {
	if i%2 == 0 {
		continue
	}
	sum = sum + i
}
```

`%` — остаток от деления. `i%2` — остаток от деления `i` на `2`. У чётного числа этот остаток равен `0`.

Для `2` и `4` срабатывает `continue`. Строка `sum = sum + i` для них не выполняется. В `sum` попадёт `1 + 3 + 5`, это `9`.

## Цикл без условия

`for` можно написать без трёх частей. Такой цикл не проверяет условие сам. Остановить его можно через `break`.

```go
n := 1
for {
	if n > 3 {
		break
	}
	n = n + 1
}
```

Пока `n` не больше `3`, тело увеличивает `n`. Когда `n` станет `4`, `break` выходит из цикла.

Без `break` этот цикл не закончится. Программа зависнет на этом месте.

## Что запомнить

- `break` выходит из цикла.
- `continue` пропускает остаток текущей итерации.
- `%` даёт остаток от деления. У чётного числа `i%2` равен `0`.
- `for` без условия останавливают через `break`.
