# 5.8. Упражнение Повторение ввода

Клавиатура в тесте недоступна. Числа лежат в одной строке, через пробел. Цикл читает их по одному, пока строка не кончится.

## Источник из строки

Пакет `strings` умеет сделать источник чтения из готовой строки. Его подключают отдельно:

```go
import "strings"
```

`strings.NewReader` создаёт этот источник. Он помнит, какое место строки ещё не прочитано.

```go
reader := strings.NewReader("4 8 15")
```

`"4 8 15"` — три числа. Пробел их разделяет.

## Одно число за повтор

`fmt.Fscan` читает следующее значение из источника и записывает его в переменную. Первый результат — сколько значений удалось прочитать.

```go
sum := 0
for {
	var n int
	read, _ := fmt.Fscan(reader, &n)
	if read == 0 {
		break
	}
	sum = sum + n
}
```

По строкам:

- `for` без условия крутится, пока его не остановит `break`.
- `var n int` создаёт число для очередного куска.
- `fmt.Fscan(reader, &n)` читает следующее число в `n`. Знак `&` значит «запиши сюда», как у `fmt.Scan`.
- `read, _ :=` забирает два результата. Второй — ошибка чтения. Её тип будет в следующем уроке. Пока на её месте `_`: значение есть, хранить его не нужно.
- `read == 0` значит, чисел больше нет. `break` выходит из цикла.
- Иначе `n` прибавляют к `sum`.

Для строки `"4 8 15"` в `sum` будет `27`.

## Что запомнить

- `strings.NewReader` читает готовую строку по частям.
- `fmt.Fscan` забирает следующее значение. Первый результат — сколько значений он записал.
- `0` значит, ввод кончился. Тогда нужен `break`.
- Второй результат `Fscan` пока отбрасывают через `_`.

## Что сделать

Это упражнение. В каждом задании прочитай строку циклом. Запуск: `go run .`. Проверка: `go test .`.
