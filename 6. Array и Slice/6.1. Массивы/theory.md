# 6.1. Массивы

Массив (array) — несколько значений одного типа, которые лежат подряд. Сколько их, записано в самом типе. Массив из трёх чисел и массив из четырёх чисел — разные типы.

## Тип с длиной

```go
var codes [3]int
```

`[3]int` читается так: массив из трёх `int`. Число в квадратных скобках — длина. Её задают сразу, потом она не меняется.

Пока ячейкам ничего не присвоили, в каждой лежит нулевое значение типа. Для `int` это `0`.

Литерал сразу кладёт значения:

```go
codes := [3]int{200, 404, 500}
```

Индекс начинается с нуля. `codes[0]` — это `200`, `codes[1]` — `404`, `codes[2]` — `500`. Индекс за границей останавливает программу через `panic`.

## Запись в ячейку

Ячейку можно заменить. Длина от этого не меняется.

```go
codes[1] = 201
```

`codes[1]` становится `201`. Соседние ячейки остаются прежними. `len(codes)` по-прежнему равен `3`.

Функция получает копию массива. Правка копии снаружи не видна. Чтобы изменить исходный массив, позже передают указатель. Это будет в главе про указатели.

## Что запомнить

- Длина массива — часть типа и не растёт.
- Индекс начинается с `0`.
- Запись в ячейку меняет значение, но не длину.
