# 6.1. Массивы

Массив (array) — несколько значений одного типа, которые лежат подряд. Сколько их, записано в самом типе. Массив из трёх чисел и массив из четырёх чисел — разные типы, их нельзя присвоить друг другу.

## Тип с длиной

```go
var codes [3]int
```

`[3]int` читается так: массив из трёх `int`. Число в квадратных скобках — длина. Её задают сразу, потом она не меняется.

Пока ячейкам ничего не присвоили, в каждой лежит нулевое значение типа. Для `int` это `0`.

## Литерал

Литерал — значение, записанное прямо в коде.

```go
codes := [3]int{200, 404, 500}
```

`:=` создаёт переменную. Справа массив из трёх чисел в том порядке, в каком они стоят в фигурных скобках.

## Индекс

Индекс — номер ячейки. Счёт начинается с нуля. У массива из трёх ячеек индексы `0`, `1` и `2`.

```go
first := codes[0]
```

`codes[0]` читает первую ячейку. В `first` попадёт `200`. Скобки после имени — обращение к ячейке, число внутри — индекс.

Вторая ячейка — `codes[1]`, в ней `404`. Третья — `codes[2]`, в ней `500`.

## Что запомнить

- Длина массива входит в тип: `[3]int` и `[4]int` — разные типы.
- Длина фиксирована.
- Индекс первой ячейки — `0`, последней — длина минус один.
- Ячейка без значения хранит нулевое значение своего типа.
