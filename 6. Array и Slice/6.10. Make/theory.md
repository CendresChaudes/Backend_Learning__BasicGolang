# 6.10. Make

`make` создаёт срез нужной длины. Ячейки сразу заполнены нулевым значением типа. Литерал `[]int{200, 404}` задаёт сами числа. `make` задаёт размер, когда числа появятся позже.

## Длина

```go
codes := make([]int, 3)
```

`make` — встроенная функция. Первый аргумент — тип среза. Второй — `len`.

`len(codes)` равен `3`. В каждой ячейке `0`. В них уже можно писать: `codes[0] = 200`. Индекс `3` по-прежнему за границей и вызывает `panic`.

## Вместимость

Третий аргумент — `cap`. Его ставят не меньше `len`.

```go
codes := make([]int, 2, 5)
```

Видны две ячейки, обе равны `0`. `cap(codes)` равен `5`: в массиве есть запас ещё на три элемента. Прочитать `codes[2]` нельзя, пока `len` равен `2`. Этот запас потом занимает `append`.

`make([]int, 0)` тоже пустой по длине, но это уже созданный срез, не `nil`. Для `append` оба варианта принимают новые элементы.

## Что запомнить

- `make([]T, n)` создаёт срез длины `n`. Ячейки равны нулевому значению `T`.
- Третий аргумент — `cap`. Он не меньше `len`.
- Индекс законен, когда он меньше `len`.
- Литерал заполняет значения. `make` задаёт размер.
