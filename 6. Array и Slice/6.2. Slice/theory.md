# 6.2. Slice

Срез (slice) — окно в массив. Длина в тип среза не входит. Один и тот же тип `[]int` подходит и к окну из двух чисел, и к окну из десяти.

## Литерал

```go
codes := []int{200, 404, 500}
```

Квадратные скобки пустые: это срез, не массив `[3]int`. Ячейка читается так же: `codes[0]`.

Окно по краям берут срезом существующего среза. Правый индекс не входит в окно.

```go
window := codes[1:3]
```

`window` видит `404` и `500`. Это не копия чисел, а другое окно на те же ячейки.

## len и cap

`len` — сколько элементов видно в окне. Индекс при чтении должен быть меньше этого числа.

`cap` — сколько ячеек есть в массиве под окном, начиная с начала окна. `cap` всегда не меньше `len`.

```go
n := len(codes)
room := cap(codes)
```

Для литерала из трёх чисел и `len`, и `cap` равны `3`.

## append и make

`append` дописывает элементы в конец и возвращает срез уже с ними. Результат нужно записать обратно: `append` может вернуть другое окно.

```go
codes = append(codes, 500)
```

Пока `len` меньше `cap`, новый элемент пишется в тот же массив. Когда свободных ячеек нет, `append` создаёт массив больше и копирует старые элементы. Точный новый размер выбирает Go. Его читают через `cap`, формулой не считают. Поэтому в переменную всегда кладут срез, который вернул `append`.

Несколько значений дописывают сразу: `append(codes, 500, 201)`.

`make` создаёт срез нужной длины. Ячейки заполнены нулевым значением. Третий аргумент — `cap`, если место под рост нужно заранее.

```go
codes := make([]int, 2, 4)
```

`len` равен `2`, `cap` равен `4`. В ячейки уже можно писать: `codes[0] = 200`.

## Что запомнить

- `[]int` — срез. Длина в тип не входит.
- `len` — сколько видно. `cap` — сколько места есть под окном.
- Результат `append` записывают обратно в переменную.
- `make` задаёт длину, а при трёх аргументах ещё и вместимость.
