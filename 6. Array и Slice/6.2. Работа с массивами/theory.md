# 6.2. Работа с массивами

Ячейку массива можно заменить. Длина от этого не меняется: на место старого значения встаёт новое.

## Запись

```go
codes := [3]int{200, 404, 500}
codes[1] = 201
```

`codes[1] = 201` пишет `201` во вторую ячейку. `codes[0]` остаётся `200`, `codes[2]` остаётся `500`.

Индекс должен попадать в массив. У трёх ячеек последний законный индекс — `2`. Индекс `3` или `-1` останавливает программу через `panic`: ячейки с таким номером нет.

## Копия при присваивании

Присваивание массива копирует каждую ячейку. Новая переменная хранит свой набор.

```go
original := [3]int{1, 2, 3}
clone := original
clone[0] = 9
```

`clone := original` переписывает три числа в `clone`. `clone[0] = 9` меняет только эту копию. `original[0]` по-прежнему `1`.

Поменять две ячейки одного массива местами можно так: справа сначала читаются старые значения, потом они записываются в новые места.

```go
methods := [2]string{"GET", "POST"}
methods[0], methods[1] = methods[1], methods[0]
```

После этого в первой ячейке `"POST"`, во второй `"GET"`.

## Что запомнить

- `a[i] = value` заменяет одну ячейку. Длина массива та же.
- Законный индекс идёт от `0` до длины минус один. Иной индекс вызывает `panic`.
- Присваивание массива копирует все ячейки. Правка копии оставляет исходный массив прежним.

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
