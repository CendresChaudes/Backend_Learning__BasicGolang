# 6.3. Циклы по срезу

`range` обходит массив или срез. На каждом шаге он отдаёт индекс и копию элемента. Границу `len` писать самому уже не нужно.

## Индекс и значение

```go
codes := []int{200, 404, 500}
for i, code := range codes {
	fmt.Println(i, code)
}
```

`i` — индекс, начиная с `0`. `code` — копия числа в этой ячейке. Правка `code` саму ячейку не меняет. Чтобы заменить ячейку, пишут `codes[i] = ...`.

Если индекс не нужен, на его место ставят `_`:

```go
sum := 0
for _, code := range codes {
	sum = sum + code
}
```

`_` говорит: это значение есть, но имя ему не нужно. Сумма здесь равна `1104`.

Пустой срез и `nil` дают ноль проходов. Тело цикла не выполняется.

## Что запомнить

- `range` отдаёт индекс и копию элемента.
- Неиспользуемый индекс заменяют на `_`.
- Копия в переменной цикла ячейку среза не меняет.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
