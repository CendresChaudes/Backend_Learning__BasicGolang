# 6.4. Упражнение Расчёт баланса

Баланс — сколько денег есть сейчас. Его начинают с известного числа и по очереди прибавляют транзакции. Положительное число увеличивает баланс. Отрицательное уменьшает.

Список операций хранят срезом `[]int`. Сколько их придёт, в типе не записано.

## Обход

Цикл `range` доходит до каждой операции. Индекс здесь не нужен.

```go
balance := start
for _, op := range ops {
	balance = balance + op
}
```

Старт `100` и операции `50, -30, -20` дают баланс `100`.

Расход — отрицательная операция. Чтобы получить сумму расходов положительным числом, такие операции берут со знаком минус, а приходы пропускают.

## Что запомнить

- Баланс начинают со старта и прибавляют операции по одной.
- Отрицательное число — расход.
- Пустой срез операций оставляет баланс равным старту.
