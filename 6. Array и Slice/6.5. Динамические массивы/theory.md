# 6.5. Динамические массивы

Длина массива записана в типе и не растёт. Срез может стать длиннее: встроенная функция `append` дописывает элементы в конец и возвращает срез уже с ними.

Такой растущий срез называют динамическим массивом. Число элементов становится известно по ходу работы, а не в момент объявления типа.

## Один новый элемент

```go
codes := []int{200, 404}
codes = append(codes, 500)
```

`append` принимает срез и значения, которые нужно добавить. Она возвращает срез. Старое имя само не обновляется, поэтому результат записывают обратно: `codes = append(...)`.

После этого `len(codes)` равен `3`, а `codes[2]` равен `500`.

За один вызов добавляют и несколько значений:

```go
codes = append(codes, 201, 204)
```

## Пустой срез

```go
var codes []int
codes = append(codes, 200)
```

`var codes []int` создаёт срез без массива. Это значение `nil`: смотреть некуда, `len` равен `0`. `nil` ты уже видел у `error` — там тоже «значения нет».

`append` с таким срезом работает. Появится массив, и в `codes` ляжет окно на него. Внутри будет одно число, `200`.

Если в текущем массиве ещё есть место (`len` меньше `cap`), `append` занимает следующую ячейку. Если места нет, Go берёт новый массив побольше и копирует туда старые элементы. Как именно растёт `cap`, будет в отдельном уроке.

## Что запомнить

- `append` дописывает элементы в конец среза и возвращает новый срез.
- Результат записывают обратно: `s = append(s, x)`.
- Пустой срез `nil` тоже можно передать в `append`.
- Растёт срез. Длина самого типа массива по-прежнему фиксирована.
