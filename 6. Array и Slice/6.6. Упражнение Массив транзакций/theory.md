# 6.6. Упражнение Массив транзакций

Транзакция здесь — одно изменение денег. Положительное число — приход. Отрицательное — расход. Ноль денег не двигает.

В названии упражнения слово «массив» стоит в бытовом смысле: список. В коде список хранят срезом `[]int`. Сколько операций придёт, в типе не записано, поэтому длина массива здесь не подходит.

## Обход по индексу

Цикл `for` из главы про управление потоком доходит до каждой ячейки. Граница — `len`.

```go
sum := 0
for i := 0; i < len(ops); i++ {
	sum = sum + ops[i]
}
```

`i` бежит от `0` до `len(ops)`, правый край в сравнение не входит. `ops[i]` — очередная транзакция.

Для `[]int{100, -40, 25}` сумма станет `85`: `100 + (-40) + 25`.

Тот же цикл годится для фильтра. Расход узнают сравнением `ops[i] < 0`. Приход — сравнением `ops[i] > 0`.

## Что запомнить

- Список транзакций — срез `[]int`.
- `for i := 0; i < len(ops); i++` проходит каждую ячейку.
- Число больше нуля — приход, меньше нуля — расход.

## Что сделать

Это упражнение. Функции уже принимают срез `ops`. Запуск: `go run .`. Проверка: `go test .`.
