# 6.7. Unpack

Три точки `...` работают с набором значений. В параметре они собирают аргументы в срез. В вызове они раскрывают готовый срез обратно в отдельные аргументы. Раскрытие и называют unpack, распаковкой.

## Собрать аргументы

Последний параметр можно записать как `name ...T`. Такая функция принимает нуль или больше аргументов типа `T`. Внутри функции они лежат в срезе.

```go
func total(nums ...int) int {
	sum := 0
	for i := 0; i < len(nums); i++ {
		sum = sum + nums[i]
	}
	return sum
}
```

`nums ...int` — ноль или больше чисел. Вызов `total(10, 20, 30)` кладёт их в срез `nums`. `len(nums)` равен `3`, сумма равна `60`.

Вызов без аргументов тоже законный: `total()`. Срез внутри пустой, сумма равна `0`.

## Раскрыть срез

В такой параметр срез по имени не передать: функция ждёт отдельные значения. Три точки после среза раскрывают его.

```go
ops := []int{10, 20, 30}
sum := total(ops...)
```

`ops...` передаёт `10`, `20` и `30` по одному. Это тот же вызов, что `total(10, 20, 30)`.

`append` устроен так же. После первого среза он ждёт отдельные элементы. Второй срез туда раскрывают теми же тремя точками.

```go
extra := []int{201, 204}
codes = append(codes, extra...)
```

`extra...` подставляет `201` и `204` как два аргумента. Оба оказываются в конце `codes`.

## Что запомнить

- `nums ...int` в параметре собирает аргументы вызова в срез.
- `ops...` в вызове раскрывает срез в отдельные аргументы.
- Второй срез в `append` передают так же: `append(base, extra...)`.
