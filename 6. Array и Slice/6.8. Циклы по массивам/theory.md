# 6.8. Циклы по массивам

`range` обходит массив или срез. На каждом шаге он отдаёт индекс и копию элемента. Границу `len` писать самому уже не нужно.

## Индекс и значение

```go
codes := []int{200, 404, 500}
for i, code := range codes {
	fmt.Println(i, code)
}
```

`range codes` перебирает `codes`. Слева два имени: `i` — индекс, `code` — копия числа из этой ячейки.

Три прохода выглядят так:

- `i` равен `0`, `code` равен `200`
- `i` равен `1`, `code` равен `404`
- `i` равен `2`, `code` равен `500`

Тот же заголовок работает с массивом `[3]int`. Меняется только то, что стоит после `range`.

## Копия элемента

`code` — отдельная переменная на время шага. Запись в неё оставляет срез прежним.

```go
for _, code := range codes {
	code = 0
}
```

`_` выбрасывает индекс. Место слева от запятой обязательно, если справа нужно значение, а номер ячейки не нужен. После цикла в `codes` по-прежнему `200`, `404` и `500`.

Ячейку меняют по индексу: `codes[i] = 0`.

Если нужен только индекс, второе имя опускают: `for i := range codes`.

## Что запомнить

- `for i, v := range s` даёт индекс и копию элемента.
- Так обходят и массив, и срез.
- `_` ставят на место индекса, когда номер не нужен.
- Правка копии срез не меняет. Ячейку записывают через `s[i]`.

## Что сделать

Заполни `tasks.go`. Обходи срезы через `range`. Запуск: `go run .`. Проверка: `go test .`.
