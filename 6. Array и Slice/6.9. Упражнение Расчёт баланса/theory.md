# 6.9. Упражнение Расчёт баланса

Баланс — сколько денег есть сейчас. Его начинают с известного числа и по очереди прибавляют транзакции. Положительное число увеличивает баланс. Отрицательное уменьшает: `100 + (-40)` равно `60`.

## Итог после всех операций

```go
balance := start
for _, op := range ops {
	balance = balance + op
}
```

`balance` стартует со `start`. `range` отдаёт каждую операцию в `op`, индекс здесь не нужен, поэтому на его месте `_`.

Для старта `100` и среза `[]int{50, -30, -20}` баланс закончится на `100`.

## Расход без минуса

Расход в списке записан отрицательным числом. Сумма трат нужна положительной: сколько денег ушло.

У отрицательного `op` смена знака даёт положительное число. Её пишут минусом перед именем: `-op`. Для `-40` значение `-op` равно `40`. Перед сменой знака проверяют `op < 0`, чтобы приход в эту сумму не попал.

## Промежуточный баланс

Промежуточный баланс — сумма после очередной операции, ещё до конца списка. Его сравнивают внутри того же цикла, пока `balance` уже обновлён.

Для старта `0` и операций `10, -4` после первого шага баланс равен `10`, после второго — `6`.

## Что запомнить

- Итоговый баланс — старт плюс все транзакции по очереди.
- `for _, op := range ops` отдаёт каждую транзакцию.
- Минус перед отрицательным числом делает его положительным.
