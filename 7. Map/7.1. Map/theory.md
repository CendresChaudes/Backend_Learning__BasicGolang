# 7.1. Map

Массив и срез находят элемент по номеру. Map находит значение по ключу. Ключ — это имя, под которым значение лежит.

Map (произносят «мэп») — набор пар «ключ — значение». В одной map все ключи одного типа и все значения одного типа. Тип пишут так: `map[тип ключа]тип значения`.

Ключом чаще всего бывает строка или число. Эти типы можно сравнить через `==`. Срез ключом быть не может.

## Литерал

```go
codes := map[string]int{
	"ok":      200,
	"missing": 404,
}
```

`codes["ok"]` равно `200`. Если ключа нет, чтение возвращает нулевое значение типа. Для `int` это `0`. По одному нулю не понять, ключа не было или значение и правда `0`.

Вторая величина при чтении отвечает на этот вопрос:

```go
value, ok := codes["ok"]
```

`ok` равен `true`, если ключ был. Если ключа нет, `ok` равен `false`, а `value` — нулевое значение.

## Запись, удаление, make

Одна и та же запись и добавляет новый ключ, и заменяет существующий.

```go
codes["ok"] = 201
delete(codes, "missing")
```

`delete` стирает пару. Если ключа не было, ничего не происходит.

`make` создаёт пустую map, в которую уже можно писать. В литерале пары есть сразу. В `make` пар ещё нет.

```go
codes := make(map[string]int)
```

`len(codes)` равен `0`. Запись `nil`-map вызывает `panic`. Пустую map перед записью создают через `make` или литерал `map[string]int{}`.

## Что запомнить

- Map ищет значение по ключу, не по номеру.
- Чтение отсутствующего ключа даёт нулевое значение. `ok` показывает, был ли ключ.
- Запись по ключу добавляет или заменяет. `delete` удаляет пару.
- В `nil`-map писать нельзя. Сначала `make` или литерал.
