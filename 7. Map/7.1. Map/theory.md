# 7.1. Map

Массив и срез находят элемент по номеру. Map находит значение по ключу. Ключ — это имя, под которым значение лежит.

Map (произносят «мэп») — набор пар «ключ — значение». В одной map все ключи одного типа и все значения одного типа. Тип пишут так: `map[тип ключа]тип значения`.

Ключом чаще всего бывает строка или число. Эти типы можно сравнить через `==`. Срез ключом быть не может: у среза нет сравнения через `==`.

## Литерал

Литерал — запись значения прямо в коде.

```go
codes := map[string]int{
	"ok":      200,
	"missing": 404,
}
```

`map[string]int` значит: ключ — строка, значение — целое число. Ключ `"ok"` связан с `200`. Ключ `"missing"` связан с `404`.

Запятая после последней пары в такой записи с новой строки обязательна. Так компилятор понимает, где пара заканчивается.

## Чтение по ключу

Значение достают квадратными скобками. Внутри скобок стоит ключ.

```go
code := codes["ok"]
```

В `code` лежит `200`.

Если ключа нет, чтение ошибкой не считается. Оно возвращает нулевое значение типа. Для `int` это `0`. Для `string` это пустая строка `""`.

```go
unknown := codes["nope"]
```

Ключа `"nope"` в `codes` нет. В `unknown` лежит `0`.

## Сколько пар

`len` для map считает пары.

```go
n := len(codes)
```

В `codes` две пары, поэтому `n` равен `2`.

Пустой литерал `map[string]int{}` создаёт map без пар. `len` у него равен `0`. В такую map уже можно записывать новые пары. Запись, замена и удаление — следующий урок.

## Что запомнить

- Map хранит пары «ключ — значение». Тип пишут как `map[K]V`.
- Чтение выглядит так: `m[ключ]`.
- Если ключа нет, приходит нулевое значение типа `V`.
- `len(m)` — сколько пар сейчас лежит в map.
