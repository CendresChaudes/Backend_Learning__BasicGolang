# 7.2. Изменение Map

Пара в map меняется по ключу. Новый ключ добавляет пару. Уже существующий ключ заменяет значение. Отдельная функция стирает пару.

## Запись

Одна и та же запись делает и добавление, и замену.

```go
codes := map[string]int{
	"ok": 200,
}
codes["missing"] = 404
codes["ok"] = 201
```

Ключа `"missing"` не было. Строка `codes["missing"] = 404` добавляет пару. `len(codes)` становится равным `2`.

Ключ `"ok"` уже был. Новая запись кладёт `201` на место `200`. Второй пары с ключом `"ok"` не появляется. `len(codes)` остаётся `2`.

Писать можно в map из литерала, в том числе в пустой `map[string]int{}`. Переменная без литерала и без `make` равна nil. Запись в nil-map останавливает программу: возникает panic. Как создать map через `make`, будет в конце главы.

## delete

`delete` — встроенная функция. Она убирает пару по ключу. Пакет для неё подключать не нужно.

```go
delete(codes, "ok")
```

После вызова ключа `"ok"` в map нет. `len` уменьшается на один.

Если такого ключа и не было, `delete` ничего не делает. Panic при этом нет.

## Ноль и отсутствующий ключ

Чтение ключа, которого нет, возвращает ноль. Ноль бывает и настоящим записанным значением. По одному числу `0` эти два случая не различить.

Второе имя при чтении отвечает, был ли ключ. Его обычно называют `ok`. Это обычная переменная типа `bool`.

```go
codes := map[string]int{
	"draft": 0,
}
value, ok := codes["draft"]
```

`value` равен `0`: в паре правда лежит ноль. `ok` равен `true`: ключ `"draft"` в map есть.

```go
missing, found := codes["nope"]
```

Ключа `"nope"` нет. `missing` равен `0`, а `found` равен `false`.

Форму `value, ok := m[ключ]` используют, когда ноль может быть настоящим значением.

## Что запомнить

- `m[ключ] = значение` добавляет пару или заменяет значение старого ключа.
- `delete(m, ключ)` удаляет пару. Чужой ключ panic не вызывает.
- Запись в nil-map вызывает panic.
- `value, ok := m[ключ]`. `ok` равен `false`, когда ключа нет.
