# 7.2. Итерация по Map

Итерация — проход по всем элементам. У map нет номеров `0, 1, 2`, поэтому цикл со счётчиком индекса здесь не из чего собрать. Все пары отдаёт `range`.

## Ключ и значение

```go
codes := map[string]int{
	"ok":      200,
	"missing": 404,
}
sum := 0
for key, value := range codes {
	fmt.Println(key, value)
	sum = sum + value
}
```

На каждом шаге `key` — копия ключа, `value` — копия значения. Сумма значений здесь равна `604`.

Порядок пар не зафиксирован. Два запуска могут напечатать пары в разном порядке. На этот порядок нельзя опираться: не собирай строку ключей «как повезло». Считать сумму, количество или искать конкретный ключ можно: результат от порядка не зависит.

Если нужен только ключ, значение заменяют на `_`. Если нужно только значение, ключ заменяют на `_`.

## Что запомнить

- Map обходят через `range`: ключ и значение.
- Порядок пар каждый раз может быть другим.
- Для ответа бери то, что от порядка не зависит: сумму, количество, наличие ключа.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
