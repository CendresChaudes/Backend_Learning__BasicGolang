# 7.3. Итерация по Map

Итерация — проход по всем элементам. У map нет номеров `0, 1, 2`, поэтому цикл со счётчиком индекса здесь не из чего собрать. Все пары отдаёт `range`.

## Ключ и значение

```go
codes := map[string]int{
	"ok":      200,
	"missing": 404,
}
for key, value := range codes {
	fmt.Println(key, value)
}
```

`range` после `for` перебирает map. На каждом шаге `key` получает очередной ключ, `value` — значение этой пары. Одна итерация печатает `ok` и `200`. Другая печатает `missing` и `404`.

Порядок пар язык не фиксирует. В одном запуске первой может быть пара `"ok"`. В другом первой окажется `"missing"`. Сумма значений от этого порядка не меняется. Поиск одной нужной пары тоже. Ждать от `range` алфавитный порядок не стоит.

## Только ключ

Если значение на этом шаге не нужно, второе имя не пишут.

```go
for key := range codes {
	fmt.Println(key)
}
```

Цикл печатает ключи: `ok` и `missing`. В каком порядке — решает запуск.

## Только значение

Если ключ не нужен, на его месте пишут `_`. Пустое имя `_` значит: значение получено и сразу отброшено. Отдельная переменная под него не заводится.

```go
sum := 0
for _, value := range codes {
	sum = sum + value
}
```

В `sum` попадёт `200 + 404`. Это `604`.

`range` по nil-map тело не выполняет и panic не вызывает. Переменная `var codes map[string]int` для такого цикла безопасна: пар нет, проходить не по чему.

## Что запомнить

- `for key, value := range m` проходит по всем парам.
- Порядок пар от запуска к запуску может меняться.
- `for key := range m` отдаёт только ключи.
- `for _, value := range m` отдаёт только значения.
