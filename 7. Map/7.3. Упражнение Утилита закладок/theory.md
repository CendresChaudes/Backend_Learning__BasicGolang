# 7.3. Упражнение Утилита закладок

Закладка — короткое имя и адрес страницы. Имя удобно положить в ключ, адрес — в значение. Тип такой коллекции: `map[string]string`.

```go
marks := map[string]string{
	"docs": "https://go.dev",
}
```

Ключ `"docs"` — имя, которое человек помнит. Значение — адрес, который по этому имени открывают.

Если имени нет, чтение даёт пустую строку. Чтобы отличить «нет закладки» от пустого адреса, смотри второе значение `ok`.

Запись `marks[name] = url` добавляет новую закладку или заменяет адрес у уже известного имени. `len(marks)` после записи — сколько закладок стало.

## Что запомнить

- Имя закладки — ключ, адрес — значение.
- Нет ключа — отдельный факт, его показывает `ok`.
- Повторная запись по тому же имени заменяет адрес и не увеличивает длину.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
