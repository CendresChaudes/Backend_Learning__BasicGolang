# 7.4. Упражнение Утилита закладок

Закладка — короткое имя и адрес страницы. Имя удобно положить в ключ, адрес — в значение. Тип такой коллекции: `map[string]string`.

```go
marks := map[string]string{
	"docs": "https://go.dev",
}
```

Ключ `"docs"` — имя, которое человек помнит. Значение — адрес, который по этому имени открывают.

## Найти адрес

Чтение по имени возвращает адрес.

```go
url := marks["docs"]
```

В `url` лежит `"https://go.dev"`. Если имени в map нет, чтение даёт пустую строку. Для `string` нулевое значение — это `""`.

## Имя уже занято

Пустая строка может быть и адресом, который ещё не заполнили. Наличие имени проверяют второй переменной `ok`.

```go
_, ok := marks["docs"]
```

Адрес в этом месте не нужен, поэтому первое имя — `_`. `ok` равен `true`: ключ `"docs"` уже есть.

Для чужого имени `ok` будет `false`.

## Записать закладку

Запись по ключу и создаёт имя, и меняет адрес.

```go
marks["blog"] = "https://go.dev/blog"
```

Имени `"blog"` не было. Пара добавляется, `len(marks)` увеличивается на один.

Если записать другой адрес в уже существующее имя, старый адрес заменяется. Число пар остаётся прежним: ключ тот же.

```go
marks["docs"] = "https://go.dev/doc"
```

Ключ `"docs"` на месте. Значение теперь `"https://go.dev/doc"`. `len(marks)` не вырос.

## Что запомнить

- Закладки хранят в `map[string]string`: имя в ключе, адрес в значении.
- Чтение по имени возвращает адрес. Нет имени — пустая строка.
- `_, ok := marks[имя]` показывает, занято ли имя.
- `marks[имя] = адрес` добавляет закладку или заменяет адрес. `len` растёт только для нового имени.

## Что сделать

Это упражнение. Запуск: `go run .`. Проверка: `go test .`.
