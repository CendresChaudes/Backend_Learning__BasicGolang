# 7.5. Labels

`break` и `continue` действуют на ближайший цикл. Когда один `for` стоит внутри другого, внутренний `break` внешний цикл не останавливает. Чтобы выйти из нужного цикла, ему ставят метку.

Метка (label) — имя и двоеточие перед оператором. Имя пишут на отдельной строке прямо над `for`.

## break с меткой

`break` с именем метки выходит из цикла, который этой меткой помечен. Внутренний цикл при этом тоже заканчивается: он находился внутри внешнего.

```go
found := 0
outer:
	for i := 1; i <= 3; i++ {
		for j := 1; j <= 3; j++ {
			found = found + 1
			if i == 2 && j == 1 {
				break outer
			}
		}
	}
```

`outer` — метка внешнего цикла. Условие `i == 2 && j == 1` срабатывает на четвёртом шаге внутреннего тела:

- при `i` равном `1` переменная `j` проходит `1`, `2` и `3` — три прибавления;
- при `i` равном `2` и `j` равном `1` счётчик становится `4`, затем `break outer` заканчивает оба цикла.

В `found` лежит `4`. Проход с `i` равным `3` не начинается.

`break` без метки на том же условии вышел бы только из цикла по `j`. Цикл по `i` продолжил бы работу.

## continue с меткой

`continue` с меткой бросает текущий проход помеченного цикла и начинает следующий его проход. Хвост внутреннего цикла в этой итерации уже не выполняется.

```go
sum := 0
outer:
	for i := 1; i <= 3; i++ {
		for j := 1; j <= 3; j++ {
			if j == 2 {
				continue outer
			}
			sum = sum + i + j
		}
	}
```

Когда `j` равен `2`, `continue outer` переходит к следующему `i`. Сложение для этого `j` не выполняется. `j` равный `3` в том же проходе тоже пропускается.

Для каждого `i` в сумму успевает попасть только `i + 1`. Это `2 + 3 + 4`, вместе `9`.

Метку и её цикл пишут в одной функции. `break` или `continue` с этим именем стоит внутри помеченного цикла.

## Что запомнить

- Метка — имя с двоеточием на строке перед `for`.
- `break метка` выходит из помеченного цикла.
- `continue метка` начинает следующую итерацию помеченного цикла.
- `break` и `continue` без метки касаются ближайшего цикла.
