# 7.6. Type Alias

Type alias — второе имя уже существующего типа. Слово alias здесь значит «псевдоним». Новый тип при этом не появляется: оба имени описывают одно и то же.

## Псевдоним

В объявлении `type` знак `=` делает псевдоним.

```go
type Code = int

var status Code = 200
var n int = status
```

`Code` и `int` — один тип. Число `200` записывается в `Code` напрямую. Значение из `status` записывается в обычный `int` тоже напрямую. Преобразование между ними не нужно.

В самом языке уже есть такой псевдоним. `byte` — другое имя типа `uint8`. Где ждут `byte`, подойдёт `uint8`, и наоборот.

Псевдоним укорачивает длинную запись. Имя `Bookmarks` читается короче, чем `map[string]string`, а тип остаётся тем же.

```go
type Bookmarks = map[string]string

marks := Bookmarks{
	"docs": "https://go.dev",
}
```

Функция с аргументом `map[string]string` примет значение типа `Bookmarks`. Это одна и та же map.

## Новый тип

Та же строка `type` без знака `=` создаёт отдельный тип. Внутри может лежать `int`, но для компилятора это уже другой тип.

```go
type Port int

var p Port = 443
var n int = int(p)
```

`443` здесь — константа без собственного типа в переменной. Её можно записать сразу в `Port`.

Готовую переменную типа `int` в `Port` напрямую не кладут. Нужно преобразование: написать имя нового типа и круглые скобки, `Port(n)`. Обратно в `int` значение достают так же: `int(p)`.

Отдельный тип отделяет разные смыслы одного числа. Порт и код ответа оба целые. `type Port int` заставляет в месте, где нужен `int`, написать преобразование явно.

## Что запомнить

- `type Имя = Тип` — псевдоним. Это тот же тип под новым именем.
- `type Имя Тип` — новый тип. Между ним и исходным нужно преобразование `Имя(значение)`.
- `byte` — псевдоним `uint8`.
- Псевдоним для map сокращает длинное имя коллекции, тип пар при этом прежний.
