# 8.1. Все типы данных

К этому месту в курсе уже есть несколько видов значений. Тип по-прежнему решает, какие операции разрешены и что лежит в переменной, пока ей ничего не присвоили.

Этот урок собирает пройденные типы в две группы. Группу определяет присваивание: копируется само значение или два имени начинают смотреть на одни и те же элементы.

## Копия значения

Число, дробное число, строка, `bool` и массив при присваивании копируются. Правка новой переменной оставляет старую прежней.

```go
code := 200
other := code
other = 404
```

`other := code` переписывает число `200` в `other`. `other = 404` меняет только `other`. В `code` по-прежнему `200`.

Со строкой и `bool` то же самое. У массива копируется каждая ячейка: это уже было в уроке про работу с массивами.

```go
title := "go"
clone := title
clone = "py"
```

`clone = "py"` записывает новую строку в `clone`. `title` остаётся `"go"`.

Сюда же относятся объявленные типы вроде `type Port int`. Для присваивания это по-прежнему отдельное числовое значение, просто со своим именем типа.

## Общие элементы

Срез и map при присваивании копируют небольшой заголовок. Сами элементы остаются общими для обоих имён.

```go
codes := []int{200, 404}
view := codes
view[0] = 201
```

`view := codes` копирует заголовок среза. Оба имени смотрят в один массив. `view[0] = 201` меняет ячейку, которую видит и `codes[0]`.

```go
marks := map[string]int{"docs": 1}
alias := marks
alias["docs"] = 2
```

`alias := marks` — вторая переменная на ту же map. `alias["docs"] = 2` меняет пару, и `marks["docs"]` тоже становится `2`.

## Нулевые значения

Пока в переменную ничего не положили, там нулевое значение её типа.

- `int` и `float64` — `0`.
- `string` — пустая строка.
- `bool` — `false`.
- В каждой ячейке массива — ноль её типа.
- Срез и map — `nil`: коллекция ещё не создана. Читать пустой результат можно, писать в nil-map нельзя.

`byte` из прошлого урока отдельным видом данных не является. Это второе имя `uint8`, целого числа размером в байт.

Дальше появится ещё один тип: указатель. Он хранит адрес переменной, а не её значение.

## Что запомнить

- `int`, `float64`, `string`, `bool` и массив при присваивании копируют значение.
- Срез и map при присваивании делят одни и те же элементы.
- Нулевое значение зависит от типа. У среза и map это `nil`.
- Указатель — следующий тип. Он хранит адрес.
