# 8.1. Указатели

У переменной есть значение и место, где это значение лежит. Место называют адресом. Указатель хранит такой адрес.

Число, строка и `bool` при присваивании копируются. Правка новой переменной оставляет старую прежней. Указатель нужен, когда функция должна изменить исходную переменную, а не копию.

## Адрес и чтение

Указатель (pointer) — переменная, в которой записан адрес другой переменной. Тип пишут со звёздочкой: `*int` — адрес переменной типа `int`.

```go
code := 200
p := &code
value := *p
```

`&code` берёт адрес. `p` имеет тип `*int`. `*p` достаёт число, которое лежит по этому адресу. Здесь `value` равен `200`.

Звезда слева от `=` пишет новое значение в ту же переменную:

```go
*p = 201
```

`code` тоже становится `201`. Меняется одна переменная, у неё два способа назвать: имя `code` и указатель `p`.

`new(int)` создаёт переменную `int` и сразу возвращает её адрес. В ней лежит `0`.

Нулевой указатель — `nil`. У него нет адреса. Читать `*p`, когда `p` равен `nil`, нельзя: программа остановится.

## Что запомнить

- `&` берёт адрес. `*` достаёт или меняет значение по адресу.
- Через указатель меняется исходная переменная, не копия.
- `nil` никуда не указывает. Разыменовывать его нельзя.
