# 8.2. Упражнение Reverse массива

Reverse значит развернуть порядок: первый элемент становится последним, последний — первым. Середина, если она одна, остаётся на месте.

Массив в аргументе функции копируется целиком. Чтобы функция поменяла массив вызывающего кода, ей передают указатель на массив. Тип такого аргумента для трёх `int` — `*[3]int`.

## Указатель на массив

```go
nums := [3]int{1, 2, 3}
p := &nums
```

`p[0]` — короткая запись для `(*p)[0]`. Через неё читают и пишут ячейку исходного массива.

Обмен двух ячеек держит одну из них во временной переменной:

```go
tmp := p[0]
p[0] = p[2]
p[2] = tmp
```

После этого массив равен `{3, 2, 1}`.

Пары берут с двух концов. Левый индекс растёт, правый уменьшается. Цикл останавливается, когда индексы встретились.

## Что запомнить

- Массив копируется. Для правки снаружи нужен указатель `*[N]T`.
- `p[i]` читает ячейку массива, на который показывает `p`.
- Обмен идёт парами от краёв к середине.
