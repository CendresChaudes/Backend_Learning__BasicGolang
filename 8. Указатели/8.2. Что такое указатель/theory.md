# 8.2. Что такое указатель

У переменной есть значение и место, где это значение лежит. Место называют адресом. Указатель хранит такой адрес.

Указатель (pointer) — переменная, в которой записан адрес другой переменной. Тип указателя пишут со звёздочкой перед типом значения: `*int` — адрес переменной типа `int`. Звезда здесь часть типа, не умножение.

## Адрес

Знак `&` перед именем переменной даёт её адрес. `&` называют взятием адреса.

```go
code := 200
p := &code
```

`code` хранит число `200`. `&code` — адрес этой переменной. `p` имеет тип `*int` и хранит этот адрес.

Само число `200` в `p` не лежит. Там лежит, где искать `code`.

## nil

Нулевое значение указателя — `nil`. Это пустой адрес: указатель пока ни на какую переменную не показывает.

```go
var p *int
empty := p == nil
```

`var p *int` создаёт указатель и ничего ему не присваивает. Сравнение `p == nil` даёт `true`, поэтому в `empty` лежит `true`.

После `p = &code` в `p` есть адрес. `p == nil` становится `false`.

## Один адрес и разные адреса

Два указателя равны, когда в них записан один и тот же адрес. Сравнение `==` здесь про адреса, не про числа в переменных.

```go
code := 200
first := &code
second := &code
same := first == second
```

`first` и `second` оба получили адрес `code`. `same` равен `true`.

```go
left := 200
right := 200
different := &left != &right
```

В `left` и `right` лежит одно и то же число `200`. Это две разные переменные, у каждой свой адрес. `different` равен `true`.

Значение, которое лежит по адресу, читают и меняют отдельно. Это следующие уроки.

## Что запомнить

- Указатель хранит адрес переменной. Тип адреса `int` пишут как `*int`.
- `&имя` даёт адрес этой переменной.
- Нулевое значение указателя — `nil`, адреса в нём нет.
- `==` у указателей сравнивает адреса.
