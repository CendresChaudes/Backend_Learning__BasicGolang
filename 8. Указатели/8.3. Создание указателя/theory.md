# 8.3. Создание указателя

Указатель появляется тремя способами: адрес уже существующей переменной, встроенная функция `new` и адрес составного литерала. Прочитать число по адресу можно сразу, звёздочкой перед указателем.

## Адрес переменной

Переменная уже есть. `&` берёт её адрес.

```go
code := 200
p := &code
value := *p
```

`p` имеет тип `*int`. `*p` читает значение по этому адресу. Звезда перед указателем в выражении значит «достань значение». В `value` попадает `200`.

Адрес есть у переменной. У голой константы места в памяти нет, поэтому `&200` не компилируется. Сначала число кладут в переменную, потом берут `&`.

## new

`new` — встроенная функция, пакет подключать не нужно. `new(T)` создаёт переменную типа `T`, кладёт в неё нулевое значение и возвращает адрес. Результат имеет тип `*T`.

```go
p := new(int)
value := *p
```

`new(int)` выделяет `int`. Пока туда ничего не записали, там `0`. `*p` читает этот ноль, в `value` лежит `0`.

`make` из прошлых уроков создавал срез или map. `new` создаёт одну переменную любого типа и возвращает указатель на неё.

## Адрес литерала

Составной литерал можно создать и сразу взять его адрес. Переменная под массив тогда не нужна.

```go
p := &[3]int{200, 404, 500}
value := (*p)[1]
```

`&[3]int{200, 404, 500}` создаёт массив из трёх чисел и даёт указатель на него. Тип `p` — `*[3]int`.

`*p` — сам массив. `(*p)[1]` читает ячейку с индексом `1`. Скобки нужны, чтобы сначала получить массив, потом взять ячейку. В `value` лежит `404`.

## Что запомнить

- `p := &переменная` сохраняет адрес уже созданной переменной.
- `*p` читает значение по адресу.
- `new(T)` создаёт переменную типа `T` с нулевым значением и возвращает `*T`.
- `&[3]int{...}` создаёт массив и сразу даёт на него указатель.
