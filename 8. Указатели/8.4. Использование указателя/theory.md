# 8.4. Использование указателя

Звезда перед указателем достаёт переменную, на которую он показывает. Слева от `=` так пишут новое значение. Справа от `=` так читают текущее. Меняется та переменная, чей адрес лежит в указателе.

## Запись по адресу

```go
code := 200
p := &code
*p = 201
```

`*p = 201` пишет `201` в переменную, адрес которой хранит `p`. Это переменная `code`. После строки в `code` лежит `201`.

Чтение выглядит так же, только звезда стоит справа:

```go
current := *p
```

В `current` попадает то, что сейчас лежит в `code`, то есть `201`.

## Аргумент функции

Функция получает копию аргумента. Копия числа не связана с переменной снаружи. Указатель копируется тоже, но в копии тот же адрес, поэтому запись по нему меняет наружную переменную.

```go
func bump(n *int) {
	*n = *n + 1
}
```

`n` имеет тип `*int`. `*n + 1` читает число и прибавляет один. `*n = ...` записывает результат обратно по тому же адресу.

```go
code := 200
bump(&code)
```

В вызов передают адрес: `&code`. Внутри `bump` указатель `n` смотрит на `code`. После вызова в `code` лежит `201`.

## nil

`*p` требует настоящий адрес. У указателя со значением `nil` адреса нет. Чтение и запись через такой указатель останавливают программу: возникает panic.

Перед звездой указатель должен указывать на переменную. Адрес дают `&`, `new` или литерал из прошлого урока.

## Обмен через два указателя

Два указателя позволяют поменять местами две разные переменные. Справа оба числа читаются до записи.

```go
a := 1
b := 2
pa := &a
pb := &b
*pa, *pb = *pb, *pa
```

`*pa, *pb = *pb, *pa` берёт старые значения и раскладывает их наоборот. В `a` оказывается `2`, в `b` оказывается `1`.

## Что запомнить

- `*p = значение` меняет переменную по адресу из `p`.
- В функцию передают `&переменная`, параметр имеет тип `*T`.
- Запись по этому параметру меняет переменную снаружи.
- Звезда на `nil` вызывает panic.
