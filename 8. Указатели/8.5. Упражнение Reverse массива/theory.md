# 8.5. Упражнение Reverse массива

Reverse значит развернуть порядок: первый элемент становится последним, последний — первым. Середина, если она одна, остаётся на месте.

Массив в аргументе функции копируется целиком. Чтобы функция поменяла массив вызывающего кода, ей передают указатель на массив. Тип такого аргумента для трёх `int` — `*[3]int`.

## Указатель на массив

```go
nums := [3]int{8, 5, 1}
p := &nums
```

`p` хранит адрес `nums`. Длину читают как обычно: `len(p)` равен `3`. Go для указателя на массив сам переходит к ячейкам, поэтому `len` принимает и `*[3]int`.

Ячейку можно записать явно через звезду:

```go
first := (*p)[0]
```

`*p` — сам массив. `(*p)[0]` — его нулевая ячейка, число `8`. Короткая запись `p[0]` здесь значит то же самое.

## Обмен краёв

Края меняют тем же двойным присваиванием, что и две ячейки одного массива. Левый индекс растёт, правый уменьшается, пока они не встретятся.

```go
left := 0
right := len(p) - 1
for left < right {
	(*p)[left], (*p)[right] = (*p)[right], (*p)[left]
	left = left + 1
	right = right - 1
}
```

`right` стартует с последнего индекса. Для длины `3` это `2`.

Первый проход меняет индексы `0` и `2`: массив становится `[1, 5, 8]`. Потом `left` равен `1`, `right` равен `1`. Условие `left < right` ложно, цикл останавливается. Средняя ячейка `5` уже на своём месте.

После цикла исходный `nums` тоже равен `[1, 5, 8]`: `p` держал его адрес, копия массива не создавалась.

## Что запомнить

- Развернуть массив — поменять ячейки с двух краёв, двигаясь к середине.
- Функции передают `*[N]int`, чтобы менялся массив снаружи.
- `(*p)[i]` — ячейка `i` массива по указателю. `p[i]` для такого указателя значит то же самое.
- Цикл идёт, пока левый индекс меньше правого.
