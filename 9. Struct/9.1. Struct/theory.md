# 9.1. Struct

У одного человека есть имя и возраст. Пока это две отдельные переменные, связь между ними видна только тебе. Struct собирает такие поля в один тип.

## Описание

Описание struct — чертёж. Оно говорит, какие поля будут у каждого значения этого типа. Само значение при описании ещё не появляется. Описание пишут на уровне пакета: вне функций.

```go
type User struct {
	Name string
	Age  int
}
```

`type User struct` задаёт имя типа. `Name` и `Age` — поля. Имя поля с большой буквы видно за пределами пакета. С маленькой — только внутри пакета.

## Инстанс

Инстанс (instance) — одно конкретное значение по этому чертежу.

```go
ann := User{Name: "Ann", Age: 20}
```

Поле читают через точку: `ann.Name` равно `"Ann"`. Поле, которое не задали, получает нулевое значение своего типа. У `int` это `0`, у строки — `""`.

```go
var guest User
```

`guest.Name` — пустая строка, `guest.Age` — `0`.

## Что запомнить

- Struct связывает несколько полей в один тип.
- Описание — чертёж на уровне пакета. Инстанс — одно заполненное значение.
- Незаданное поле равно нулевому значению своего типа.
