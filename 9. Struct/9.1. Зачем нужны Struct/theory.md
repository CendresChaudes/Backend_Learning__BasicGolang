# 9.1. Зачем нужны Struct

У одного человека есть имя и возраст. Пока это две отдельные переменные, связь между ними видна только тебе.

```go
name := "Ann"
age := 20
```

`name` хранит строку. `age` хранит число. В коде эти переменные стоят рядом, но ничто не связывает их в одного человека.

Второй человек — ещё одна пара переменных. Возраст первого легко прочитать рядом с именем второго.

Struct (структура) — тип, который собирает такие части в одно значение. Поле (field) — одна именованная часть: у неё есть имя и тип.

```go
type User struct {
	Name string
	Age  int
}
```

`type User struct` объявляет тип с именем `User`. В фигурных скобках перечислены поля. `Name` — строка. `Age` — целое число.

Одно значение типа `User` держит оба поля вместе.

```go
user := User{Name: "Ann", Age: 20}
fmt.Println(user.Name)
```

`user` — один человек. Точка между именем значения и именем поля читает эту часть. `user.Name` — строка `"Ann"`.

Второго человека кладут во вторую переменную того же типа. Поля первой переменной при этом остаются при ней.

Правила описания типа и способы создать значение разобраны в следующих уроках. Здесь важно назначение: связанные данные живут одним значением.

## Что запомнить

- Struct собирает поля одного объекта в одно значение.
- Поле — часть struct: имя и тип.
- К полю обращаются через точку: `user.Name`.
- Два значения одного типа хранят свои поля отдельно.
