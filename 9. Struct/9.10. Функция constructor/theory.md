# 9.10. Функция constructor

Constructor в этом уроке — обычная функция, которая собирает struct и возвращает его. Отдельного ключевого слова для конструктора в Go нет. По имени функции видно, значение какого типа она создаёт: имя начинают с `New`, дальше пишут имя типа.

Тип и функцию размещают на уровне пакета.

```go
type User struct {
	Name string
	Age  int
}

func NewUser(name string, age int) User {
	return User{Name: name, Age: age}
}
```

`NewUser` принимает имя и возраст. `return User{Name: name, Age: age}` создаёт инстанс и сразу отдаёт его. Поля заполнены из аргументов.

Вызов сохраняют в переменную:

```go
user := NewUser("Ann", 20)
```

`user.Name` равен `"Ann"`. `user.Age` равен `20`. Кто вызывает `NewUser`, не собирает литерал сам. Сборку делает одна функция, и все инстансы проходят через неё.

В конструкторе можно задать поле, которого нет среди аргументов.

```go
type Account struct {
	Owner   string
	Balance int
}

func NewAccount(owner string) Account {
	return Account{Owner: owner, Balance: 10}
}
```

Снаружи передают только владельца. Баланс нового счёта всегда `10`: это решение записано внутри `NewAccount`.

Проверку аргументов перед созданием добавляют в следующем уроке. Здесь функция только собирает значение.

## Что запомнить

- Конструктор — функция, которая возвращает готовый struct.
- Имя обычно такое: `New` и имя типа, например `NewUser`.
- Тип и функцию пишут на уровне пакета.
- Поле можно заполнить внутри функции, без отдельного аргумента.
