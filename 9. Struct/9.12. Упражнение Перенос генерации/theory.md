# 9.12. Упражнение Перенос генерации

Генерация пароля из упражнения про алфавит пока жила отдельной функцией: алфавит каждый раз передавали аргументом. Теперь алфавит становится полем struct, а сборка пароля — методом этого struct.

```go
type Generator struct {
	Alphabet string
}
```

`Alphabet` — строка разрешённых символов. Один инстанс хранит один алфавит.

Метод читает алфавит из получателя. Срез rune нужен по той же причине, что и раньше: индекс выбирает символ.

```go
func (g Generator) Symbol(i int) string {
	chars := []rune(g.Alphabet)
	return string(chars[i])
}
```

`g` — копия генератора. `g.Alphabet` — его алфавит. `chars[i]` — rune с номером `i`. `string(...)` превращает его в строку из одного символа.

```go
gen := Generator{Alphabet: "ab"}
fmt.Println(gen.Symbol(1))
```

На экран попадёт `b`. Алфавит в вызов `Symbol` уже не передают: он лежит в `gen`.

Длинный пароль собирают тем же способом в цикле по списку индексов. Каждый шаг дописывает `string(chars[i])` к строке. Число символов в алфавите считают циклом `range` по `g.Alphabet`: `len` считает байты и для русских букв даст другое число.

Повтор одного символа — тот же цикл, только индекс на каждом шаге один и тот же, обычно нулевой: первая rune алфавита.

## Что запомнить

- Алфавит хранят в поле struct.
- Метод берёт алфавит из получателя: `g.Alphabet`.
- Символ по индексу: `string([]rune(g.Alphabet)[i])`.
- В вызов метода алфавит отдельно не передают.

## Что сделать

Это упражнение. Перенеси сборку пароля в методы `Generator`. Запуск: `go run .`. Проверка: `go test .`.
