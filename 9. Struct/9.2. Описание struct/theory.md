# 9.2. Описание struct

Описание struct — это чертёж. Оно говорит, какие поля будут у каждого значения этого типа. Само значение при описании ещё не появляется.

## Тип

Описание пишут на уровне пакета: вне функций, рядом с ними.

```go
type Book struct {
	Title string
	Pages int
}
```

`type` начинает объявление типа. `Book` — имя, по которому к этому чертежу обращаются дальше. `struct` говорит, что тип собран из полей.

Каждое поле — отдельная строка: сначала имя, потом тип. `Title` имеет тип `string`. `Pages` имеет тип `int`. Имена полей в одном struct различаются.

Поля могут быть разного типа. В `Book` рядом лежат строка и число. У другого struct все поля могут быть числами. Состав полей задаёт описание.

## Нулевое значение

Переменная без присвоенного значения получает нулевое значение своего типа. У struct нулевое значение собирается из нулей полей.

```go
var book Book
```

`var book Book` создаёт переменную типа `Book` и оставляет её нулевой. `book.Title` — пустая строка. `book.Pages` — число `0`. Нулевое значение поля такое же, как у его типа: у `int` это `0`, у `string` это пустая строка, у `bool` это `false`.

## Чтение поля

Поле читают точкой, когда значение уже есть. Один способ получить значение — записать поля в фигурных скобках. Подробные способы создания разобраны в следующем уроке. Здесь литерал нужен, чтобы увидеть описанное поле.

```go
book := Book{Title: "Go", Pages: 120}
fmt.Println(book.Pages)
```

`Book{Title: "Go", Pages: 120}` — значение по чертежу `Book`. `book.Pages` читает поле `Pages`. На экран попадёт `120`.

Порядок строк в описании — порядок полей в типе. Имя поля в литерале показывает, в какое поле попадёт значение. `Pages: 120` заполняет число страниц.

## Что запомнить

- `type Имя struct { ... }` описывает тип и его поля.
- Строка поля: имя, затем тип.
- Нулевой struct: в каждом поле нулевое значение его типа.
- Поле читают через точку: `book.Pages`.
