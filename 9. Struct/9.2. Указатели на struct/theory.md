# 9.2. Указатели на struct

Функция получает копию аргумента. Для struct копируются все поля. Поля переменной снаружи остаются прежними.

```go
func older(u User) {
	u.Age = 30
}
```

После `older(ann)` возраст `ann` снаружи не меняется: функция правила копию.

Указатель хранит адрес struct. Тип пишут `*User`. По этому адресу меняют поля исходного значения.

```go
func grow(u *User) {
	u.Age = u.Age + 1
}
```

Вызов `grow(&ann)` передаёт адрес. Запись `u.Age` — короткая форма для `(*u).Age`. Go сам достаёт struct по указателю, когда через точку читают поле. После вызова возраст снаружи больше на 1.

Если указатель равен `nil`, поля читать нельзя.

## Что запомнить

- Struct в аргументе копируется. Правка копии снаружи не видна.
- `*User` указывает на исходное значение. Поля через точку меняют его.
- Адрес передают через `&`.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
