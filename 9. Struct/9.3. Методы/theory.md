# 9.3. Методы

Метод (method) — функция, привязанная к типу. Её вызывают у значения через точку. Получатель (receiver) — значение, для которого метод вызван. Его записывают в скобках перед именем метода.

Тип и метод объявляют на уровне пакета. Внутри другой функции метод не описывают.

```go
type User struct {
	Name string
}

func (u User) Label() string {
	return "user: " + u.Name
}
```

`ann.Label()` вызывает метод. Внутри `u` — копия `ann`. Получатель без звезды работает с копией: запись в поле снаружи не сохранится.

Чтобы запись в поле сохранилась, получатель делают указателем.

```go
func (u *User) Rename(name string) {
	u.Name = name
}
```

`ann.Rename("Mia")` меняет исходную переменную. Go сам берёт адрес, если переменная — не указатель, а метод ждёт `*User`.

## Что запомнить

- Метод вызывают через точку у значения.
- Получатель `User` — копия. Получатель `*User` меняет исходное значение.
- Тип и метод лежат на уровне пакета.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
