# 9.3. Создание инстанса

Инстанс (instance) — одно конкретное значение типа. `type User struct` описывает чертёж. Инстанс — один заполненный объект по этому чертежу.

```go
type User struct {
	Name string
	Age  int
}
```

Дальше в примерах используется этот `User`.

## Литерал с именами полей

В фигурных скобках пишут имя поля, двоеточие и значение.

```go
user := User{Name: "Ann", Age: 20}
```

`user` — инстанс типа `User`. В `Name` лежит `"Ann"`, в `Age` лежит `20`.

Порядок именованных полей в скобках может отличаться от порядка в типе. Пара `Age: 20` всё равно попадает в поле `Age`.

Поле, которого нет в скобках, получает нулевое значение своего типа.

```go
user := User{Name: "Ann"}
```

Здесь задано только имя. `user.Age` равен `0`.

## Запись в поле

Точка слева от `=` меняет уже созданный инстанс.

```go
user.Age = 21
```

В поле `Age` этого `user` теперь лежит `21`. Поле `Name` остаётся `"Ann"`.

## Литерал по порядку полей

Имена полей в скобках можно не писать. Тогда значения идут в том порядке, в каком поля стоят в типе. Нужны все поля: пропустить одно в такой записи нельзя.

```go
user := User{"Otto", 40}
```

Первое значение попадает в `Name`, второе — в `Age`. Имя — `"Otto"`, возраст — `40`.

Если поменять числа местами без имён, они попадут в другие поля. Именованная запись это исключает: там поле выбирают по имени.

## Что запомнить

- Инстанс — конкретное значение struct.
- `User{Name: "Ann"}` заполняет названные поля. Остальные становятся нулевыми.
- `user.Age = 21` записывает новое значение в поле.
- `User{"Otto", 40}` заполняет все поля по порядку описания.
