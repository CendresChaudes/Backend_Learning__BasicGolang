# 9.3. Упражнение Генерация пароля

Rune — один символ текста в виде числа. В языке это второе имя типа `int32`. Символ в одинарных кавычках имеет тип rune. В двойных кавычках `"A"` — строка, другой тип.

Пароль здесь — строка из разрешённых символов. Набор таких символов называют алфавитом. Алфавит хранят строкой.

Индекс в строке считает байты. Чтобы взять символ по номеру, строку превращают в срез rune.

```go
chars := []rune("ab")
symbol := string(chars[1])
```

`[]rune("ab")` — срез из двух rune: `'a'` и `'b'`. Индекс `1` — второй символ. `string(chars[1])` даёт строку `"b"`.

Пароль собирают, дописывая такие строки друг к другу. Проверка смотрит каждую rune пароля и ищет её в алфавите.

## Что запомнить

- Rune — один символ. Одинарные кавычки задают rune, двойные — строку.
- `[]rune(text)` режет строку на символы, не на байты.
- `string(oneRune)` делает из символа строку.
