# 9.4. Конструктор

Constructor в этом уроке — обычная функция, которая собирает struct и возвращает его. Отдельного ключевого слова для конструктора в Go нет. По имени видно, что функция создаёт значение: имя начинается с `New`.

Валидация — проверка данных до того, как из них соберут struct. Плохое значение в конструктор не проходит. Функция возвращает ошибку, а готовый инстанс — только когда данные подошли.

```go
func NewUser(name string, age int) (User, error) {
	if name == "" {
		return User{}, errors.New("пустое имя")
	}
	if age < 0 {
		return User{}, errors.New("отрицательный возраст")
	}
	return User{Name: name, Age: age}, nil
}
```

`User{}` — пустое значение на месте результата, когда есть ошибка. `nil` во втором результате значит: ошибки нет.

Вызывающий код сначала смотрит на ошибку. Поля struct читают, только если ошибки нет.

## Что запомнить

- Конструктор — обычная функция `New...`, которая возвращает struct.
- Плохие данные возвращают ошибку и пустой struct.
- `nil` во втором результате значит, что значение можно использовать.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
