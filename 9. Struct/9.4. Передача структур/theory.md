# 9.4. Передача структур

Функция получает копию аргумента. Для struct копируется всё значение: каждое поле. Копия живёт внутри функции. Поля переменной снаружи остаются прежними.

```go
type User struct {
	Name string
	Age  int
}

func older(u User) User {
	u.Age = u.Age + 1
	return u
}
```

Параметр `u` имеет тип `User`. Внутри `older` выражение `u.Age = u.Age + 1` меняет поле копии. `return u` отдаёт эту копию вызывающему коду.

```go
user := User{Name: "Ann", Age: 20}
next := older(user)
```

В `user.Age` по-прежнему `20`. В `next.Age` лежит `21`. `next` — отдельное значение, которое вернула функция.

Чтобы снаружи появился новый возраст, его возвращают. Результат функции — другой инстанс с уже изменённой копией.

## Сравнение

Два значения одного struct можно сравнить знаком `==`, если так можно сравнить каждое поле. Число, строка и `bool` сравниваются. Срез и map — нет, и struct с таким полем тоже не сравнивается через `==`.

```go
a := User{Name: "Ann", Age: 20}
b := User{Name: "Ann", Age: 20}
same := a == b
```

`same` равен `true`: имя и возраст совпали. Если у `b` другой возраст, `a == b` даст `false`. Сравниваются значения полей, а не то, одна ли это переменная.

## Что запомнить

- В параметр типа struct попадает копия всех полей.
- Запись в поле копии оставляет исходную переменную прежней.
- Новые данные наружу отдают через `return`.
- `==` сравнивает поля, если каждое поле само сравнивается.
