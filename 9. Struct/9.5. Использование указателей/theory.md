# 9.5. Использование указателей

Указатель хранит адрес переменной. Для struct тип указателя пишут как `*User`: звезда и имя типа. По этому адресу можно менять поля исходного значения. Копия всего struct для этого не нужна.

```go
type User struct {
	Name string
	Age  int
}
```

## Адрес и поле

`&` берёт адрес уже созданной переменной.

```go
user := User{Name: "Ann", Age: 20}
p := &user
p.Age = 21
```

`p` имеет тип `*User`. `p.Age = 21` записывает поле того `user`, чей адрес лежит в `p`. После этой строки `user.Age` равен `21`.

Та же запись через звезду выглядит так: `(*p).Age = 21`. Скобки нужны, чтобы звезда относилась к `p`, а точка — к полю. Для struct короткая форма `p.Age` делает то же самое. Go сам переходит от указателя к значению, когда после него стоит поле.

Адрес можно взять у литерала сразу. Так же в уроке про указатели брали адрес литерала массива.

```go
p := &User{Name: "Ann", Age: 20}
```

`p` снова имеет тип `*User`. Отдельная переменная `user` здесь не нужна.

## Параметр-указатель

Функция с параметром `*User` получает копию адреса. Адрес тот же, поэтому запись в поле меняет переменную снаружи.

```go
func birthday(u *User) {
	u.Age = u.Age + 1
}
```

`u.Age = u.Age + 1` читает возраст по адресу и записывает число на один больше.

```go
user := User{Name: "Ann", Age: 20}
birthday(&user)
```

В вызов передают `&user`. После вызова `user.Age` равен `21`.

## nil

Нулевое значение указателя — `nil`. Адреса в нём нет. Чтение и запись поля через такой указатель останавливают программу: возникает panic.

```go
var p *User
```

Пока в `p` не положили адрес, к `p.Age` не обращаются. Адрес дают `&` или `new`, как в главе про указатели.

## Что запомнить

- Тип указателя на struct — `*User`. Адрес переменной даёт `&`.
- `p.Age = 21` меняет поле исходного значения.
- Функция с параметром `*User` меняет поля переменной снаружи.
- Указатель `nil` не ведёт на значение. Поле через него не читают и не пишут.
