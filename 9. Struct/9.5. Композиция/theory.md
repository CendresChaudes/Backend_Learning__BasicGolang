# 9.5. Композиция

Композиция — сборка одного типа из другого. Внешний struct хранит внутренний как поле. Так описание администратора включает описание пользователя и добавляет своё.

Поле без имени снаружи называют встраиванием. Имя поля тогда совпадает с именем типа.

```go
type User struct {
	Name string
}

func (u User) Label() string {
	return "user: " + u.Name
}

type Admin struct {
	User
	Level int
}
```

Поля и методы встроенного `User` видны у `Admin` напрямую.

```go
adm := Admin{User: User{Name: "Ann"}, Level: 2}
name := adm.Name
label := adm.Label()
```

`adm.Name` читает поле встроенного `User`. `adm.Label()` вызывает его метод. `adm.Level` — собственное поле `Admin`.

Если у внешнего типа есть своё поле или метод с тем же именем, оно перекрывает встроенное. Тогда внутреннее достают через имя типа: `adm.User.Name`.

## Что запомнить

- Композиция собирает новый тип из уже существующего.
- Поле без имени встраивает внутренний тип.
- Поля и методы встроенного типа вызывают снаружи напрямую.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
