# 9.6. Rune

Rune — один символ текста в виде числа. В языке это псевдоним типа `int32`: второе имя уже знакомого целого, как `byte` был вторым именем `uint8`. Отдельный смысл у rune такой: это кодовый пункт Unicode, номер символа в общей таблице.

Символ в одинарных кавычках имеет тип rune.

```go
letter := 'A'
```

`letter` хранит номер символа `A`. В двойных кавычках `"A"` — это строка из одного символа, другой тип.

Строку из одного символа получают преобразованием. Имя типа пишут как вызов:

```go
text := string(letter)
```

В `text` лежит `"A"`.

## Байты и символы

Строка в памяти — последовательность байтов. `len` считает байты.

```go
word := "код"
size := len(word)
```

В `size` будет `6`. Буквы `к`, `о` и `д` в кодировке UTF-8 занимают по два байта. Символов три, байтов шесть.

Цикл `range` по строке идёт по символам и на каждом шаге отдаёт rune.

```go
count := 0
for _, symbol := range word {
	count = count + 1
}
```

`symbol` имеет тип rune. На первом шаге это `'к'`. `count` станет `3`: по одному шагу на букву.

Первый символ можно забрать и превратить обратно в строку.

```go
var first string
for _, symbol := range "Мир" {
	first = string(symbol)
	break
}
```

`break` останавливает цикл после первого шага. В `first` лежит `"М"`.

Дальше из таких символов собирают пароль: каждый знак пароля — rune, а сам пароль — строка.

## Что запомнить

- Rune — псевдоним `int32` и номер одного символа.
- Символ в одинарных кавычках — rune. `string(rune)` делает из него строку.
- `len` у строки считает байты.
- `for _, symbol := range word` перебирает символы. `symbol` — rune.
