# 9.7. Упражнение Генерация пароля

Пароль здесь — строка из разрешённых символов. Набор таких символов называют алфавитом. Алфавит хранят строкой. Каждый его знак — rune из прошлого урока.

Индекс в строке считает байты. Чтобы взять символ по номеру, строку превращают в срез rune.

```go
chars := []rune("ab")
symbol := string(chars[1])
```

`[]rune("ab")` — срез из двух rune: `'a'` и `'b'`. Индекс `1` — второй символ. `string(chars[1])` даёт строку `"b"`.

Пароль собирают циклом. К строке дописывают выбранный символ.

```go
indexes := []int{1, 0}
password := ""
for _, i := range indexes {
	password = password + string(chars[i])
}
```

`indexes` хранит номера символов в алфавите. Первый шаг берёт индекс `1` и дописывает `"b"`. Второй берёт индекс `0` и дописывает `"a"`. В `password` получается `"ba"`.

Проверка смотрит каждый символ пароля: он должен встретиться в алфавите.

```go
func allowed(symbol rune, alphabet string) bool {
	for _, item := range alphabet {
		if item == symbol {
			return true
		}
	}
	return false
}
```

`item` — очередной rune алфавита. Если он равен `symbol`, символ разрешён, функция возвращает `true`. Если цикл закончился и совпадения не было, символ в алфавите отсутствует, функция возвращает `false`.

Для целого пароля ту же проверку запускают на каждый его rune. Пароль подходит, когда подошёл каждый символ.

## Что запомнить

- Алфавит — строка разрешённых символов.
- `[]rune(алфавит)` даёт символы по индексу, а не байты.
- Пароль собирают так: `password + string(chars[i])`.
- Символ разрешён, если такой rune есть в алфавите.

## Что сделать

Это упражнение. Собери пароль и проверь символы. Запуск: `go run .`. Проверка: `go test .`.
