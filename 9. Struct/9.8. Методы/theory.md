# 9.8. Методы

Метод (method) — функция, привязанная к типу. Её вызывают у значения через точку. Получатель (receiver) — это значение, для которого метод вызван. Его записывают перед именем метода.

Тип, у которого есть метод, объявляют на уровне пакета. Внутри другой функции такой тип с методом не описывают: метод тоже лежит на уровне пакета.

```go
type User struct {
	Name string
}

func (u User) Label() string {
	return u.Name
}
```

`(u User)` — получатель. `u` внутри метода — имя копии того значения, у которого метод вызвали. `Label` — имя метода. Дальше всё как у обычной функции: параметры, если они нужны, и тип результата.

Вызов выглядит как чтение поля, только со скобками:

```go
user := User{Name: "Ann"}
text := user.Label()
```

`user.Label()` вызывает метод. Внутри него `u.Name` равен `"Ann"`. В `text` попадает `"Ann"`.

Получатель-значение — копия, как аргумент struct из урока про передачу. Запись в `u.Name` меняет эту копию. Поле исходной переменной `user` остаётся прежним.

Метод может принимать обычные параметры и возвращать число, строку или `bool`.

```go
type Rect struct {
	W int
	H int
}

func (r Rect) Area() int {
	return r.W * r.H
}
```

`box := Rect{W: 2, H: 5}` и вызов `box.Area()` дают `10`. Получатель `r` — копия `box`. Из его полей считают площадь.

Как менять исходный struct из метода — в следующем упражнении. Там получатель будет указателем.

## Что запомнить

- Метод — функция с получателем. Тип и метод пишут на уровне пакета.
- Получатель стоит перед именем: `func (u User) Label() string`.
- Вызов: `user.Label()`.
- Получатель-значение — копия. Поля исходной переменной из такого метода не меняются.

## Что сделать

Заполни `tasks.go`. Запуск: `go run .`. Проверка: `go test .`.
