# 9.9. Упражнение Мутация struct

Мутация здесь значит изменение полей уже существующего значения. Метод с получателем-значением работает с копией, поэтому исходная переменная после такого метода остаётся прежней.

Чтобы запись в поле сохранилась, получатель делают указателем. В скобках перед именем метода пишут `*ИмяТипа`.

```go
type User struct {
	Name string
}

func (u *User) Rename(name string) {
	u.Name = name
}
```

`u` имеет тип `*User`. `u.Name = name` записывает поле того значения, на которое показывает получатель. Параметр `name` — новое имя, его передают в скобках при вызове.

Вызов пишут через точку у переменной:

```go
user := User{Name: "Ann"}
user.Rename("Eva")
```

`user.Rename("Eva")` вызывает метод. Получатель в описании — указатель, переменная `user` — само значение. Go берёт её адрес сам. После вызова `user.Name` равен `"Eva"`.

Тот же метод меняет число, если прибавлять его к полю.

```go
type Wallet struct {
	Balance int
}

func (w *Wallet) Deposit(amount int) {
	w.Balance = w.Balance + amount
}
```

`Deposit` прибавляет `amount` к балансу по адресу из `w`. Вызов `wallet.Deposit(5)` при стартовом балансе `10` оставляет в `wallet.Balance` число `15`.

Метод можно вызвать несколько раз подряд. Каждый вызов видит уже изменённое поле.

## Что запомнить

- Получатель `*User` указывает на исходное значение.
- Запись в поле такого получателя меняет переменную снаружи.
- Вызов выглядит как `user.Rename("Eva")`. Адрес переменной Go берёт сам.
- Повторный вызов работает с уже обновлёнными полями.

## Что сделать

Это упражнение. У каждого задания свой тип и метод с получателем-указателем. Запуск: `go run .`. Проверка: `go test .`.
